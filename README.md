# 上海初高中知识点汇总

> 按教材逐节编排的**上海初高中知识图谱**：物理已发布（高中 166 考点 + 初中 45 考点），高中数学已发布（13 单元 / 41 考点），高中英语已发布（28 单元 / 1560 词条 / 7 篇故事），高中化学已发布（19 单元 / 130 考点），之后扩展到初中数学、生物、语文。
>
> 每个考点配 3 道自评题 + 3 道梯度例题，支持「先测后学、会了就跳过」。
>
> 本仓库只收**已完成的汇总版**；两个物理老仓库的单独地址见文末「九、仓库关系」。

| 第 6 批 | 初中 | 英语 | 计划中 | 视进度 |

**为什么这个顺序：**

1. **数学**排第二——它是物理之外需求最大、也最依赖"题型 + 变式"结构的学科；
2. **化学、生物**排在理科之后——与物理共享"实验 + 计算 + 概念辨析"的骨架，改造成本低；
3. **语文、英语**放最后——这两科的核心是语料和阅读，卡片体例要做较大调整（从"公式推导"转向"文本分析 + 积累"），需要单独设计；
4. 每批**同时推进初高中**，避免只做高中、初中断档。

**完成一科大概要多久：** 物理高中卷（166 考点）花了约 20 轮迭代；初中卷（43 考点）一次成型。其余学科体量介于两者之间，具体看内容难度。

## 四、怎么用

**打印**：下载对应 PDF，双面打印（初中物理约 26 张、高中物理约 115 张、高中数学约 35 张）。

**电脑查**：下载 HTML 用浏览器打开——
- 顶部搜索框查考点、公式；
- `#c=C-8` 深链直达某个考点；
- 「图谱」页看考点间的前置/派生关系。

**给孩子做**：先做单元入口自评，按得分决定学多少；错题隔天重做、三天后换数字。

## 五、自己构建

每个学科目录独立，进去执行：

```bash
cd 高中/物理 && bash build/make.sh
cd 初中/物理 && bash build/make.sh
cd 高中/数学 && bash build/make.sh
cd 高中/英语 && bash build/make.sh
cd 高中/化学 && bash build/make.sh
```

依赖：`python3`、`python-docx`、`openpyxl`、`markdown`、`matplotlib`、Google Chrome。

## 六、内容标准

- **按教材顺序**：一个考点对应教材的一节或几节，不按"知识模块"重排；
- **三级分流**：章入口 10 题 → 考点 3 题 → 按得分决定跳过/精学；
- **例题梯度**：基础 → 常考 → 综合，每题带"陷阱"和"变式"；
- **公式统一排版**：源文件写纯文本，构建时转 LaTeX，PDF 与 HTML 完全一致。

## 九、仓库关系（改内容前先看这一节）

工作目录 `上海高得-项目管理/` 下有三个**互相独立**的 git 仓库，别改错地方：

| 本地目录 | 远程仓库 | 内容 | 状态 |
|---|---|---|---|
| `上海初高中知识点/` | `mojozhang/shanghai-secondary-knowledge-points` | **汇总仓库**：初中物理 + 高中物理 + 高中数学 + 高中英语（本文件所在） | 活跃，新内容都进这里 |
| `上海高中物理知识图谱/` | `mojozhang/shanghai-high-school-knowledge-points` | 高中物理的早期独立仓库 | 冻结，仅存档 |
| `上海初中物理知识图谱/` | `mojozhang/shanghai-junior-physics-points` | 初中物理的早期独立仓库 | 冻结，仅存档 |

规则：

- **新学科、新修订一律在 `上海初高中知识点/` 里做**；两个物理老仓库不再接收提交，避免同一份内容分叉。
- 三个目录的 remote 各不相同，`git push` 前先 `git remote -v` 确认。
- 汇总仓库里的物理内容是从老仓库迁入的版本，以此处为准。
