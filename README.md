# 上海初高中知识点汇总 · 物理卷

> 一个按教材逐节编排的**物理知识图谱合集**，覆盖上海初中四册与高中六册，共 **209 个考点、627 道梯度例题**。
>
> 每个考点配 3 道自评题 + 3 道梯度例题，支持「先测后学、会了就跳过」。

## 三、怎么用

### 打印给孩子

| 学段 | 文件 |
|---|---|
| 高中 | `高中物理/输出/上海高中物理知识图谱手册.pdf`（229 页） |
| 初中 | `初中物理/输出/上海初中物理知识图谱手册.pdf`（51 页） |

双面打印，高中约 115 张、初中约 26 张。

### 电脑上查

打开对应目录下的 `.html` 文件，支持：
- 顶部搜索框按关键词查考点、公式；
- `#c=C-8` 深链直接跳到某个考点；
- 「图谱」视图看考点间的前置/派生关系。

### 重新构建

两个分册各自独立，进入对应目录执行：

```bash
cd 高中物理 && bash build/make.sh
cd 初中物理 && bash build/make.sh
```

依赖：`python3`、`python-docx`、`openpyxl`、`markdown`、`matplotlib`、Google Chrome。

## 四、两个分册的关系

**同一套体例，难度分档：**

| 维度 | 初中 | 高中 |
|---|---|---|
| 例题步数 | 1–2 步推导 | 3–4 步，多对象多过程 |
| 数学工具 | 比例法、定性分析 | 矢量分解、图像法、微元 |
| 典型难点 | 概念辨析（音调 vs 响度、压力 vs 重力） | 多过程衔接、临界条件、能量观点 |
| 卡片结构 | 完全一致 | 完全一致 |
