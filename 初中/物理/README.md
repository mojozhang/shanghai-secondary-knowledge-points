# 上海初中物理知识点汇总

> 按上海初中物理教材四册（八上、八下、九上、九下）逐节编排：**10 个单元、45 个考点、135 道梯度例题**，支持「先测后学、会了就跳过」。

## 一、这是什么

一套给初中生用的物理学习材料，和《上海高中知识点汇总》同一套体例：

- **按教材顺序编排**，一个考点对应教材的一节或几节；
- 每个考点配 **3 道梯度例题**（基础 / 常考 / 综合）+ **3 道自评题**；
- 每个单元有**入口自评**，做对就跳过，不浪费时间；
- 错题按类型打码，隔天重做。

## 四、一张卡片的结构

| 段落 | 作用 |
|---|---|
| ⚡ 先猜 | 反直觉小问题，制造认知冲突 |
| 30 秒概述 | 两三句话讲清核心 |
| 30 秒自评 | 3 道题，答案紧随 |
| 原理与公式 | 逐条列出 |
| 适用条件 / 易错边界 | 写清什么时候不适用、错在哪 |
| 例题 1 / 2 / 3 | 基础 → 常考 → 综合，含陷阱与变式 |
| ✅ 接下来做什么 | 按对题数给出走法 |

## 七、和高中的关系

同一套体例，难度按初中课标降低一档：

- 高中强调"多过程、多对象、图像法"，初中强调"概念辨析 + 单一公式应用"；
- 高中例题常含 3–4 步推导，初中多为 1–2 步；
- 初中不引入矢量分解、动能定理等，改用比例法和定性分析。
