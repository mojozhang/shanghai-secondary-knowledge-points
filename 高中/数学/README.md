## 公式排版

源文件写纯文本（`x² + 1 ≥ 0`、`log₂8 = 3`），构建时转 LaTeX 由 MathJax 排版。已支持集合（∈ ∪ ∩ ⊆ ∅ ∁）、数集（ℝ ℕ ℤ ℚ ℂ）、逻辑（∀ ∃ ⇒）、三角与对数函数。
