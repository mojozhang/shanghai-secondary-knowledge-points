## 公式排版

源文件写纯文本（`x² + 1 ≥ 0`、`log₂8 = 3`、`S = ½ab sin C`），构建时统一转 LaTeX：HTML/PDF 由 MathJax 排版，Word 由 `mathfmt.py` 渲染成透明 PNG 内嵌。

已支持：
- 集合（∈ ∉ ∪ ∩ ⊆ ⊂ ∅ ∁）、数集（ℝ ℕ ℤ ℚ ℂ）、逻辑（∀ ∃ ⇒ ⇔）
- 上下标（x² x⁻¹ log₂ aₙ₊₁）、根号（√ ∛）、分数（½ 或 a/b）
- 三角（sin cos tan cot，含 sin²α）与对数函数正体
- 集合花括号（`{1, 2, 3}` 会正确排成花括号，不会被 LaTeX 当成分组）
- 指数位置的分式（`8^(2/3)` 会排成真正的分数指数）
- 向量箭头（`a⃗`、`AB⃗` 会排成 \vec 形式）、平行与垂直（∥ ⊥）、组合数（C(n, k)）
