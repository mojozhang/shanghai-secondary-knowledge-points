## A-2.1 等式与不等式的性质

*不等式 › 必修一 第2章 ｜ Ⅱ · 考频中 ｜ 前置 A-1.2 ｜ 关联 A-2.2*

**⚡ 先猜**：a > b 时，两边同乘 -1，不等号要不要变？

### 30 秒概述

不等式两边同加同一个数，方向不变；同乘（除）**正数**方向不变，同乘（除）**负数**方向**改变**。

### 30 秒自评

1. a > b ⇒ a + c > b + c。
2. a > b ⇒ ac > bc 对任意 c 成立。
3. a > b，c > d ⇒ a + c > b + d。

> **答案**：1. ✓　2. ✗（c 为负时反向）　3. ✓

### 🔑 原理与公式

- **a > b ⟺ a - b > 0**
- 同乘负数：**a > b, c < 0 ⇒ ac < bc**
- 同向可加：**a > b, c > d ⇒ a + c > b + d**

**适用条件**：同向可加不可逆；乘法需判号。

**易错边界**
1. 乘负数不变号
2. 两个同向不等式相减或相除
3. 忽略两边同乘的式子符号

### 例题 1 · L1 基础

已知 a > b，判断 ac² 与 bc² 的大小。

**解析**：c² ≥ 0。c ≠ 0 时 c² > 0 ⇒ **ac² > bc²**；c = 0 时**相等**。故 **ac² ≥ bc²**。

**💥 陷阱**：直接写 ac² > bc²（漏 c = 0）。

**变式**：a > b，则 -2a 与 -2b 的大小？（-2a < -2b）

### 例题 2 · L2 常考

a > b > 0，比较 1/a 与 1/b。

**解析**：a > b > 0，两边同除 ab > 0 ⇒ **1/b > 1/a**。

**💥 陷阱**：直接说“取倒数不变号”。

**变式**：a < b < 0 时呢？（1/a > 1/b）

### 例题 3 · L3 综合

已知 -1 < a < 3，2 < b < 4，求 a - b 和 a/b 的范围。

**解析**：
1. -b ∈ (-4, -2)，相加得 **a - b ∈ (-5, 1)**
2. a/b：分子分母异号需分情况；直接算最小时用 a 最小、b 最大：-1/4；最大时 3/2
3. 故 **a/b ∈ (-1/4, 3/2)**

**💥 陷阱**：把区间端点直接相减。

**变式**：a + b 的范围？（1 < a + b < 7）

- **3 道全对** → 例题 3 + 变式。
- **对 2 道** → 例题 2、3。
- **对 0–1 道** → 顺序做。

## A-2.2 不等式的求解

*不等式 › 必修一 第2章 ｜ Ⅱ · 考频**高** ｜ 前置 A-2.1 ｜ 关联 A-2.3　★*

**⚡ 先猜**：x² > 4 的解是 x > 2 吗？

### 30 秒概述

一元二次不等式用**因式分解 + 根的分布**求解；**|x| < a ⟺ -a < x < a**，**|x| > a ⟺ x > a 或 x < -a**。分式不等式化归为整式，注意分母不为零。

### 30 秒自评

1. x² > 4 的解是 x > 2 或 x < -2。
2. |x| < 3 的解是 -3 < x < 3。
3. 分式不等式去分母时不用考虑符号。

> **答案**：1. ✓　2. ✓　3. ✗（要判分母符号）

### 🔑 原理与公式

- **x² < a² ⟺ |x| < a ⟺ -a < x < a**
- **x² > a² ⟺ |x| > a ⟺ x > a 或 x < -a**
- 二次不等式：先求根，再看开口

**适用条件**：a > 0；分式需分母 ≠ 0。

**易错边界**
1. 开平方时漏掉负半轴
2. 二次不等式不看开口方向
3. 分式不等式直接乘分母

### 例题 1 · L1 基础

解不等式 x² - 5x + 6 < 0。

**解析**：(x - 2)(x - 3) < 0 ⇒ **2 < x < 3**

**💥 陷阱**：写成 x < 2 或 x > 3。

**变式**：x² - 5x + 6 > 0？（x < 2 或 x > 3）

### 例题 2 · L2 常考

解不等式 |2x - 1| ≤ 3。

**解析**：-3 ≤ 2x - 1 ≤ 3 ⇒ -2 ≤ 2x ≤ 4 ⇒ **-1 ≤ x ≤ 2**

**💥 陷阱**：只解一半。

**变式**：|2x - 1| ≥ 3？（x ≤ -1 或 x ≥ 2）

### 例题 3 · L3 综合

解不等式 (x - 1)/(x + 2) > 0。

**解析**：
1. 等价于 (x - 1)(x + 2) > 0 且 x ≠ -2
2. 解得 **x > 1 或 x < -2**

**💥 陷阱**：直接乘 (x + 2) 不判号。

**变式**：(x-1)/(x+2) < 0？（-2 < x < 1）

- **3 道全对** → 例题 3 + 变式。
- **对 2 道** → 例题 2、3。
- **对 0–1 道** → 顺序做。

## A-2.3 基本不等式

*不等式 › 必修一 第2章 ｜ Ⅱ · 考频**高** ｜ 前置 A-2.2 ｜ 关联 A-4.1　★*

**⚡ 先猜**：x + 1/x 的最小值一定是 2 吗？

### 30 秒概述

**a + b ≥ 2√(ab)**（a, b > 0），当且仅当 **a = b** 取等号。用它的三条件：**一正、二定、三相等**。

### 30 秒自评

1. 基本不等式对任意实数成立。
2. a = b 时 a + b = 2√(ab)。
3. x + 1/x ≥ 2 对任意 x ≠ 0 成立。

> **答案**：1. ✗（要求 a,b > 0）　2. ✓　3. ✗（x < 0 时为负）

### 🔑 原理与公式

- **a + b ≥ 2√(ab)**（a, b > 0），等号 ⟺ a = b
- 变形：**ab ≤ ((a+b)/2)²**
- 积定和最小、和定积最大

**适用条件**：一正、二定、三相等。

**易错边界**
1. 忽略正数条件
2. 不验证等号能否取到
3. 变量为负时不分类

### 例题 1 · L1 基础

x > 0 时，求 x + 4/x 的最小值。

**解析**：x·4/x = 4 为定值 ⇒ x + 4/x ≥ 2√4 = **4**，等号在 x = 2 时取到。

**💥 陷阱**：不检查 x = 2 是否在定义域内。

**变式**：x < 0 时呢？（最大值为 -4）

### 例题 2 · L2 常考

x > 0，求 2x + 1/x 的最小值。

**解析**：2x·1/x = 2 ⇒ 2x + 1/x ≥ 2√2。等号 2x = 1/x ⇒ x = √2/2 时取到 **2√2**。

**💥 陷阱**：写成 √2。

**变式**：3x + 4/x 的最小值？（4√3）

### 例题 3 · L3 综合

已知 a, b > 0 且 a + b = 1，求 1/a + 1/b 的最小值。

**解析**：
1. 1/a + 1/b = (a+b)(1/a+1/b) = 2 + b/a + a/b
2. b/a + a/b ≥ 2，等号 a = b = 1/2
3. 最小值为 **4**

**💥 陷阱**：直接用 1/a + 1/b ≥ 2/√(ab) 后无法定值。

**变式**：a + b = 1 时 ab 的最大值？（1/4）
