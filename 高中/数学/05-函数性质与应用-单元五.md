## A-5.1 函数的概念与表示

*函数 › 必修一 第5章 ｜ Ⅱ · 考频**高** ｜ 前置 A-4.3 ｜ 关联 A-5.2　★*

**⚡ 先猜**：f(x) = x² 与 g(t) = t² 是同一个函数吗？

### 30 秒概述

函数由**定义域、对应法则**决定，值域随之确定——这就是"三要素"。判断两个函数是否相同，看**定义域与对应法则是否都相同**，与用什么字母无关。**分段函数是一个函数**，只是在定义域的不同部分用不同式子表示。

### 30 秒自评

1. 两个函数的定义域与对应法则都相同，则它们是同一个函数。
2. f(x) = x 与 g(x) = x²/x 是同一个函数。
3. 分段函数是由几个函数组成的。

> **答案**：1. ✓　2. ✗（g 的定义域是 x ≠ 0）　3. ✗（整体是一个函数）

### 🔑 原理与公式

- **定义**：设 A、B 是非空数集，对 A 中任意 x，按法则 f 都有**唯一确定**的 y 与之对应，记作 y = f(x)，x ∈ A
- **三要素**：定义域、对应法则、值域；值域由前两者唯一确定
- **相同函数**：定义域相同 **且** 对应法则相同，与自变量字母无关
- **分段函数**：各段定义域互不重叠，合起来覆盖整个定义域，整体仍是一个函数
- **定义域**：分母 ≠ 0；偶次根号下 ≥ 0；对数真数 > 0；实际问题还要受实际意义限制

**适用条件**：先看定义域，再谈其他性质；求分段函数的值，先判断自变量落在哪一段。

**易错边界**

1. 只看化简后的解析式判断相同函数，漏掉定义域
2. 分段函数在分界点处不检验归属
3. 定义域写成不等式却不写成集合或区间

### 例题 1 · L1 基础

求函数 f(x) = √(x − 2) + 1/(x − 3) 的定义域。

**解析**：两个条件同时成立：
1. 偶次根号下非负：x − 2 ≥ 0，即 x ≥ 2
2. 分母不为零：x − 3 ≠ 0，即 x ≠ 3

所以定义域是 **x ≥ 2 且 x ≠ 3**，即 [2, 3) ∪ (3, +∞)。

**💥 陷阱**：只写 x ≥ 2，把 x = 3 也放进去，函数在那里无意义。

**变式**：求 f(x) = 1/√(x − 1) 的定义域。（x > 1，注意根号在分母上，不能等于 0）

### 例题 2 · L2 常考

判断下列各组函数是否为同一个函数：
（1）f(x) = x 与 g(x) = x²/x；
（2）f(x) = x 与 h(x) = √(x²)。

**解析**：

1. g(x) 的定义域是 x ≠ 0，与 f(x) 的定义域 ℝ 不同，故**不是**同一个函数
2. h(x) = √(x²)，当 x < 0 时 h(x) = -x，与 f(x) = x 的对应结果不同（如 h(-1) = 1 ≠ -1），故**不是**同一个函数

**💥 陷阱**：把 x²/x 约分成 x 就下结论"相同"——约分的前提是 x ≠ 0，定义域已经变了。

**变式**：f(x) = x² 与 g(x) = (x + 1)² 是同一个函数吗？（不是，对应法则不同）

### 例题 3 · L3 综合

已知分段函数
f(x) = x + 1（x < 0），f(x) = x²（0 ≤ x < 2），f(x) = 2x（x ≥ 2）。
（1）求 f(f(-2))；（2）若 f(a) = 3，求 a。

**解析**：

1. 先看 -2 < 0，用第一段：f(-2) = -2 + 1 = -1
2. 再看 -1 < 0，仍用第一段：f(-1) = 0，故 **f(f(-2)) = 0**
3. 解 f(a) = 3，必须逐段讨论：
    - 第一段：a + 1 = 3 得 a = 2，不满足 a < 0，舍
    - 第二段：a² = 3 得 a = √3 或 a = -√3，只有 √3 满足 0 ≤ a < 2
    - 第三段：2a = 3 得 a = 3/2，不满足 a ≥ 2，舍
4. 故 **a = √3**

**💥 陷阱**：解出 a 后不代回检验它是否落在这一段里，三个段各留一个"假解"。

**变式**：若 f(a) = 4，求 a。（a = 2，落在第三段）

> 答案：① 定义域、对应法则、值域　② x ≥ -1

## A-5.2 函数的基本性质

*函数 › 必修一 第5章 ｜ Ⅱ · 考频**高** ｜ 前置 A-5.1 ｜ 关联 A-5.3　★*

**⚡ 先猜**：奇函数如果在 x = 0 处有定义，f(0) 一定等于 0 吗？

### 30 秒概述

**单调性**描述函数在区间上的增减，**奇偶性**描述图像关于原点或 y 轴的对称。判断奇偶性，第一步永远是看**定义域是否关于原点对称**；证明单调性，用的是"取值—作差—变形—定号"。

### 30 秒自评

1. 奇函数的图像关于 y 轴对称。
2. 若 f(x) 在 [-1, 1] 上单调递增，则 f(-1) 是它在 [-1, 1] 上的最小值。
3. 判断奇偶性时，应先看定义域是否关于原点对称。

> **答案**：1. ✗（关于原点对称）　2. ✓　3. ✓

### 🔑 原理与公式

- **单调性**：区间 D 上任取 x₁ < x₂，若 f(x₁) < f(x₂) 则 f 在 D 上严格增；若 f(x₁) > f(x₂) 则严格减
- **证明五步**：取值 → 作差 f(x₁) - f(x₂) → 因式分解或通分 → 定号 → 结论
- **奇偶性**：定义域关于原点对称；f(-x) = -f(x) 为奇函数，f(-x) = f(x) 为偶函数
- **图像**：奇函数关于原点对称，偶函数关于 y 轴对称
- **最值**：单调函数在区间端点取得最大值、最小值

**适用条件**：单调性是对**区间**而言的；奇偶性必须先满足定义域关于原点对称。

**易错边界**

1. 不检验定义域是否关于原点对称就判奇偶
2. 把两个单调区间用并集符号连起来
3. 奇函数在 x = 0 处无定义，却写 f(0) = 0

### 例题 1 · L1 基础

判断 f(x) = x³ + x 的奇偶性。

**解析**：

1. 定义域是 ℝ，关于原点对称
2. f(-x) = (-x)³ + (-x) = -x³ - x = -(x³ + x) = -f(x)
3. 所以 f(x) 是**奇函数**

**💥 陷阱**：看到 x³、x 都是奇次项就直接下结论，不写 f(-x) 的验证过程——解答题要写。

**变式**：判断 f(x) = x⁴ - 2x² 的奇偶性。（偶函数）

### 例题 2 · L2 常考

用定义证明 f(x) = x² + 1 在 (-∞, 0] 上是严格减函数。

**解析**：

1. 任取 x₁ < x₂ ≤ 0
2. 作差：f(x₁) - f(x₂) = (x₁² + 1) - (x₂² + 1) = x₁² - x₂² = (x₁ - x₂)(x₁ + x₂)
3. 定号：x₁ - x₂ < 0；又 x₁ < x₂ ≤ 0，所以 x₁ + x₂ < 0；负乘负得正
4. 故 f(x₁) - f(x₂) > 0，即 f(x₁) > f(x₂)
5. 所以 f(x) 在 (-∞, 0] 上是**严格减函数**

**💥 陷阱**：用"开口向上、对称轴是 y 轴"的图像法代替定义证明——判断可以，证明题必须用定义。

**变式**：用定义证明 f(x) = 1/x 在 (0, +∞) 上是严格减函数。（作差得 (x₂ - x₁)/(x₁x₂) > 0）

### 例题 3 · L3 综合

已知 f(x) 是定义在 (-1, 1) 上的奇函数，且在 (-1, 1) 上严格递减。解不等式 f(1 - a) + f(1 - a²) < 0。

**解析**：

1. 移项：f(1 - a) < -f(1 - a²)
2. 用奇性：-f(1 - a²) = f(a² - 1)，所以 f(1 - a) < f(a² - 1)
3. 用单调性（严格递减）：1 - a > a² - 1，即 a² + a - 2 < 0，解得 -2 < a < 1
4. 用定义域：-1 < 1 - a < 1 得 0 < a < 2；-1 < 1 - a² < 1 得 0 < a² < 2，即 -√2 < a < √2 且 a ≠ 0，取 0 < a < √2
5. 三个条件取交集：**0 < a < 1**

**💥 陷阱**：只用单调性解出 -2 < a < 1 就交卷，忘了 1 - a 与 1 - a² 都必须落在 (-1, 1) 内。

**变式**：若 f 是偶函数且在 [0, +∞) 上递增，解 f(2x - 1) < f(1/3)。（由偶性得 -1/3 < 2x - 1 < 1/3，解得 1/3 < x < 2/3）

> 答案：① 原点　② 不能，必须分别写

## A-5.3 函数的应用

*函数 › 必修一 第5章 ｜ Ⅱ · 考频**中** ｜ 前置 A-5.2 ｜ 关联 A-5.4*

**⚡ 先猜**：函数 y = f(x) 的图像与 x 轴有交点，说明方程 f(x) = 0 有实数解吗？

### 30 秒概述

函数的应用有三条主线：**建立函数关系**（设变量、找关系、写解析式并注明定义域）、**求零点**（方程 f(x) = 0 的根，可用零点存在定理与二分法逼近）、**用函数观点看不等式**（f(x) > 0 的解集就是图像在 x 轴上方的部分）。

### 30 秒自评

1. 函数的零点是一个点。
2. 若 f 在 [a, b] 上连续且 f(a)·f(b) < 0，则 f 在 (a, b) 内至少有一个零点。
3. 建立函数关系时，写出解析式就够了，定义域可以不管。

> **答案**：1. ✗（零点是一个数）　2. ✓　3. ✗（定义域必须写）

### 🔑 原理与公式

- **建模四步**：设自变量与因变量 → 找等量关系 → 写解析式 **并注明定义域** → 用单调性、配方或基本不等式求最值
- **零点**：使 f(x) = 0 的实数 x；零点是**数**，不是点
- **零点存在定理**：f 在 [a, b] 上连续，且 f(a)·f(b) < 0，则 (a, b) 内至少有一个零点
- **二分法**：取中点，判断零点在左半还是右半，反复把区间缩小一半，直到满足精度
- **用函数解不等式**：f(x) > 0 的解集 = 图像在 x 轴上方部分的横坐标集合

**适用条件**：存在定理只保证"至少一个"，不保证唯一；二分法要求函数连续且端点函数值异号。

**易错边界**

1. 写解析式不写定义域，最值取到定义域外
2. 把零点写成坐标 (x₀, 0)
3. 用存在定理找到一个零点，就说"只有一个零点"

### 例题 1 · L1 基础

求函数 f(x) = x² - 2x - 3 的零点。

**解析**：令 f(x) = 0，得 x² - 2x - 3 = 0，即 (x - 3)(x + 1) = 0，所以零点是 **x = 3 或 x = -1**。

**💥 陷阱**：写成 (3, 0) 和 (-1, 0)——那是图像与 x 轴的交点，零点本身是数。

**变式**：求 f(x) = 2x - 5 的零点。（x = 5/2）

### 例题 2 · L2 常考

用二分法求 f(x) = x³ + x - 3 在区间 (1, 2) 内的零点近似值（精确到 0.1）。

**解析**：

1. f(1) = 1 + 1 - 3 = -1 < 0，f(2) = 8 + 2 - 3 = 7 > 0，零点在 (1, 2) 内
2. 取中点 1.5：f(1.5) = 3.375 + 1.5 - 3 = 1.875 > 0，零点在 (1, 1.5)
3. 取中点 1.25：f(1.25) = 1.953 + 1.25 - 3 = 0.203 > 0，零点在 (1, 1.25)
4. 取中点 1.125：f(1.125) = 1.424 + 1.125 - 3 = -0.451 < 0，零点在 (1.125, 1.25)
5. 取中点 1.1875：f(1.1875) = 1.675 + 1.1875 - 3 = -0.137 < 0，零点在 (1.1875, 1.25)
6. 区间长度 0.0625 < 0.1，精度已满足，取中点得零点近似值 **x ≈ 1.2**

**💥 陷阱**：算一次中点就停；或者区间长度还大于 0.1 就报答案。

**变式**：判断 f(x) = x³ + x - 3 在 (0, 1) 内有无零点。（f(0) = -3，f(1) = -1，同号，不能用定理；又 f 在 ℝ 上递增，故 (0, 1) 内没有零点）

### 例题 3 · L3 综合

某商场促销：一次购物标价不超过 500 元不予优惠；超过 500 元但不超过 1000 元的按 9 折；超过 1000 元的，前 1000 元按 9 折、超出部分按 7 折。设标价为 x 元，实付 y 元。
（1）写出 y 关于 x 的函数；（2）标价 1200 元时实付多少？

**解析**：

1. 分段建立关系，注意每段的定义域：
    - 0 < x ≤ 500：y = x
    - 500 < x ≤ 1000：y = 0.9x
    - x > 1000：y = 0.9 × 1000 + 0.7(x - 1000) = 0.7x + 200
2. 第（2）问 x = 1200 > 1000，用第三段：y = 0.7 × 1200 + 200 = **1040 元**

**💥 陷阱**：第三段写成 0.7x，把前 1000 元的 9 折也一起丢掉；或者漏写定义域，导致分段重叠。

**变式**：标价 800 元时实付多少？（800 落在第二段，y = 720 元）

### ⏱️ 限时挑战（60 秒）

① 函数的零点是点还是数？② 二分法要求函数满足什么条件？

> 答案：① 是一个数　② 在区间上连续，且两端点函数值异号

## A-5.4 反函数

*函数 › 必修一 第5章 ｜ Ⅰ · 考频**中** ｜ 前置 A-5.1 ｜ 关联 A-4.3*

**⚡ 先猜**：偶函数有反函数吗？

### 30 秒概述

如果对值域中的每个 y，只有**唯一**的 x 与之对应，函数就有**反函数**。求反函数三步：**先求值域、再解出 x、最后交换 x 与 y**。互为反函数的两个函数，图像关于直线 **y = x** 对称；指数函数与对数函数就是最典型的一对。

### 30 秒自评

1. 在定义域上严格单调的函数一定有反函数。
2. 偶函数（定义域不止一个点）没有反函数。
3. 求反函数时，交换 x、y 之前要先解出 x。

> **答案**：1. ✓　2. ✓　3. ✓

### 🔑 原理与公式

- **存在条件**：一一对应；在定义域上严格增或严格减 ⇒ 一定存在反函数
- **求法三步**：① 求原函数的值域（它就是反函数的定义域）② 由 y = f(x) 解出 x ③ 交换 x、y，写成 y = f⁻¹(x)
- **图像**：y = f(x) 与 y = f⁻¹(x) 的图像关于直线 y = x 对称
- **对应关系**：f⁻¹(b) = a ⟺ f(a) = b
- **典型一对**：y = aˣ 与 y = logₐx 互为反函数

**适用条件**：先判断是否一一对应；反函数的定义域必须写出来。

**易错边界**

1. 只写解析式，不写反函数的定义域
2. 认为所有函数都有反函数
3. 交换 x、y 之后忘记解方程，直接写 y = f⁻¹(y)

### 例题 1 · L1 基础

求 y = 2x + 1 的反函数。

**解析**：

1. 原函数的值域是 ℝ
2. 解出 x：x = (y - 1)/2
3. 交换 x、y：y = (x - 1)/2，x ∈ ℝ
4. 所以反函数是 **y = (x - 1)/2**

**💥 陷阱**：把原函数直接"倒过来"写成 y = 1/(2x + 1)，这是倒数，不是反函数。

**变式**：求 y = -3x + 2 的反函数。（y = (2 - x)/3，x ∈ ℝ）

### 例题 2 · L2 常考

求 y = x²（x ≥ 0）的反函数。

**解析**：

1. 原函数在 [0, +∞) 上严格增，值域是 [0, +∞)
2. 解出 x：x = √y（因为 x ≥ 0，取正根）
3. 交换 x、y：y = √x，x ≥ 0
4. 所以反函数是 **y = √x，x ≥ 0**

**💥 陷阱**：忘写 x ≥ 0；或者把负数那支也塞进来，那样就不是函数了。

**变式**：求 y = x²（x ≤ 0）的反函数。（y = -√x，x ≥ 0）

### 例题 3 · L3 综合

已知 f(x) = x² - 2x（x ≤ 1）。
（1）求 f 的反函数；（2）求 f⁻¹(3)。

**解析**：

1. 配方：f(x) = (x - 1)² - 1，当 x ≤ 1 时严格递减，值域是 [-1, +∞)
2. 解出 x：由 y = (x - 1)² - 1 得 (x - 1)² = y + 1；因为 x ≤ 1，所以 x - 1 ≤ 0，取负根：x = 1 - √(y + 1)
3. 交换 x、y：**y = 1 - √(x + 1)，x ≥ -1**
4. 求 f⁻¹(3)：由 f⁻¹(3) = a ⟺ f(a) = 3，解 a² - 2a = 3 得 a = 3 或 a = -1；因为定义域要求 a ≤ 1，所以 **f⁻¹(3) = -1**

**💥 陷阱**：开方时取正根，得到 x = 1 + √(y + 1)——那是 x ≥ 1 那一支的反函数，不是本题。

**变式**：求 f(x) = x² - 2x（x ≥ 1）的反函数。（y = 1 + √(x + 1)，x ≥ -1）

> 答案：① y = x　② 2
