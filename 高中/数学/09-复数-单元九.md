## A-9.1 复数的概念与四则运算

*复数 › 必修二 第9章 ｜ Ⅱ · 考频**高** ｜ 前置 A-8.4 ｜ 关联 A-9.2　★*

**⚡ 先猜**：i² 等于 −1 还是 1？

### 30 秒概述

复数写成 **z = a + bi**（a、b 是实数），其中 i² = −1，a 叫实部，b 叫虚部。加减法实部虚部分别算，乘法按多项式展开再把 i² 换成 −1，除法上下同乘分母的**共轭**。

### 30 秒自评

1. 2 + 3i 的实部是 2，虚部是 3i。
2. i³ = −i。
3. z · z̄ = |z|²。

> **答案**：1. ✗（虚部是实数 3，不带 i）　2. ✓　3. ✓

### 🔑 原理与公式

- **定义**：z = a + bi（a, b ∈ ℝ），i² = −1；a 为实部，b 为虚部
- **分类**：b = 0 时为实数；b ≠ 0 时为虚数；a = 0 且 b ≠ 0 时为纯虚数
- **相等**：a + bi = c + di ⟺ a = c 且 b = d
- **加减**：(a + bi) ± (c + di) = (a ± c) + (b ± d)i
- **乘法**：(a + bi)(c + di) = (ac − bd) + (ad + bc)i
- **除法**：(a + bi)/(c + di) = [(a + bi)(c − di)]/(c² + d²)
- **共轭**：z̄ = a − bi；z + z̄ = 2a，z − z̄ = 2bi，z · z̄ = a² + b²
- **模**：|z| = √(a² + b²)
- **i 的幂**：i¹ = i，i² = −1，i³ = −i，i⁴ = 1，周期为 4

**适用条件**：除法要求分母不为 0；虚部是实数 b，写"虚部为 bi"是常见错误。

**易错边界**

1. 把虚部写成 3i（应为 3）
2. i 的幂按周期算错，如 i⁵ = i²
3. 除法时只除实部，忘了整体乘共轭

### 例题 1 · L1 基础

计算 (1 + 2i)(3 − i)。

**解析**：

1. 按多项式展开：3 − i + 6i − 2i²
2. 用 i² = −1：−2i² = 2
3. 合并实部与虚部：**5 + 5i**

**💥 陷阱**：把 i² 直接当成 1，得到 1 + 5i。

**变式**：计算 (2 − i)²。（4 − 4i + i² = 3 − 4i）

### 例题 2 · L2 常考

计算 (1 + i)/(1 − i)。

**解析**：

1. 分子分母同乘分母的共轭 1 + i
2. 分母：(1 − i)(1 + i) = 1 − i² = 2
3. 分子：(1 + i)² = 1 + 2i + i² = 2i
4. 所以原式 = 2i/2 = **i**

**💥 陷阱**：直接约去 1 + i 与 1 − i，得到 1，分母的复数不能这样约。

**变式**：计算 (2 + i)/(1 − i)。（分子分母同乘 1 + i，得 (1 + 3i)/2）

### 例题 3 · L3 综合

已知复数 z 满足 z(1 + i) = 3 − i，求 z 与 |z|。

**解析**：

1. z = (3 − i)/(1 + i)
2. 分子分母同乘 1 − i：z = [(3 − i)(1 − i)]/[(1 + i)(1 − i)]
3. 分母 = 2；分子 = 3 − 3i − i + i² = 2 − 4i
4. 所以 **z = 1 − 2i**
5. |z| = √(1 + 4) = **√5**

**💥 陷阱**：把除法写成 (3 − i)(1 + i)/2，乘错了共轭的方向。

**变式**：求 z̄。（z̄ = 1 + 2i）

### ⏱️ 限时挑战（60 秒）

① i² 等于多少？② 3 + 4i 的模是多少？

> 答案：① −1　② 5

## A-9.2 复数的几何意义

*复数 › 必修二 第9章 ｜ Ⅱ · 考频**中** ｜ 前置 A-9.1 ｜ 关联 A-9.3*

**⚡ 先猜**：两个复数能比较大小吗？

### 30 秒概述

复数 z = a + bi 对应复平面上的点 **Z(a, b)**，也对应向量 **OZ⃗**。于是 |z| 是点到原点的距离，|z₁ − z₂| 是两点间的距离，共轭就是关于实轴对称。**只有实数才能比较大小**。

### 30 秒自评

1. 复数 z = a + bi 对应复平面上的点 (a, b)。
2. |z| 表示点 Z 到原点的距离。
3. 两个复数可以比较大小。

> **答案**：1. ✓　2. ✓　3. ✗（只有实数可以比较大小）

### 🔑 原理与公式

- **复平面**：x 轴为实轴，y 轴为虚轴（虚轴**不含原点**）
- **一一对应**：z = a + bi ⟷ 点 Z(a, b) ⟷ 向量 OZ⃗
- **模的几何意义**：|z| = 点 Z 到原点的距离；|z₁ − z₂| = 两点 Z₁、Z₂ 间的距离
- **共轭**：z̄ 与 z 对应的点关于**实轴**对称
- **加法与减法**：对应向量的平行四边形法则与三角形法则
- **常见轨迹**：|z| = r 是以原点为圆心、r 为半径的圆；|z − z₀| = r 是以 z₀ 对应点为圆心、r 为半径的圆

**适用条件**：只有实部相等且虚部为 0 的复数才谈得上大小比较；虚轴不包括原点。

**易错边界**

1. 把虚轴画成包含原点，导致纯虚数判断出错
2. 把 |z − z₀| 理解成"向量长度"，漏掉"两点距离"
3. 把共轭当成相反数（共轭是 a − bi，相反数是 −a − bi）

### 例题 1 · L1 基础

已知 z = 3 − 4i，写出它对应的点与模。

**解析**：

1. 对应点是 **(3, −4)**，在第四象限
2. |z| = √(3² + (−4)²) = **5**

**💥 陷阱**：把点写成 (−4, 3)，实部与虚部的位置颠倒。

**变式**：z = −1 + i 对应点在第几象限？（第二象限）

### 例题 2 · L2 常考

说明下列方程表示的图形：
（1）|z| = 1；（2）|z − 1| = 2。

**解析**：

1. |z| = 1 表示以原点为圆心、1 为半径的**单位圆**
2. |z − 1| = 2 表示以点 (1, 0) 为圆心、2 为半径的**圆**

**💥 陷阱**：把 |z − 1| = 2 说成"以 1 为半径的圆"，把 2 当成了半径还是距离没分清——2 是半径。

**变式**：|z − i| = 1 表示什么图形？（以 (0, 1) 为圆心、1 为半径的圆）

### 例题 3 · L3 综合

已知复数 z 满足 |z| = 1，求 |z − 2| 的最大值与最小值。

**解析**：

1. |z| = 1 表示 z 对应的点在单位圆上
2. |z − 2| 表示单位圆上的点到点 (2, 0) 的距离
3. 圆心到 (2, 0) 的距离为 2，圆的半径为 1
4. 所以最大值为 2 + 1 = **3**（z = −1 时取到），最小值为 2 − 1 = **1**（z = 1 时取到）

**💥 陷阱**：直接把 |z − 2| 拆成 |z| + 2 = 3，只得到最大值，漏掉最小值。

**变式**：|z − 2i| 的最大值是多少？（2 + 1 = 3）

### ⏱️ 限时挑战（60 秒）

① 复数在复平面上对应什么？② |z₁ − z₂| 的几何意义是什么？

> 答案：① 一个点（或一个向量）　② 两点 Z₁、Z₂ 之间的距离

## A-9.3 实系数一元二次方程与复数的三角形式

*复数 › 必修二 第9章 ｜ Ⅱ · 考频**中** ｜ 前置 A-9.2 ｜ 关联 A-10.1*

**⚡ 先猜**：实系数一元二次方程在 Δ < 0 时有实数根吗？

### 30 秒概述

实系数一元二次方程在 **Δ < 0** 时没有实根，但有一对**共轭虚根**，韦达定理仍然成立。复数还能写成**三角形式** r(cos θ + i sin θ)：乘法变成"模相乘、辐角相加"，乘方用**棣莫弗定理**。

### 30 秒自评

1. 方程 x² + 1 = 0 的根是 ±i。
2. 实系数一元二次方程的虚根一定成对出现，且互为共轭。
3. 复数三角形式 r(cos θ + i sin θ) 中，r 是复数的模。

> **答案**：1. ✓　2. ✓　3. ✓

### 🔑 原理与公式

- **求根公式**（Δ < 0）：x = (−b ± i√(4ac − b²))/(2a)
- **韦达定理**：x₁ + x₂ = −b/a，x₁x₂ = c/a（对虚根同样成立）
- **三角形式**：z = r(cos θ + i sin θ)，其中 r = |z| > 0，θ 为辐角
- **乘法**：模相乘、辐角相加；**除法**：模相除、辐角相减
- **棣莫弗定理**：[r(cos θ + i sin θ)]ⁿ = rⁿ(cos nθ + i sin nθ)
- **常用互化**：1 + i = √2(cos 45° + i sin 45°)；1 + √3i = 2(cos 60° + i sin 60°)

**适用条件**：三角形式要求 r > 0；辐角要根据点所在象限确定，不能只看一个特殊角。

**易错边界**

1. 虚根只写一个，漏掉共轭的那一个
2. 化三角形式时辐角象限判断错误
3. 乘方时只把模乘方，忘了辐角也要乘 n

### 例题 1 · L1 基础

解方程 x² + 2x + 5 = 0。

**解析**：

1. Δ = 4 − 20 = −16 < 0，方程有一对共轭虚根
2. x = (−2 ± i√16)/2 = (−2 ± 4i)/2
3. 所以 **x = −1 + 2i 或 x = −1 − 2i**

**💥 陷阱**：看到 Δ < 0 就写"无解"——在复数范围内它有两个虚根。

**变式**：解方程 x² + 4 = 0。（x = ±2i）

### 例题 2 · L2 常考

已知实系数一元二次方程 x² + px + q = 0 的一个根是 1 + i，求 p、q。

**解析**：

1. 实系数方程的虚根成对出现，另一个根是 1 − i
2. 由韦达定理：x₁ + x₂ = 2 = −p，所以 **p = −2**
3. x₁x₂ = (1 + i)(1 − i) = 1 + 1 = 2 = q，所以 **q = 2**

**💥 陷阱**：只代一个根进去，得到一个方程却有两个未知数，解不下去。

**变式**：若方程 x² + px + q = 0 的两根是 2 ± i，求 p、q。（p = −4，q = 5）

### 例题 3 · L3 综合

把 z = 1 + √3i 化为三角形式，并求 z³。

**解析**：

1. r = √(1 + 3) = 2
2. 对应点 (1, √3) 在第一象限，tan θ = √3，所以 θ = 60°
3. 三角形式：**z = 2(cos 60° + i sin 60°)**
4. 棣莫弗定理：z³ = 2³(cos 180° + i sin 180°) = 8 × (−1 + 0i)
5. 所以 **z³ = −8**

**💥 陷阱**：z³ 只算 2³ = 8，忘了辐角要乘 3。

**变式**：求 z⁶。（z⁶ = 2⁶(cos 360° + i sin 360°) = 64）

### ⏱️ 限时挑战（60 秒）

① 方程 x² + 9 = 0 的根是什么？② 三角形式中的 r 表示什么？

> 答案：① x = ±3i　② 复数的模
