## A-4.1 幂函数

*三类基本函数 › 必修一 第4章 ｜ Ⅱ · 考频**中** ｜ 前置 A-3.1 ｜ 关联 A-4.2*

**⚡ 先猜**：y = x² 和 y = 2ˣ 都是幂函数吗？

### 30 秒概述

形如 **y = xᵃ**（a 为常数）的函数叫**幂函数**。它的定义域随指数 a 变化；图像都过点 (1, 1)；在 (0, +∞) 上，**a > 0 时递增，a < 0 时递减**。

### 30 秒自评

1. 幂函数 y = xᵃ 的图像一定过点 (1, 1)。
2. y = 2x³ 是幂函数。
3. 幂函数 y = x⁻¹ 在 (-∞, 0) ∪ (0, +∞) 上是减函数。

> **答案**：1. ✓　2. ✗（系数必须是 1）　3. ✗（只能说在每个区间内递减，不能说在并集上递减）

### 🔑 原理与公式

- **定义**：y = xᵃ，a 为常数，**系数为 1、底数是 x、指数是常数**，三个条件缺一不可
- **定义域**：a 为正整数时是 ℝ；a = 1/n 且 n 为偶数时是 [0, +∞)；a 为负整数时是 {x | x ≠ 0}
- **单调性**：在 (0, +∞) 上，a > 0 严格增，a < 0 严格减
- **定点**：所有幂函数图像都过 (1, 1)；a > 0 时还过 (0, 0)
- **奇偶性**：a 为整数时，a 为奇数则图像关于原点对称，a 为偶数则关于 y 轴对称

**适用条件**：比较大小必须在同一个单调区间内进行；a < 0 时 x = 0 不在定义域内，不能直接代入。

**易错边界**

1. 把 y = 2x³ 当幂函数（系数不是 1）
2. a < 0 时误以为在整个定义域上递减
3. 没先求定义域就代负值，把无意义的值算进去

### 例题 1 · L1 基础

判断下列函数中哪些是幂函数：y = x³，y = 2ˣ，y = x⁻²，y = (x+1)²，y = √x。

**解析**：幂函数要求"底数是 x、指数是常数、系数为 1"。
1. y = x³：符合
2. y = 2ˣ：指数是变量，是**指数函数**
3. y = x⁻²：符合
4. y = (x+1)²：底数不是 x，不符合
5. y = √x：即 x 的 1/2 次幂，符合

**结论**：y = x³、y = x⁻²、y = √x 是幂函数。

**💥 陷阱**：把 y = 2ˣ 当成幂函数——2ˣ 的自变量在指数上，这是幂函数与指数函数最典型的混淆点。

**变式**：y = 1/x² 是幂函数吗？（是，可写成 y = x⁻²）

### 例题 2 · L2 常考

比较下列各组数的大小：
（1）1.5³ 与 1.7³；
（2）0.7⁻² 与 0.8⁻²。

**解析**：

1. 构造幂函数 f(x) = x³，指数 3 > 0，在 (0, +∞) 上单调递增，而 1.5 < 1.7，故 **1.5³ < 1.7³**
2. 构造幂函数 g(x) = x⁻²，指数 -2 < 0，在 (0, +∞) 上单调递减，而 0.7 < 0.8，故 **0.7⁻² > 0.8⁻²**

**💥 陷阱**：只记"底数大函数值就大"，忘了负指数时单调性正好相反。

**变式**：比较 2⁻³ 与 3⁻³ 的大小？（2⁻³ > 3⁻³，即 1/8 > 1/27）

### 例题 3 · L3 综合

已知幂函数 f(x) = x^(m²−2m−3)（m ∈ ℤ）在 (0, +∞) 上是减函数，且图像关于 y 轴对称，求 m 的值。

**解析**：

1. 在 (0, +∞) 上递减 ⇒ 指数小于 0：m² − 2m − 3 < 0，解得 -1 < m < 3
2. m 为整数 ⇒ m = 0, 1, 2
3. 图像关于 y 轴对称 ⇒ f 是偶函数 ⇒ 指数为偶数
4. 逐个检验：m = 0 时指数为 -3（奇）；m = 1 时指数为 -4（偶）；m = 2 时指数为 -3（奇）
5. 故 **m = 1**

**💥 陷阱**：解完不等式就交卷，把 m = 0、1、2 全写上去，没用"偶函数"这条筛掉两个。

**变式**：若只要求 f(x) 在 (0, +∞) 上递增，求 m 的取值范围。（m < -1 或 m > 3）

### ⏱️ 限时挑战（60 秒）

> 答案：① [0, +∞)　② 减函数

## A-4.2 指数函数

*三类基本函数 › 必修一 第4章 ｜ Ⅱ · 考频**高** ｜ 前置 A-4.1 ｜ 关联 A-4.3　★*

**⚡ 先猜**：指数函数 y = aˣ 的值域是 ℝ 吗？

### 30 秒概述

**y = aˣ**（a > 0 且 a ≠ 1）叫**指数函数**，定义域是 ℝ，值域是 (0, +∞)，图像恒过 (0, 1)。**a > 1 时递增，0 < a < 1 时递减**，x 轴是它的渐近线。

### 30 秒自评

1. y = 3·2ˣ 是指数函数。
2. y = aˣ（a > 0 且 a ≠ 1）的图像恒过点 (0, 1)。
3. 0 < a < 1 时，y = aˣ 是减函数。

> **答案**：1. ✗（系数必须是 1）　2. ✓　3. ✓

### 🔑 原理与公式

- **定义**：y = aˣ，a > 0 且 a ≠ 1；定义域 ℝ，值域 **(0, +∞)**
- **定点**：恒过 (0, 1)；a > 1 时 x → -∞ 图像贴近 x 轴，0 < a < 1 时 x → +∞ 图像贴近 x 轴
- **单调性**：a > 1 严格增；0 < a < 1 严格减
- **对称性**：y = aˣ 与 y = (1/a)ˣ 的图像关于 y 轴对称
- **比较大小**：同底用单调性；不同底先化同底，或插入中间量 1

**适用条件**：底数必须 a > 0 且 a ≠ 1；值域是开区间，0 取不到。

**易错边界**

1. 忽略 a > 0 且 a ≠ 1 的限制
2. 把值域写成 ℝ
3. 0 < a < 1 时把单调性记成递增

### 例题 1 · L1 基础

比较下列各组数的大小：
（1）1.7² 与 1.7³；
（2）0.8⁻¹ 与 0.8⁻²。

**解析**：

1. y = 1.7ˣ 的底数 1.7 > 1，是增函数，2 < 3，故 **1.7² < 1.7³**
2. y = 0.8ˣ 的底数 0 < 0.8 < 1，是减函数，-1 > -2，故 **0.8⁻¹ > 0.8⁻²**

**💥 陷阱**：看到 0.8⁻² 的指数更小就判它更小，忘了底数小于 1 时单调性反过来了。

**变式**：比较 0.8⁰ 与 0.8⁻¹ 的大小？（0.8⁰ > 0.8⁻¹，即 1 > 1.25）

### 例题 2 · L2 常考

解不等式 2^(x²−1) ≥ 4。

**解析**：

1. 化同底：4 = 2²，原不等式即 2^(x²−1) ≥ 2²
2. 底数 2 > 1，函数递增，不等号方向不变：x² − 1 ≥ 2
3. 解得 x² ≥ 3，即 **x ≤ -√3 或 x ≥ √3**

**💥 陷阱**：忘记把 4 化成 2²，直接让 x² − 1 ≥ 4。

**变式**：解不等式 0.5^(x−1) > 1/4。（底数 0 < 0.5 < 1，化为 0.5^(x−1) > 0.5² 得 x − 1 < 2，即 x < 3）

### 例题 3 · L3 综合

已知函数 f(x) = aˣ（a > 0 且 a ≠ 1）在区间 [-1, 1] 上的最大值与最小值之差为 3/2，求 a 的值。

**解析**：

1. 指数函数在闭区间上单调，最值在端点取得
2. 若 a > 1，f 递增，最大值 a，最小值 a⁻¹，则 a − a⁻¹ = 3/2
3. 两边乘 2a：2a² − 3a − 2 = 0，解得 a = 2 或 a = -1/2（舍）
4. 若 0 < a < 1，f 递减，最大值 a⁻¹，最小值 a，则 a⁻¹ − a = 3/2
5. 两边乘 2a：2 − 2a² = 3a，即 2a² + 3a − 2 = 0，解得 a = 1/2 或 a = -2（舍）
6. 故 **a = 2 或 a = 1/2**

**💥 陷阱**：默认 a > 1，只得到一个答案，漏掉 0 < a < 1 的情形。

**变式**：若 f(x) 在 [-1, 1] 上的最大值为 4，求 a。（a = 4 或 a = 1/4）

### ⏱️ 限时挑战（60 秒）

① 指数函数 y = aˣ 的定义域和值域分别是什么？② 它的图像恒过哪个点？

> 答案：① 定义域 ℝ，值域 (0, +∞)　② (0, 1)

## A-4.3 对数函数

*三类基本函数 › 必修一 第4章 ｜ Ⅱ · 考频**高** ｜ 前置 A-4.2 ｜ 关联 A-5.4　★*

**⚡ 先猜**：y = log₂x 与 y = 2ˣ 的图像关于哪条直线对称？

### 30 秒概述

**y = logₐx**（a > 0 且 a ≠ 1，x > 0）叫**对数函数**，定义域 (0, +∞)，值域 ℝ，图像恒过 (1, 0)。**a > 1 递增，0 < a < 1 递减**；它与 y = aˣ 互为反函数，图像关于直线 y = x 对称。

### 30 秒自评

1. y = logₐx 的定义域是 (0, +∞)。
2. y = logₐx 的值域是 ℝ。
3. 0 < a < 1 时，y = logₐx 是增函数。

> **答案**：1. ✓　2. ✓　3. ✗（是减函数）

### 🔑 原理与公式

- **定义**：y = logₐx ⟺ aʸ = x，a > 0 且 a ≠ 1，x > 0
- **定义域与值域**：定义域 (0, +∞)，值域 ℝ
- **定点**：恒过 (1, 0)
- **单调性**：a > 1 严格增；0 < a < 1 严格减
- **反函数**：y = logₐx 与 y = aˣ 互为反函数，图像关于 y = x 对称
- **比大小**：同底用单调性；不同底用 0 或 1 作中间量（a > 1 时，真数大于 1 则对数为正）

**适用条件**：真数必须大于 0；底数大于 0 且不等于 1。

**易错边界**

1. 求定义域时只写 x > 0，忘了真数是 x − 1 这类式子
2. 底数在 (0, 1) 内时把单调性记反
3. 比较对数与 0 的大小时，不看真数与 1 的关系

### 例题 1 · L1 基础

求函数 y = log₂(x − 1) 的定义域。

**解析**：真数必须大于 0，即 x − 1 > 0，所以定义域是 **(1, +∞)**。

**💥 陷阱**：只写"对数定义域是 (0, +∞)"，把 x − 1 当成 x。

**变式**：求 y = log₂(3 − x) 的定义域。（x < 3）

### 例题 2 · L2 常考

比较下列各组数的大小：
（1）log₂3 与 log₂5；
（2）设 a = 1/2，比较 logₐ3 与 logₐ5。

**解析**：

1. 第（1）组同底：y = log₂x 的底数 2 > 1，是增函数，3 < 5，故 **log₂3 < log₂5**
2. 第（2）组底数 a = 1/2，满足 0 < a < 1，是减函数，3 < 5，故 **logₐ3 > logₐ5**

**💥 陷阱**：不看底数范围，一律"真数大的对数大"。

**变式**：比较 log₂3 与 1 的大小。（log₂3 > 1，因为 3 > 2）

### 例题 3 · L3 综合

已知 f(x) = logₐ(2x − 1)，其中 a = 1/2。解不等式 f(x) > 0。

**解析**：

1. 先求定义域：2x − 1 > 0，即 x > 1/2
2. 0 = logₐ1，原不等式即 logₐ(2x − 1) > logₐ1
3. 底数 a = 1/2 在 (0, 1) 内，函数递减，不等号反向：2x − 1 < 1
4. 解得 x < 1
5. 与定义域取交集：**1/2 < x < 1**

**💥 陷阱**：只解到 x < 1 就结束，把 x ≤ 1/2 那些让真数无意义的值也算进解集。

**变式**：若 a = 2，f(x) > 0 的解集是什么？（x > 1）

### ⏱️ 限时挑战（60 秒）

① y = logₐx 的定义域是什么？② 它的图像恒过哪个点？

> 答案：① (0, +∞)　② (1, 0)
