## A-8.1 向量的概念与线性运算

*平面向量 › 必修二 第8章 ｜ Ⅱ · 考频**高** ｜ 前置 A-7.3 ｜ 关联 A-8.2　★*

**⚡ 先猜**：零向量有方向吗？

### 30 秒概述

向量是**既有大小又有方向**的量，大小叫**模**。两个向量只要方向相同、模相等就是**相等向量**；方向相同或相反叫**平行（共线）向量**。加法用三角形法则或平行四边形法则，减法就是加上相反向量，数乘改变长度、可能反向。

### 30 秒自评

1. 模为 1 的向量都相等。
2. 零向量与任意向量平行。
3. |a⃗ + b⃗| = |a⃗| + |b⃗| 对任意向量都成立。

> **答案**：1. ✗（方向可以不同）　2. ✓（零向量方向任意）　3. ✗（只有同向时取等号）

### 🔑 原理与公式

- **定义**：向量由大小与方向两个要素确定；向量 a⃗ 的大小叫模，记作 |a⃗|
- **零向量与单位向量**：模为 0 的向量叫零向量 0⃗，方向任意；模为 1 的向量叫单位向量
- **相等与平行**：方向相同且模相等 ⟺ a⃗ = b⃗；方向相同或相反 ⟺ a⃗ ∥ b⃗
- **加法**：三角形法则（首尾相接）与平行四边形法则（共起点）；**减法** a⃗ − b⃗ = a⃗ + (−b⃗)
- **数乘**：λa⃗ 的模是 |λ||a⃗|；λ > 0 时同向，λ < 0 时反向，λ = 0 时得零向量
- **共线定理**：a⃗ ≠ 0⃗ 时，b⃗ ∥ a⃗ ⟺ 存在唯一实数 λ，使 b⃗ = λa⃗
- **三角不等式**：||a⃗| − |b⃗|| ≤ |a⃗ + b⃗| ≤ |a⃗| + |b⃗|

**适用条件**：共线定理要求 a⃗ ≠ 0⃗；向量不能比较大小，"a⃗ > b⃗"这种写法没有意义。

**易错边界**

1. 把向量的模当成向量本身，写出 a⃗ > b⃗
2. 忽略零向量，让"平行的传递性"失效
3. 数乘时把 λ 的符号与长度变化混为一谈

### 例题 1 · L1 基础

判断下列说法的正误：
（1）若 |a⃗| = |b⃗|，则 a⃗ = b⃗；
（2）若 a⃗ ∥ b⃗，b⃗ ∥ c⃗，则 a⃗ ∥ c⃗；
（3）零向量与任意向量共线。

**解析**：

1. 第（1）句错：模相等只说明长度相同，方向可能相反
2. 第（2）句错：若 b⃗ = 0⃗，则 a⃗ 与 c⃗ 的方向都可以任意，不一定平行
3. 第（3）句对：零向量的方向任意，规定它与任意向量共线

**💥 陷阱**：把"平行"当成普通的大小关系直接传递，忘了零向量这个例外。

**变式**：若 a⃗ = b⃗，则 |a⃗| = |b⃗| 吗？（成立，相等向量方向相同、模相等）

### 例题 2 · L2 常考

在平行四边形 ABCD 中，用 AB⃗、AD⃗ 表示 AC⃗、BD⃗，以及对角线交点 O 对应的 AO⃗。

**解析**：

1. 由三角形法则：AC⃗ = AB⃗ + BC⃗ = **AB⃗ + AD⃗**
2. 减法：BD⃗ = AD⃗ − AB⃗（从 B 指向 D）
3. O 是 AC 的中点，所以 **AO⃗ = ½AC⃗ = ½(AB⃗ + AD⃗)**

**💥 陷阱**：把 BD⃗ 写成 AB⃗ − AD⃗，方向正好反了。

**变式**：用 AB⃗、AD⃗ 表示 BO⃗。（BO⃗ = ½BD⃗ = ½(AD⃗ − AB⃗)）

### 例题 3 · L3 综合

已知 m⃗、n⃗ 不共线，a⃗ = m⃗ + 2n⃗，b⃗ = 2m⃗ + λn⃗。若 a⃗ ∥ b⃗，求 λ 的值。

**解析**：

1. a⃗ ∥ b⃗ 且 b⃗ ≠ 0⃗，所以存在实数 k，使 a⃗ = kb⃗
2. 即 m⃗ + 2n⃗ = k(2m⃗ + λn⃗) = 2k m⃗ + kλ n⃗
3. 因为 m⃗、n⃗ 不共线，比较系数：1 = 2k，2 = kλ
4. 由 1 = 2k 得 k = 1/2，代入得 **λ = 4**

**💥 陷阱**：不说明"m⃗、n⃗ 不共线"就直接比较系数——这句话正是比较系数的依据。

**变式**：若 a⃗ = m⃗ + λn⃗ 与 b⃗ = 2m⃗ + 4n⃗ 共线，求 λ。（λ = 2）

### ⏱️ 限时挑战（60 秒）

① 向量 a⃗ 的大小叫什么？② 零向量的方向是怎么规定的？

> 答案：① 模，记作 |a⃗|　② 方向任意，规定与任意向量共线

## A-8.2 向量的数量积

*平面向量 › 必修二 第8章 ｜ Ⅱ · 考频**高** ｜ 前置 A-8.1 ｜ 关联 A-8.3　★*

**⚡ 先猜**：a⃗ · b⃗ 的结果是向量还是数？

### 30 秒概述

**数量积** a⃗ · b⃗ = |a⃗||b⃗|cos⟨a⃗, b⃗⟩，**结果是一个数**。它把"长度"和"夹角"装进同一个式子：模由 a⃗ · a⃗ 得到，垂直由 a⃗ · b⃗ = 0 判断，夹角由 cos θ = a⃗ · b⃗ ÷ (|a⃗||b⃗|) 求出。

### 30 秒自评

1. 若 a⃗ · b⃗ = 0，则 a⃗ ⊥ b⃗。
2. (a⃗ · b⃗)c⃗ = a⃗(b⃗ · c⃗) 对任意向量都成立。
3. |a⃗|² = a⃗ · a⃗。

> **答案**：1. ✗（a⃗ = 0⃗ 时也等于 0，但零向量不谈垂直）　2. ✗（数量积不满足结合律）　3. ✓

### 🔑 原理与公式

- **定义**：a⃗ · b⃗ = |a⃗||b⃗|cos⟨a⃗, b⃗⟩，夹角 θ ∈ [0°, 180°]
- **运算律**：交换律 a⃗ · b⃗ = b⃗ · a⃗；分配律 (a⃗ + b⃗) · c⃗ = a⃗ · c⃗ + b⃗ · c⃗；(λa⃗) · b⃗ = λ(a⃗ · b⃗)
- **模**：|a⃗| = √(a⃗ · a⃗)，即 |a⃗|² = a⃗ · a⃗
- **垂直**：非零向量 a⃗ ⊥ b⃗ ⟺ a⃗ · b⃗ = 0
- **夹角**：cos θ = (a⃗ · b⃗)/(|a⃗||b⃗|)
- **投影**：b⃗ 在 a⃗ 方向上的投影为 |b⃗|cos θ = (a⃗ · b⃗)/|a⃗|
- **柯西不等式**：|a⃗ · b⃗| ≤ |a⃗||b⃗|，等号当且仅当两向量共线

**适用条件**：夹角必须是两个向量**起点重合**后所成的角；零向量与任意向量的数量积为 0，但讨论垂直时默认非零向量。

**易错边界**

1. 把 a⃗ · b⃗ 当成向量，继续往下"加箭头"
2. 套用结合律，把 (a⃗ · b⃗)c⃗ 与 a⃗(b⃗ · c⃗) 当成相等
3. 求夹角时没把两个向量移到同一起点

### 例题 1 · L1 基础

已知 |a⃗| = 2，|b⃗| = 3，a⃗ 与 b⃗ 的夹角为 60°，求 a⃗ · b⃗ 与 (a⃗ + b⃗) · (a⃗ − b⃗)。

**解析**：

1. a⃗ · b⃗ = 2 × 3 × cos 60° = **3**
2. (a⃗ + b⃗) · (a⃗ − b⃗) = a⃗ · a⃗ − b⃗ · b⃗ = |a⃗|² − |b⃗|² = 4 − 9 = **−5**

**💥 陷阱**：把 (a⃗ + b⃗) · (a⃗ − b⃗) 当成向量减法，继续写"= a⃗² − b⃗²"的向量式——它的结果是数。

**变式**：求 |a⃗ − b⃗|。（|a⃗ − b⃗|² = 4 + 9 − 6 = 7，故 |a⃗ − b⃗| = √7）

### 例题 2 · L2 常考

已知 |a⃗| = 1，|b⃗| = 2，a⃗ · b⃗ = 1，求 |a⃗ + b⃗| 与 a⃗、b⃗ 的夹角。

**解析**：

1. |a⃗ + b⃗|² = |a⃗|² + 2a⃗ · b⃗ + |b⃗|² = 1 + 2 + 4 = 7，所以 **|a⃗ + b⃗| = √7**
2. cos θ = (a⃗ · b⃗)/(|a⃗||b⃗|) = 1/(1 × 2) = 1/2
3. 所以夹角 **θ = 60°**

**💥 陷阱**：把 |a⃗ + b⃗| 直接写成 |a⃗| + |b⃗| = 3。

**变式**：求 |a⃗ − b⃗|。（|a⃗ − b⃗|² = 1 − 2 + 4 = 3，故 |a⃗ − b⃗| = √3）

### 例题 3 · L3 综合

已知 |a⃗| = 2，|b⃗| = 1，a⃗ 与 b⃗ 的夹角为 60°，求 |a⃗ − 2b⃗|。

**解析**：

1. |a⃗ − 2b⃗|² = |a⃗|² − 4a⃗ · b⃗ + 4|b⃗|²
2. a⃗ · b⃗ = 2 × 1 × cos 60° = 1
3. 代入：4 − 4 × 1 + 4 × 1 = 4
4. 所以 **|a⃗ − 2b⃗| = 2**

**💥 陷阱**：中间项写成 −2a⃗ · b⃗，忘了 2b⃗ 的系数平方后是 4|b⃗|²、交叉项系数是 2 × 1 × 2 = 4。

**变式**：求 (a⃗ + 2b⃗) · (a⃗ − b⃗)。（= |a⃗|² − 2|b⃗|² + a⃗ · b⃗ = 4 − 2 + 1 = 3）

### ⏱️ 限时挑战（60 秒）

① 数量积的结果是数还是向量？② 两个非零向量垂直的充要条件是什么？

> 答案：① 数　② 数量积等于 0

## A-8.3 向量的坐标表示

*平面向量 › 必修二 第8章 ｜ Ⅱ · 考频**高** ｜ 前置 A-8.2 ｜ 关联 A-8.4　★*

**⚡ 先猜**：a⃗ = (1, 2)，b⃗ = (2, 4)，a⃗ ∥ b⃗ 吗？

### 30 秒概述

把向量放进直角坐标系，加减、数乘、数量积全变成**坐标运算**。两条判据必须记牢：**平行 ⟺ x₁y₂ − x₂y₁ = 0**，**垂直 ⟺ x₁x₂ + y₁y₂ = 0**。模与夹角也都有坐标公式。

### 30 秒自评

1. a⃗ = (x₁, y₁)，b⃗ = (x₂, y₂)，则 a⃗ · b⃗ = x₁x₂ + y₁y₂。
2. a⃗ ∥ b⃗ 的充要条件是 x₁y₂ − x₂y₁ = 0。
3. 若 x₁x₂ + y₁y₂ = 0，则 a⃗ ⊥ b⃗。

> **答案**：1. ✓　2. ✓　3. ✓（在 a⃗、b⃗ 非零的前提下）

### 🔑 原理与公式

- **坐标运算**：a⃗ ± b⃗ = (x₁ ± x₂, y₁ ± y₂)；λa⃗ = (λx₁, λy₁)
- **数量积**：a⃗ · b⃗ = x₁x₂ + y₁y₂
- **模**：|a⃗| = √(x₁² + y₁²)；两点距离 |AB⃗| = √((x₂ − x₁)² + (y₂ − y₁)²)
- **平行**：a⃗ ∥ b⃗ ⟺ x₁y₂ − x₂y₁ = 0
- **垂直**：a⃗ ⊥ b⃗ ⟺ x₁x₂ + y₁y₂ = 0
- **夹角**：cos θ = (x₁x₂ + y₁y₂)/(√(x₁² + y₁²) · √(x₂² + y₂²))
- **中点**：A(x₁, y₁)、B(x₂, y₂) 的中点是 ((x₁ + x₂)/2, (y₁ + y₂)/2)

**适用条件**：坐标运算的前提是取定了同一组正交单位基底；平行条件对零向量也成立，垂直条件默认非零。

**易错边界**

1. 平行与垂直的坐标条件记反
2. 求模时忘记开平方
3. 坐标减法方向反了，把 AB⃗ 写成 B − A 之外的形式

### 例题 1 · L1 基础

已知 a⃗ = (3, 4)，b⃗ = (−1, 2)，求 a⃗ · b⃗、|a⃗|、|b⃗| 与 a⃗ + b⃗。

**解析**：

1. a⃗ · b⃗ = 3 × (−1) + 4 × 2 = **5**
2. |a⃗| = √(9 + 16) = **5**
3. |b⃗| = √(1 + 4) = **√5**
4. a⃗ + b⃗ = (3 − 1, 4 + 2) = **(2, 6)**

**💥 陷阱**：把 |a⃗| 写成 9 + 16 = 25，忘记开方。

**变式**：求 a⃗ 与 b⃗ 夹角的余弦值。（5/(5√5) = √5/5）

### 例题 2 · L2 常考

已知 a⃗ = (1, 2)，b⃗ = (x, −1)。
（1）若 a⃗ ⊥ b⃗，求 x；（2）若 a⃗ ∥ b⃗，求 x。

**解析**：

1. 垂直用数量积为 0：1 · x + 2 · (−1) = 0，解得 **x = 2**
2. 平行用交叉积为 0：1 · (−1) − 2 · x = 0，解得 **x = −1/2**

**💥 陷阱**：把平行条件也写成 x₁x₂ + y₁y₂ = 0，两个条件混用。

**变式**：若 a⃗ 与 b⃗ 的夹角为钝角，求 x 的取值范围。（a⃗ · b⃗ = x − 2 < 0 得 x < 2；再排除反向的 x = −1/2，故 x < 2 且 x ≠ −1/2）

### 例题 3 · L3 综合

已知 a⃗ = (1, 2)，b⃗ = (−3, 2)。当 k 为何值时，ka⃗ + b⃗ 与 a⃗ − 3b⃗ 平行？

**解析**：

1. ka⃗ + b⃗ = (k − 3, 2k + 2)
2. a⃗ − 3b⃗ = (1 + 9, 2 − 6) = (10, −4)
3. 平行：−4(k − 3) − 10(2k + 2) = 0
4. 化简：−4k + 12 − 20k − 20 = 0，即 −24k = 8，解得 **k = −1/3**

**💥 陷阱**：用垂直条件 x₁x₂ + y₁y₂ = 0 去解，答案完全不对。

**变式**：若 ka⃗ + b⃗ 与 a⃗ − 3b⃗ 垂直，求 k。（10(k − 3) − 4(2k + 2) = 0，解得 k = 19）

### ⏱️ 限时挑战（60 秒）

① 写出 a⃗ ∥ b⃗ 的坐标条件。② 写出 a⃗ ⊥ b⃗ 的坐标条件。

> 答案：① x₁y₂ − x₂y₁ = 0　② x₁x₂ + y₁y₂ = 0

## A-8.4 向量的应用

*平面向量 › 必修二 第8章 ｜ Ⅱ · 考频**中** ｜ 前置 A-8.3 ｜ 关联 A-9.1*

**⚡ 先猜**：用向量能证明三点共线吗？

### 30 秒概述

向量是"把几何问题变成代数运算"的工具：**证共线**看两向量是否成比例，**证垂直**看数量积是否为 0，**求长度**就是求模。物理里力的合成、速度合成，也正是向量加法。

### 30 秒自评

1. 要证 A、B、C 三点共线，可证 AB⃗ 与 AC⃗ 共线。
2. 两个力的合力可以用平行四边形法则求。
3. 用向量求线段的长度，就是求对应向量的模。

> **答案**：1. ✓　2. ✓　3. ✓

### 🔑 原理与公式

- **三点共线**：AB⃗ = λAC⃗（必须从同一点出发）
- **垂直**：AB⃗ · AC⃗ = 0
- **长度**：|AB⃗| = √((x₂ − x₁)² + (y₂ − y₁)²)
- **中点**：OM⃗ = ½(OA⃗ + OB⃗)
- **物理应用**：两个力 F⃗、G⃗ 的合力为 F⃗ + G⃗；速度合成 v⃗ = v⃗₁ + v⃗₂；做功 W = F⃗ · s⃗

**适用条件**：判断共线时两个向量必须同起点；物理量要统一单位后再合成。

**易错边界**

1. 共线判定没有取同一起点
2. 只算出合力大小，漏掉方向
3. 用坐标求长度时忘记开平方

### 例题 1 · L1 基础

已知 A(0, 0)，B(2, 1)，C(−1, 2)，证明 AB⃗ ⊥ AC⃗。

**解析**：

1. AB⃗ = (2 − 0, 1 − 0) = (2, 1)
2. AC⃗ = (−1 − 0, 2 − 0) = (−1, 2)
3. AB⃗ · AC⃗ = 2 × (−1) + 1 × 2 = 0
4. 所以 **AB⃗ ⊥ AC⃗**

**💥 陷阱**：把 AC⃗ 写成 (1, −2)（方向取反），点积仍为 0，但说明不了任何问题——坐标必须按"终点减起点"算。

**变式**：求 |BC⃗|。（BC⃗ = (−3, 1)，|BC⃗| = √10）

### 例题 2 · L2 常考

两个力 F⃗、G⃗ 的大小都是 10 N，夹角为 120°，求合力的大小与方向。

**解析**：

1. |F⃗ + G⃗|² = |F⃗|² + |G⃗|² + 2|F⃗||G⃗|cos 120°
2. = 100 + 100 + 2 × 10 × 10 × (−1/2) = 100
3. 所以合力大小 **|F⃗ + G⃗| = 10 N**
4. 方向：沿 F⃗ 与 G⃗ 夹角的**角平分线**

**💥 陷阱**：把合力写成 10 + 10 = 20 N，忽略了夹角。

**变式**：若夹角为 60°，合力多大？（|F⃗ + G⃗|² = 100 + 100 + 100 = 300，|F⃗ + G⃗| = 10√3 N）

### 例题 3 · L3 综合

在 △ABC 中，AB⃗ = (2, 3)，AC⃗ = (1, k)。若 △ABC 是直角三角形，求 k 的值。

**解析**：直角可能在 A、B、C 三处，逐一讨论：

1. **A 为直角**：AB⃗ · AC⃗ = 2 + 3k = 0，得 k = −2/3
2. **B 为直角**：BA⃗ = (−2, −3)，BC⃗ = AC⃗ − AB⃗ = (−1, k − 3)；BA⃗ · BC⃗ = 2 − 3(k − 3) = 0，得 k = 11/3
3. **C 为直角**：CA⃗ = (−1, −k)，CB⃗ = AB⃗ − AC⃗ = (1, 3 − k)；CA⃗ · CB⃗ = −1 − k(3 − k) = 0，即 k² − 3k − 1 = 0，得 k = (3 ± √13)/2
4. 综上：**k = −2/3 或 11/3 或 (3 ± √13)/2**

**💥 陷阱**：只讨论 ∠A 为直角，漏掉另外两种情形。

**变式**：若 ∠A 为锐角，求 k 的取值范围。（AB⃗ · AC⃗ = 2 + 3k > 0，得 k > −2/3）
