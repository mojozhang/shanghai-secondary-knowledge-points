## A-6.1 任意角与弧度制

*三角比 › 必修二 第6章 ｜ Ⅱ · 考频**中** ｜ 前置 A-5.4 ｜ 关联 A-6.2*

**⚡ 先猜**：30° 与 390° 的终边相同吗？

### 30 秒概述

角可以**任意大、可正可负**。与角 α 终边相同的所有角，彼此相差 360° 的整数倍。改用**弧度制**后，角与实数一一对应，弧长、扇形面积公式变得非常简洁：**l = |α|r**、**S = ½|α|r²**。

### 30 秒自评

1. 与 30° 终边相同的角可以写成 30° + k·360°（k ∈ ℤ）。
2. 1 弧度的角比 1° 的角大。
3. 圆心角为 60°、半径为 2 的扇形，弧长是 2。

> **答案**：1. ✓　2. ✓（1 弧度≈57.3°）　3. ✗（应先把 60° 化成 π/3，得弧长 2π/3）

### 🔑 原理与公式

- **任意角**：按逆时针方向旋转形成的角为正角，顺时针为负角，不旋转为零角
- **象限角**：把角放在坐标系中，顶点在原点、始边与 x 轴正半轴重合，终边在第几象限就叫第几象限角
- **终边相同的角**：β = α + k·360°（k ∈ ℤ）；弧度制下 β = α + 2kπ（k ∈ ℤ）
- **弧度定义**：弧长等于半径的弧所对的圆心角为 1 弧度；α = l/r
- **换算**：180° = π 弧度；1° = π/180；1 弧度 = 180/π ≈ 57.3°
- **弧长与扇形面积**：l = |α|r；S = ½|α|r² = ½lr

**适用条件**：公式中的 α 必须用**弧度**；求 α/2 的象限时，要按 k 的奇偶分类讨论。

**易错边界**

1. 写终边相同的角漏掉 k ∈ ℤ
2. 度与弧度混用，直接把 60 代进 l = |α|r
3. 求 α/2 的象限只除以 2，不讨论 k 的奇偶

### 例题 1 · L1 基础

把 67°30′ 化为弧度。

**解析**：

1. 先统一成度：67°30′ = 67.5° = 135/2 度
2. 乘换算系数：67.5° × π/180 = 135π/360 = **3π/8**

**💥 陷阱**：把 30′ 当成 0.3°，写成 67.3°——角度是 60 进制，30′ = 0.5°。

**变式**：把 -π/12 化为角度。（-15°）

### 例题 2 · L2 常考

已知扇形的半径为 6，圆心角为 60°，求它的弧长和面积。

**解析**：

1. 先把圆心角化为弧度：60° = π/3
2. 弧长 l = |α|r = (π/3) × 6 = **2π**
3. 面积 S = ½|α|r² = ½ × (π/3) × 36 = **6π**

**💥 陷阱**：直接把 60 代进公式，得 l = 360，量级完全不对。

**变式**：扇形半径为 3，弧长为 2π，求圆心角与面积。（α = 2π/3，S = 3π）

### 例题 3 · L3 综合

已知 α 是第二象限角，判断 α/2 是第几象限角。

**解析**：

1. α 是第二象限角：2kπ + π/2 < α < 2kπ + π（k ∈ ℤ）
2. 两边除以 2：kπ + π/4 < α/2 < kπ + π/2
3. 当 k 为偶数，设 k = 2n：2nπ + π/4 < α/2 < 2nπ + π/2，α/2 是**第一象限角**
4. 当 k 为奇数，设 k = 2n + 1：2nπ + 5π/4 < α/2 < 2nπ + 3π/2，α/2 是**第三象限角**
5. 所以 α/2 是第一或第三象限角

**💥 陷阱**：只算 π/4 < α/2 < π/2 就答"第一象限"，把 kπ 的平移整个丢了。

**变式**：若 α 是第三象限角，α/2 是第几象限角？（第二或第四象限）

### ⏱️ 限时挑战（60 秒）

① 180° 等于多少弧度？② 写出与 60° 终边相同的所有角组成的集合。

> 答案：① π　② β = 60° + k·360°（k ∈ ℤ）

## A-6.2 三角比与同角关系、诱导公式

*三角比 › 必修二 第6章 ｜ Ⅱ · 考频**高** ｜ 前置 A-6.1 ｜ 关联 A-6.3　★*

**⚡ 先猜**：sin 150° = sin 30° 吗？

### 30 秒概述

任意角的三角比用**终边上点的坐标**定义：sin α = y/r，cos α = x/r，tan α = y/x。符号看象限，大小看锐角。两组工具必须背熟：**同角关系**（sin²α + cos²α = 1、tan α = sin α/cos α）和**诱导公式**（把任意角化到锐角）。

### 30 秒自评

1. sin²30° + cos²30° = 1。
2. tan 90° 有意义。
3. sin(180° − α) = sin α。

> **答案**：1. ✓　2. ✗（cos 90° = 0，tan 90° 无意义）　3. ✓

### 🔑 原理与公式

- **定义**：角 α 终边上取一点 P(x, y)，r = √(x² + y²) > 0，则 sin α = y/r，cos α = x/r，tan α = y/x（x ≠ 0）
- **单位圆**：终边与单位圆交于 (cos α, sin α)
- **符号**：一全正、二正弦、三正切、四余弦
- **同角关系**：sin²α + cos²α = 1；tan α = sin α/cos α（cos α ≠ 0）
- **诱导公式**：
  - sin(-α) = -sin α，cos(-α) = cos α
  - sin(π − α) = sin α，cos(π − α) = -cos α
  - sin(π + α) = -sin α，cos(π + α) = -cos α
  - sin(2π − α) = -sin α，cos(2π − α) = cos α
  - sin(π/2 − α) = cos α，cos(π/2 − α) = sin α
- **口诀**：奇变偶不变，符号看象限（把 α 当锐角，看原角所在象限）

**适用条件**：tan α 要求 cos α ≠ 0；由 sin α 求 cos α 时要先判断象限定符号。

**易错边界**

1. 开平方求 cos α 时不判象限，丢掉负号
2. 诱导公式的符号判断错，没把 α 当锐角检验
3. 把 sin²α 写成 sin α²

### 例题 1 · L1 基础

求 sin 210°、cos 240°、tan 225° 的值。

**解析**：

1. sin 210° = sin(180° + 30°) = -sin 30° = **-1/2**
2. cos 240° = cos(180° + 60°) = -cos 60° = **-1/2**
3. tan 225° = tan(180° + 45°) = tan 45° = **1**

**💥 陷阱**：只看 210°、240° 里的 30°、60°，忘了第三象限的符号。

**变式**：求 sin 300°。（-√3/2）

### 例题 2 · L2 常考

已知 sin α = 3/5，且 α 是第二象限角，求 cos α 与 tan α。

**解析**：

1. 由 sin²α + cos²α = 1：cos²α = 1 − (3/5)² = 16/25
2. 开方得 cos α = ±4/5
3. α 在第二象限，cos α < 0，取 **cos α = -4/5**
4. tan α = sin α/cos α = (3/5) ÷ (-4/5) = **-3/4**

**💥 陷阱**：开方后不判象限，直接取正号，得到 cos α = 4/5。

**变式**：已知 cos α = -4/5，α 是第三象限角，求 sin α 与 tan α。（sin α = -3/5，tan α = 3/4）

### 例题 3 · L3 综合

化简 [sin(π − α) · cos(2π − α)] / [cos(π + α) · sin(-α)]。

**解析**：

1. sin(π − α) = sin α
2. cos(2π − α) = cos α
3. cos(π + α) = -cos α
4. sin(-α) = -sin α
5. 分子 = sin α · cos α，分母 = (-cos α) · (-sin α) = sin α · cos α
6. 原式 = **1**

**💥 陷阱**：分母里两个负号只处理一个，算成 -1。

**变式**：已知 tan α = 2，求 (sin α + cos α)/(sin α − cos α)。（分子分母同除以 cos α，得 (tan α + 1)/(tan α − 1) = 3）

### ⏱️ 限时挑战（60 秒）

① sin²α + cos²α 等于多少？② sin(π + α) 等于什么？

> 答案：① 1　② -sin α

## A-6.3 两角和差与二倍角公式

*三角比 › 必修二 第6章 ｜ Ⅱ · 考频**高** ｜ 前置 A-6.2 ｜ 关联 A-6.4　★*

**⚡ 先猜**：sin(α + β) = sin α + sin β 吗？

### 30 秒概述

和差角公式回答"两个角的三角比如何合成一个角"，二倍角公式是它的特例，辅助角公式把 **a sin α + b cos α** 收成一个正弦。这一节的套路是：**凑角、降幂、合并**。

### 30 秒自评

1. cos(α − β) = cos α cos β + sin α sin β。
2. sin 2α = 2 sin α。
3. a sin α + b cos α 可以化成 √(a² + b²) sin(α + φ) 的形式。

> **答案**：1. ✓　2. ✗（sin 2α = 2 sin α cos α）　3. ✓

### 🔑 原理与公式

- **和差余弦**：cos(α − β) = cos α cos β + sin α sin β；cos(α + β) = cos α cos β − sin α sin β
- **和差正弦**：sin(α ± β) = sin α cos β ± cos α sin β
- **和差正切**：tan(α ± β) = (tan α ± tan β)/(1 ∓ tan α tan β)
- **二倍角**：sin 2α = 2 sin α cos α；tan 2α = 2tan α/(1 − tan²α)
- **二倍角余弦**：cos 2α = cos²α − sin²α = 2cos²α − 1 = 1 − 2sin²α
- **降幂**：sin²α = (1 − cos 2α)/2；cos²α = (1 + cos 2α)/2
- **辅助角**：a sin α + b cos α = √(a² + b²) sin(α + φ)，其中 tan φ = b/a
- **半角**：sin(α/2) = ±√((1 − cos α)/2)，cos(α/2) = ±√((1 + cos α)/2)，符号由半角所在象限决定

**适用条件**：tan 的公式要求分母不为 0；半角公式的 ± 号由半角象限决定，不能想当然取正。

**易错边界**

1. 把 sin(α + β) 拆成 sin α + sin β
2. 二倍角余弦选错形式，求值越算越繁
3. 辅助角的 φ 位置算错，把 b/a 写成 a/b

### 例题 1 · L1 基础

求 sin 75° 的值。

**解析**：

1. 拆角：75° = 45° + 30°
2. 用和角正弦：sin 75° = sin 45° cos 30° + cos 45° sin 30°
3. 代入特殊值：(√2/2)(√3/2) + (√2/2)(1/2) = (√6 + √2)/4
4. 所以 **sin 75° = (√6 + √2)/4**

**💥 陷阱**：写成 sin 45° + sin 30°，把"和的正弦"当成"正弦的和"。

**变式**：求 cos 15° 的值。（(√6 + √2)/4）

### 例题 2 · L2 常考

已知 sin α = 3/5，α ∈ (π/2, π)，求 sin 2α 与 cos 2α。

**解析**：

1. α 在第二象限，cos α < 0；由 sin²α + cos²α = 1 得 cos α = -4/5
2. sin 2α = 2 sin α cos α = 2 × (3/5) × (-4/5) = **-24/25**
3. cos 2α = 1 − 2sin²α = 1 − 2 × 9/25 = **7/25**

**💥 陷阱**：忽略 α 在第二象限，把 cos α 取成 4/5，sin 2α 的符号就反了。

**变式**：求 tan 2α。（tan α = -3/4，tan 2α = 2tan α/(1 − tan²α) = -24/7）

### 例题 3 · L3 综合

求函数 y = sin x + √3 cos x 的最大值，并求取得最大值时 x 的集合。

**解析**：

1. 用辅助角公式：a = 1，b = √3，√(a² + b²) = 2
2. y = 2(½ sin x + (√3/2) cos x) = 2 sin(x + π/3)
3. 正弦的最大值是 1，所以 y 的最大值是 **2**
4. 取得最大值时 x + π/3 = π/2 + 2kπ，即 **x = π/6 + 2kπ（k ∈ ℤ）**

**💥 陷阱**：辅助角写成 π/6——把 sin x 的系数与 cos x 的系数对调，φ 就错了。

**变式**：求 y = √3 sin x − cos x 的最大值及取得最大值时 x 的集合。（y = 2 sin(x − π/6)，最大值 2，此时 x = 2π/3 + 2kπ）

### ⏱️ 限时挑战（60 秒）

① 写出 cos 2α 的三个等价形式。② tan 45° 等于多少？

> 答案：① cos²α − sin²α、2cos²α − 1、1 − 2sin²α　② 1

## A-6.4 解三角形

*三角比 › 必修二 第6章 ｜ Ⅱ · 考频**高** ｜ 前置 A-6.3 ｜ 关联 A-7.1　★*

**⚡ 先猜**：已知两边和其中一边的对角，三角形一定唯一确定吗？

### 30 秒概述

解三角形就是"由已知的边和角求其余的边和角"。两件武器：**正弦定理**处理"对角"关系，**余弦定理**处理"三边与夹角"关系；面积用 **S = ½ab sin C**。

### 30 秒自评

1. 在 △ABC 中，a/sin A = b/sin B。
2. 余弦定理：a² = b² + c² − 2bc cos A。
3. △ABC 的面积 S = ab sin C。

> **答案**：1. ✓　2. ✓　3. ✗（漏了 ½）

### 🔑 原理与公式

- **正弦定理**：a/sin A = b/sin B = c/sin C = 2R（R 为外接圆半径）
- **正弦定理变形**：a = 2R sin A；sin A : sin B : sin C = a : b : c
- **余弦定理**：a² = b² + c² − 2bc cos A；cos A = (b² + c² − a²)/(2bc)
- **面积公式**：S = ½ab sin C = ½bc sin A = ½ac sin B
- **内角和**：A + B + C = π
- **解的情况**（已知 a、b、A）：a ≥ b 时一解；a < b 时比较 a 与 b sin A——a = b sin A 一解，a > b sin A 两解，a < b sin A 无解

**适用条件**：正弦定理适合"两角一边""两边及一边对角"；余弦定理适合"三边""两边及夹角"；大边对大角。

**易错边界**

1. 用正弦定理求角时只取锐角，漏掉钝角解
2. 余弦定理求角时分子里的减号写成加号
3. 面积公式漏掉 ½

### 例题 1 · L1 基础

在 △ABC 中，A = 30°，B = 45°，a = 2，求 b。

**解析**：

1. 用正弦定理：b/sin B = a/sin A
2. b = a sin B / sin A = 2 × (√2/2) / (1/2) = **2√2**

**💥 陷阱**：把比例写反，算成 b = a sin A / sin B。

**变式**：若 a = 2，A = 30°，C = 105°，求 c。（c = a sin C / sin A = 4 sin 105° = √6 + √2）

### 例题 2 · L2 常考

在 △ABC 中，a = 3，b = 4，C = 60°，求 c 与 △ABC 的面积。

**解析**：

1. 用余弦定理：c² = a² + b² − 2ab cos C = 9 + 16 − 2 × 3 × 4 × (1/2) = 13
2. 所以 **c = √13**
3. 面积 S = ½ab sin C = ½ × 3 × 4 × (√3/2) = **3√3**

**💥 陷阱**：余弦定理里写成 +2ab cos C，得到 c² = 37。

**变式**：若 a = 3，b = 4，c = √13，求 C。（cos C = (9 + 16 − 13)/(2 × 3 × 4) = 1/2，C = 60°）

### 例题 3 · L3 综合

在 △ABC 中，a = √3，b = √2，B = 45°，求 A 与 C。

**解析**：

1. 用正弦定理：sin A = a sin B / b = √3 × (√2/2) / √2 = √3/2
2. 所以 A = 60° 或 A = 120°
3. 检验：A = 60° 时 C = 75°；A = 120° 时 C = 15°；两组都满足 A + B < 180°
4. 所以有两组解：**A = 60°，C = 75°** 或 **A = 120°，C = 15°**

**💥 陷阱**：看到 sin A = √3/2 就只写 A = 60°，把钝角解丢了。

**变式**：若 a = √2，b = √3，B = 60°，求 A。（sin A = √2/2，A = 45° 或 135°；A = 135° 时 A + B > 180°，舍去，故 A = 45°）

### ⏱️ 限时挑战（60 秒）

① 写出正弦定理的比例式。② 写出用两边及夹角表示三角形面积的公式。

> 答案：① a/sin A = b/sin B = c/sin C　② S = ½ab sin C
