## A-3.1 幂与指数

*幂指对 › 必修一 第3章 ｜ Ⅱ · 考频**高** ｜ 前置 A-2.3 ｜ 关联 A-3.2*

**⚡ 先猜**：a⁰ = 1 对 a = 0 也成立吗？

### 30 秒概述

指数运算法则：**aᵐ·aⁿ = aᵐ⁺ⁿ**、**(aᵐ)ⁿ = aᵐⁿ**、**(ab)ⁿ = aⁿbⁿ**，其中 a > 0。负指数 **a⁻ⁿ = 1/aⁿ**，分数指数 **a^(m/n) = ⁿ√(aᵐ)**。

### 30 秒自评

1. aᵐ·aⁿ = aᵐ⁺ⁿ。
2. a⁰ = 1 对任意 a 成立。
3. a^(1/2) = √a。

> **答案**：1. ✓　2. ✗（a ≠ 0）　3. ✓（a ≥ 0）

### 🔑 原理与公式

- **aᵐ·aⁿ = aᵐ⁺ⁿ**，**aᵐ/aⁿ = aᵐ⁻ⁿ**
- **(aᵐ)ⁿ = aᵐⁿ**，**(ab)ⁿ = aⁿbⁿ**
- **a^(m/n) = ⁿ√(aᵐ)**（a > 0）
- **a⁻ⁿ = 1/aⁿ**

**适用条件**：底数 a > 0；分数指数要求 a ≥ 0。

**易错边界**

1. 把 (aᵐ)ⁿ 与 aᵐ·aⁿ 混淆
2. 负指数写成负数
3. 忽略底数必须为正

### 例题 1 · L1 基础

计算 8^(2/3)。

**解析**：8^(2/3) = (2³)^(2/3) = 2² = **4**

**💥 陷阱**：算成 8² / 3。

**变式**：27^(2/3)？（9）

### 例题 2 · L2 常考

化简 (a^(1/2) · b^(-1/3))⁶（a, b > 0）。

**解析**：(a^(1/2))⁶ · (b^(-1/3))⁶ = **a³b⁻²** = a³/b²

**💥 陷阱**：指数没相乘。

**变式**：a^(1/3) · a^(1/6)？（a^(1/2)）

### 例题 3 · L3 综合

已知 a + a⁻¹ = 3，求 a² + a⁻²。

**解析**：两边平方：a² + 2 + a⁻² = 9 ⇒ a² + a⁻² = **7**

**💥 陷阱**：直接平方得 9。

**变式**：a - a⁻¹ 的值？（±√5）

### ✅ 接下来做什么

- **3 道全对** → 例题 3 + 变式。
- **对 2 道** → 例题 2、3。
- **对 0–1 道** → 顺序做。

> **过关线**：期中做到例题 2｜期末做到例题 3。

## A-3.2 对数

*幂指对 › 必修一 第3章 ｜ Ⅱ · 考频**高** ｜ 前置 A-3.1 ｜ 关联 A-4.3　★*

**⚡ 先猜**：log₂(-4) 有意义吗？

### 30 秒概述

**aᵇ = N ⟺ b = logₐN**（a > 0, a ≠ 1, N > 0）。运算：**logₐ(MN) = logₐM + logₐN**、**logₐ(M/N) = logₐM - logₐN**、**logₐMⁿ = n·logₐM**。换底：**logₐb = log_c b / log_c a**。

### 30 秒自评

1. logₐ(MN) = logₐM · logₐN。
2. logₐ1 = 0。
3. 真数可以为负数。

> **答案**：1. ✗（是相加）　2. ✓　3. ✗（必须大于 0）

### 🔑 原理与公式

- **aᵇ = N ⟺ logₐN = b**
- **logₐ(MN) = logₐM + logₐN**
- **logₐMⁿ = n logₐM**
- **logₐb = log_c b / log_c a**

**适用条件**：a > 0 且 a ≠ 1；真数 > 0。

**易错边界**

1. 把乘法法则当成相乘
2. 忽略真数为正
3. 换底公式分子分母颠倒

### 例题 1 · L1 基础

计算 log₂8 + log₂(1/4)。

**解析**：log₂8 = 3，log₂(1/4) = -2 ⇒ 和为 **1**

**💥 陷阱**：算成 3 + 2。

**变式**：log₃9 + log₃(1/3)？（1）

### 例题 2 · L2 常考

计算 log₄8。

**解析**：换底：log₄8 = log₂8 / log₂4 = 3/2 = **1.5**

**💥 陷阱**：写成 2。

**变式**：log₉27？（1.5）

### 例题 3 · L3 综合

解方程 log₂(x - 1) + log₂(x + 3) = 3。

**解析**：

1. 合并：log₂((x-1)(x+3)) = 3 ⇒ (x-1)(x+3) = 8
2. x² + 2x - 11 = 0 ⇒ x = -1 ± 2√3
3. 需 x - 1 > 0 且 x + 3 > 0 ⇒ 取 **x = -1 + 2√3**

**💥 陷阱**：忘记检验定义域。

**变式**：若 log₂(x-1) = 2，x = ？（5）

- **对 0–1 道** → 顺序做。
