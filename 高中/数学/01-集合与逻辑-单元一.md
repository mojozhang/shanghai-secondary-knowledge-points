## A-1.1 集合初步

*集合与逻辑 › 必修一 第1章 ｜ Ⅱ · 考频**高** ｜ 前置 无 ｜ 关联 A-1.2　★*

**⚡ 先猜**：空集是任何集合的子集吗？

### 30 秒概述

集合是确定的、互异的对象的整体。三个运算：**交集 A ∩ B**（公共部分）、**并集 A ∪ B**（合起来）、**补集 ∁ᵤA**（全集中去掉 A）。子集关系 **A ⊆ B**，真子集 **A ⊂ B**。

### 30 秒自评

1. ∅ 是任何集合的子集。
2. 若 A ⊆ B 且 B ⊆ A，则 A = B。
3. ∅ 是任何集合的真子集。

> **答案**：1. ✓　2. ✓　3. ✗（∅ 不是自身的真子集）

### 🔑 原理与公式

- **A ⊆ B ⟺ 任意 x ∈ A 都有 x ∈ B**
- **A ∪ B**：由属于 A **或** 属于 B 的元素组成
- **A ∩ B**：由**同时**属于 A 和 B 的元素组成
- 含 n 个元素的集合有 **2ⁿ** 个子集

**适用条件**：集合元素满足确定性、互异性、无序性。

**易错边界**

1. 忘记 ∅ 是子集
2. 求补集时没考虑全集
3. 忽略互异性导致重复计数

### 例题 1 · L1 基础

A = {1, 2, 3}，B = {2, 3, 4}。求 A ∩ B、A ∪ B。

**解析**：A ∩ B = **{2, 3}**；A ∪ B = **{1, 2, 3, 4}**

**💥 陷阱**：并集漏掉或重复元素。

**变式**：A 为所有大于 1 的实数，B 为所有小于 3 的实数，求 A ∩ B。（1 < x < 3）

### 例题 2 · L2 常考

集合 A = {1, 2} 的子集有几个？真子集几个？

**解析**：子集 **2² = 4** 个：∅、{1}、{2}、{1,2}；真子集 **3** 个（去掉自身）。

**💥 陷阱**：把真子集也算成 4 个。

**变式**：含 4 个元素的集合有几个子集？（16 个）

### 例题 3 · L3 综合

已知 A 是 -1 ≤ x ≤ 3 的全体实数，B 是 x > a 的全体实数，若 A ⊆ B，求 a 的取值范围。

**解析**：

1. A ⊆ B 要求 A 中每个元素都满足 x > a
2. 即 a < A 的最小值 -1
3. 故 **a < -1**

**💥 陷阱**：写成 a ≤ -1（当 a = -1 时 -1 ∉ B）。

**变式**：若 A ∩ B = ∅，a 的范围？（a ≥ 3）

### ⏱️ 限时挑战（60 秒）

① 含 3 个元素的集合有几个子集？② A ⊆ B 且 B ⊆ A 说明什么？

> 答案：① 8 个　② A = B

## A-1.2 常用逻辑用语

*集合与逻辑 › 必修一 第1章 ｜ Ⅱ · 考频**高** ｜ 前置 A-1.1 ｜ 关联 A-2.1　★*

**⚡ 先猜**：「所有」的否定是「所有都不」吗？

### 30 秒概述

命题分**全称命题**（∀）与**存在命题**（∃）。否定规则：**∀ 变 ∃、∃ 变 ∀，结论取反**。充分必要条件：**p ⇒ q** 则 p 是 q 的充分条件，q 是 p 的必要条件。

### 30 秒自评

1. 全称命题的否定是存在命题。
2. 若 p ⇒ q，则 p 是 q 的必要条件。
3. 「所有 x 都成立」的否定是「所有 x 都不成立」。

> **答案**：1. ✓　2. ✗（充分条件）　3. ✗（是「存在 x 不成立」）

### 🔑 原理与公式

- 全称：**∀x ∈ M, p(x)**
- 存在：**∃x ∈ M, p(x)**
- 否定：**¬(∀x, p) = ∃x, ¬p**；**¬(∃x, p) = ∀x, ¬p**
- p ⇒ q：p 充分，q 必要；p ⟺ q：充要

**适用条件**：命题在给定范围内讨论。

**易错边界**

1. 否定时只改结论不改量词
2. 混淆充分与必要
3. 把「不都」与「都不」混为一谈

### 例题 1 · L1 基础

写出「所有实数的平方都大于 0」的否定。

**解析**：**存在实数，其平方不大于 0**。（∃x ∈ ℝ, x² ≤ 0）

**💥 陷阱**：写成「所有实数的平方都不大于 0」。

**变式**：「存在 x 使 x² = 2」的否定？（对所有 x，x² ≠ 2）

### 例题 2 · L2 常考

「x > 2」是「x > 1」的什么条件？

**解析**：

1. x > 2 ⇒ x > 1，所以是**充分条件**
2. x > 1 ⇏ x > 2（如 x = 1.5），所以不是必要条件
3. 结论：**充分不必要条件**

**💥 陷阱**：方向判断反了。

**变式**：「x = 0」是「x² = 0」的什么条件？（充要）

### 例题 3 · L3 综合

已知 p：x² - 3x + 2 > 0，q：x > 2。
(1) p 是 q 的什么条件？
(2) 说明理由。

**解析**：

1. (1) **必要不充分条件**
2. (2) x² - 3x + 2 > 0 的解为 x < 1 或 x > 2；q 的范围 {x > 2} 是 p 的真子集
3. 即 q ⇒ p 但 p ⇏ q

**💥 陷阱**：只解不等式不比较范围包含关系。

**变式**：若 p 是 q 的充分条件，两者的解集什么关系？（p 的解集 ⊆ q 的解集）

### ⏱️ 限时挑战（60 秒）

① ∀ 的否定怎么写？② p ⇒ q 时 p 是什么条件？

> 答案：① ∃ 且结论取反　② 充分条件
