## A-7.1 正弦函数、余弦函数的图像与性质

*三角函数 › 必修二 第7章 ｜ Ⅱ · 考频**高** ｜ 前置 A-6.2 ｜ 关联 A-7.2　★*

**⚡ 先猜**：y = sin x 的对称轴是 x = kπ 吗？

### 30 秒概述

正弦、余弦是刻画**周期现象**的基本函数。图像用**五点法**画：一个周期内定出五个关键点，再用光滑曲线连起来。它们的周期都是 **2π**，正弦是奇函数，余弦是偶函数，单调区间、最值、对称性都要按"**加 2kπ**"写全。

### 30 秒自评

1. y = sin x 的最小正周期是 2π。
2. y = cos x 是奇函数。
3. y = sin x 在 [π/2, 3π/2] 上单调递减。

> **答案**：1. ✓　2. ✗（是偶函数）　3. ✓

### 🔑 原理与公式

- **五点法**（y = sin x，x ∈ [0, 2π]）：(0, 0)、(π/2, 1)、(π, 0)、(3π/2, -1)、(2π, 0)
- **周期**：y = sin(ωx + φ) 与 y = cos(ωx + φ) 的最小正周期 T = 2π/|ω|
- **奇偶性**：y = sin x 是奇函数，y = cos x 是偶函数
- **单调性**：
  - sin x：增区间 [-π/2 + 2kπ, π/2 + 2kπ]，减区间 [π/2 + 2kπ, 3π/2 + 2kπ]
  - cos x：增区间 [-π + 2kπ, 2kπ]，减区间 [2kπ, π + 2kπ]
- **最值**：sin x 在 x = π/2 + 2kπ 取 1，在 x = -π/2 + 2kπ 取 -1；cos x 在 x = 2kπ 取 1，在 x = π + 2kπ 取 -1
- **对称性**：sin x 的对称中心是 (kπ, 0)，对称轴是 x = π/2 + kπ；cos x 的对称中心是 (π/2 + kπ, 0)，对称轴是 x = kπ

**适用条件**：求单调区间时先把 ω 化为正；复合函数用整体代换，别把 x 的系数丢了。

**易错边界**

1. 单调区间漏写 2kπ，只写一个周期
2. 把 sin 与 cos 的单调区间记混
3. 对称轴与对称中心搞反

### 例题 1 · L1 基础

求 y = 2 sin x + 1 的最大值、最小值，以及取得最值时 x 的集合。

**解析**：

1. sin x 的最大值是 1，此时 y = 2 × 1 + 1 = **3**
2. 取得最大值时 x = π/2 + 2kπ（k ∈ ℤ）
3. sin x 的最小值是 -1，此时 y = 2 × (-1) + 1 = **-1**
4. 取得最小值时 x = -π/2 + 2kπ（k ∈ ℤ）

**💥 陷阱**：只写最大值 3，不写取得最值时 x 的集合——题目问的是两件事。

**变式**：求 y = 1 − 3 cos x 的最大值与最小值。（最大值 4，此时 x = π + 2kπ；最小值 -2，此时 x = 2kπ）

### 例题 2 · L2 常考

求 y = sin(2x − π/3) 的单调递增区间。

**解析**：

1. 令 u = 2x − π/3，y = sin u 的增区间是 [-π/2 + 2kπ, π/2 + 2kπ]
2. 即 -π/2 + 2kπ ≤ 2x − π/3 ≤ π/2 + 2kπ
3. 各项加 π/3：-π/6 + 2kπ ≤ 2x ≤ 5π/6 + 2kπ
4. 各项除以 2：**-π/12 + kπ ≤ x ≤ 5π/12 + kπ**（k ∈ ℤ）

**💥 陷阱**：把区间写成 [-π/2, π/2] 后直接当成 x 的范围，忘了先解出 x。

**变式**：求 y = sin(2x − π/3) 的单调递减区间。（5π/12 + kπ ≤ x ≤ 11π/12 + kπ）

### 例题 3 · L3 综合

求函数 y = sin²x + sin x − 1 的值域。

**解析**：

1. 换元：令 t = sin x，则 t ∈ [-1, 1]
2. y = t² + t − 1 = (t + 1/2)² − 5/4
3. 这是开口向上的二次函数，顶点 t = -1/2 在 [-1, 1] 内
4. t = -1/2 时取最小值 **-5/4**；t = 1 时取最大值 1 + 1 − 1 = **1**
5. 所以值域是 **[-5/4, 1]**

**💥 陷阱**：只算两个端点 t = -1 和 t = 1 的函数值，漏掉顶点处的最小值。

**变式**：求 y = cos²x − cos x + 1 的值域。（令 t = cos x ∈ [-1, 1]，y = (t − 1/2)² + 3/4，值域 [3/4, 3]）

### ⏱️ 限时挑战（60 秒）

① y = sin x 的最小正周期是多少？② y = sin x 的对称中心是什么？

> 答案：① 2π　② (kπ, 0)，k ∈ ℤ

## A-7.2 函数 y = A sin(ωx + φ) 的图像

*三角函数 › 必修二 第7章 ｜ Ⅱ · 考频**高** ｜ 前置 A-7.1 ｜ 关联 A-7.3　★*

**⚡ 先猜**：把 y = sin x 的图像先向左平移 π/3、再把横坐标缩短为原来的 1/2，与"先缩短再平移"，结果一样吗？

### 30 秒概述

y = A sin(ωx + φ) 里有三个"旋钮"：**A 管振幅**、**ω 管周期**、**φ 管左右平移**。图像变换的关键是记住：**平移是对 x 本身加减**，所以先伸缩后平移时，平移量要变成 |φ/ω|。

### 30 秒自评

1. y = 3 sin(2x + π/4) 的振幅是 3。
2. y = 3 sin(2x + π/4) 的最小正周期是 π。
3. 把 y = sin x 的图像向左平移 π/3，得到 y = sin(x + π/3)。

> **答案**：1. ✓　2. ✓（T = 2π/2）　3. ✓

### 🔑 原理与公式

- **标准形式**：y = A sin(ωx + φ)，A > 0，ω > 0
- **三个量**：振幅 A；周期 T = 2π/ω；频率 f = 1/T；初相 φ；相位 ωx + φ
- **变换路线一**（先平移后伸缩）：y = sin x → 左移 φ（φ > 0）→ 横坐标变为原来的 1/ω → 纵坐标变为 A 倍
- **变换路线二**（先伸缩后平移）：y = sin x → 横坐标变为 1/ω → 左移 |φ/ω| → 纵坐标变为 A 倍
- **等价写法**：y = A sin[ω(x + φ/ω)]，平移量一目了然
- **求性质**：整体代换，令 u = ωx + φ，先算 u 的范围，再解出 x

**适用条件**：平移只对 x 加减；ω < 0 时先提负号化为正；A 影响值域，不影响周期。

**易错边界**

1. 先伸缩后平移时，平移量仍取 |φ| 而不是 |φ/ω|
2. 周期算成 2π/ω 以外的值
3. 求单调区间时忘了除以 ω

### 例题 1 · L1 基础

求 y = 3 sin(2x + π/4) 的振幅、最小正周期与初相。

**解析**：

1. 对照标准形式：A = 3，ω = 2，φ = π/4
2. 振幅 **A = 3**
3. 周期 **T = 2π/ω = 2π/2 = π**
4. 初相 **φ = π/4**

**💥 陷阱**：周期写成 2π——那是 y = sin x 的周期，ω = 2 时缩短了一半。

**变式**：求 y = 2 sin(x/2 − π/6) 的最小正周期。（T = 2π ÷ (1/2) = 4π）

### 例题 2 · L2 常考

把 y = sin x 图像上各点的横坐标缩短为原来的 1/2（纵坐标不变），再向左平移 π/6，求所得函数的解析式。

**解析**：

1. 横坐标缩短为 1/2：x 的系数变为 2，得 y = sin 2x
2. 向左平移 π/6：把 x 换成 x + π/6，得 y = sin 2(x + π/6)
3. 化简：**y = sin(2x + π/3)**

**💥 陷阱**：直接写成 y = sin(2x + π/6)——平移量没有跟着 ω 一起变。

**变式**：若改为先向左平移 π/6、再把横坐标缩短为原来的 1/2，解析式是什么？（y = sin(2x + π/6)，与上题不同，说明变换顺序会影响结果）

### 例题 3 · L3 综合

已知 f(x) = A sin(ωx + φ)（A > 0，ω > 0，|φ| < π/2），其图像相邻两条对称轴的距离为 π/2，且图像经过点 (π/6, 2) 并在该点取得最大值。
（1）求 f(x) 的解析式；（2）求 f(x) 在 [0, π/2] 上的值域。

**解析**：

1. 相邻两条对称轴的距离是半个周期：T/2 = π/2，故 T = π，ω = 2π/T = 2
2. 最大值是 2，故 A = 2
3. 在 x = π/6 处取最大值：2 × π/6 + φ = π/2 + 2kπ，得 φ = π/6 + 2kπ
4. 由 |φ| < π/2 得 φ = π/6
5. 所以 **f(x) = 2 sin(2x + π/6)**
6. 当 x ∈ [0, π/2] 时，2x + π/6 ∈ [π/6, 7π/6]，sin 的取值范围是 [-1/2, 1]
7. 所以 f(x) 的值域是 **[-1, 2]**

**💥 陷阱**：把"相邻对称轴距离"当成周期，得 T = π/2、ω = 4，后面全错。

**变式**：求 f(x) = 2 sin(2x + π/6) 的单调递减区间。（π/6 + kπ ≤ x ≤ 2π/3 + kπ）

### ⏱️ 限时挑战（60 秒）

① y = A sin(ωx + φ) 的周期公式是什么？② 振幅由哪个字母决定？

> 答案：① T = 2π/ω　② A

## A-7.3 正切函数的图像与性质

*三角函数 › 必修二 第7章 ｜ Ⅱ · 考频**中** ｜ 前置 A-7.2 ｜ 关联 A-8.1*

**⚡ 先猜**：y = tan x 在整个定义域上是增函数吗？

### 30 秒概述

正切函数的图像由**一支一支**的曲线组成，被渐近线 x = π/2 + kπ 隔开。它的定义域是 x ≠ π/2 + kπ，值域是 ℝ，周期是 **π**，是奇函数，在**每个**区间 (-π/2 + kπ, π/2 + kπ) 内严格递增——注意，不能说"在整个定义域上递增"。

### 30 秒自评

1. y = tan x 的最小正周期是 π。
2. y = tan x 是偶函数。
3. y = tan x 在 (-π/2, π/2) 内单调递增。

> **答案**：1. ✓　2. ✗（是奇函数）　3. ✓

### 🔑 原理与公式

- **定义域**：x ≠ π/2 + kπ（k ∈ ℤ）
- **值域**：ℝ
- **周期**：T = π；y = tan(ωx + φ) 的最小正周期 T = π/|ω|
- **奇偶性**：奇函数，图像关于原点对称
- **单调性**：在每个区间 (-π/2 + kπ, π/2 + kπ) 内严格递增
- **零点与渐近线**：零点 x = kπ；渐近线 x = π/2 + kπ
- **对称中心**：(kπ/2, 0)

**适用条件**：单调性只能写在每个连续区间内；定义域要把渐近线所在的位置挖掉。

**易错边界**

1. 说 y = tan x 在定义域上递增
2. 周期写成 2π
3. 对称中心只写 (kπ, 0)，漏掉 (π/2 + kπ, 0)

### 例题 1 · L1 基础

求 y = tan(2x − π/4) 的定义域。

**解析**：

1. 正切有意义的条件：2x − π/4 ≠ π/2 + kπ
2. 移项：2x ≠ 3π/4 + kπ
3. 除以 2：**x ≠ 3π/8 + kπ/2**（k ∈ ℤ）

**💥 陷阱**：只写 x ≠ π/2 + kπ，没有把 2x − π/4 整体代入。

**变式**：求 y = tan(x/2 + π/3) 的定义域。（x ≠ π/3 + 2kπ）

### 例题 2 · L2 常考

求 y = tan(x + π/3) 的最小正周期与单调递增区间。

**解析**：

1. ω = 1，周期 **T = π/1 = π**
2. 增区间：-π/2 + kπ < x + π/3 < π/2 + kπ
3. 各项减 π/3：**-5π/6 + kπ < x < π/6 + kπ**（k ∈ ℤ）

**💥 陷阱**：周期写成 2π；或者解区间时忘了减 π/3。

**变式**：求 y = tan(2x + π/6) 的单调递增区间。（-π/3 + kπ/2 < x < π/6 + kπ/2）

### 例题 3 · L3 综合

解不等式 tan x ≥ 1。

**解析**：

1. 先在一个周期内解：在 (-π/2, π/2) 上，tan x 严格增，且 tan(π/4) = 1
2. 所以 π/4 ≤ x < π/2
3. 加上周期 kπ：**π/4 + kπ ≤ x < π/2 + kπ**（k ∈ ℤ）

**💥 陷阱**：漏掉周期，只写 π/4 ≤ x < π/2；或者右端写成"≤"，把渐近线也算进解集。

**变式**：解不等式 tan x ≤ -1。（-π/2 + kπ < x ≤ -π/4 + kπ）

### ⏱️ 限时挑战（60 秒）

① y = tan x 的最小正周期是多少？② 它的定义域是什么？

> 答案：① π　② x ≠ π/2 + kπ（k ∈ ℤ）
