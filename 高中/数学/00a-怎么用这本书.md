# 怎么用这本书

## 一张卡片长什么样

每个考点一张卡片，固定 8 个部分，从上往下读就行：

| 部分 | 是什么 | 要不要全看 |
|---|---|---|
| **编号 + 名称** | 如 `A-4.1 幂函数` | — |
| **灰色小字** | 所在章节、Ⅰ/Ⅱ 要求、考频、前置与关联考点 | 可跳过 |
| **⚡ 先猜** | 一道反直觉的小问题，**故意不给答案** | 建议做，30 秒 |
| **30 秒概述** | 几句话讲清"这个东西解决什么问题" | 必看 |
| **30 秒自评** | 3 道判断题或小计算，答案紧跟其后 | 必做，2 分钟 |
| **原理与公式 / 适用条件 / 易错边界** | 正文，公式都在这里 | 按自评结果决定 |
| **例题 1 / 2 / 3** | 难度递增：基础 → 常考 → 综合，每题带陷阱和变式 | 看年级 |
| **⏱️ 限时挑战 + ✅ 接下来做什么** | 60 秒小测，再按"对了几道"告诉你下一步 | 必看 |

## 标记图例

| 标记 | 含义 |
|---|---|
| **Ⅰ / Ⅱ** | 合格考要求 / 等级考要求 |
| **高 / 中 / 低** | 近 5 年上海高考的考查频率 |
| **★** | 本章重点考点，自评不理想时必须学 |
| **L1 / L2 / L3** | 例题难度：L1 高一同步、L2 高二复习、L3 高三冲刺 |
| **⚡ 先猜** | 卡片最前面的小节，一道反直觉的问题，故意不给答案 |
| **💥 陷阱** | 例题解析里指出"最容易错在哪一步"的那段 |
| **变式** | 例 3 后面换条件的小题，能做对才算真会 |
| **⏱️ 限时挑战** | 每个考点末尾 60 秒 2 题，专门练速度 |

## 三个年级怎么用

| 年级 | 建议做法 | 每页花多久 |
|---|---|---|
| **高一** | 跟着教材进度，看概述 + 自评 + 原理，做例题 1；例题 2 挑着做 | 10–15 分钟 |
| **高二** | 全看，重点啃"易错边界"，做例题 1、2，把三角与函数串起来 | 20–25 分钟 |
| **高三** | 跳过概述，直接自评；全对就只做例题 3 + 变式 | 8–12 分钟 |

## 一个考点的完整闭环

1. **先猜**（30 秒）：带着悬念往下读，猜错了更好，说明这里有东西可学。
2. **30 秒自评**（3 题）：做完数一数对了几道，别急着看答案。
3. **按结果做题**：
   - 3 道全对 → 直接做例题 3 + 变式，全对才进下一个考点；
   - 对 2 道 → 读"易错边界"，做例题 2、3；
   - 对 0–1 道 → 从"原理与公式"顺序学到例题 3。
4. **限时挑战**（60 秒）：只练已学内容的熟练度，不出新题；超时也做完，不记分。
5. **错了就回炉**：遮住解析重做一遍，隔天再做一次，隔三天换个数字再做一次。

## 三条使用建议

1. **不要从第一页读到最后一页。** 每张卡片都是独立的，先做自评，再决定读多少。
2. **例题的答案不要提前看。** 遮住解析做一遍，再对照"陷阱"检查自己是不是也那么想的。
3. **错题比新题值钱。** 同一道错题隔天重做、隔三天换数字再做，比刷十道新题有用。

## 版本说明

- 教材依据：上海教育出版社 2020 版 必修第一、二、三册（第 1–13 章）
- 考试依据：上海高考数学（满分 150 分）
- 记号约定：区间用 (a, b)、[a, b]；集合用 {x | …}；角度与弧度按教材写法，弧度制下省略"弧度"二字
- 取值约定：特殊角 sin30° = 1/2、sin45° = √2/2、sin60° = √3/2；tan30° = √3/3、tan45° = 1、tan60° = √3
