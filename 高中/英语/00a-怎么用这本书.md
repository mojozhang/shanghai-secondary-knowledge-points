# 怎么用这本书

## 一张卡片长什么样

一个 Unit 一张卡，固定 14 段，从上往下读就行：

| 部分 | 是什么 | 要不要全看 |
|---|---|---|
| **标题 + 灰色斜体行** | 如 `E-4.2 Making a difference`，后面是册/Unit、层级、话题、语法、词数 | 可跳过 |
| **⚡ 先猜** | 一句中式英语错句，**故意不给答案** | 建议做，30 秒 |
| **30 秒概述** | 三句话：本单元话题、语法主线、写作任务 | 必看 |
| **30 秒自评** | 3 道题（词义 / 语法 / 短语），答案紧跟其后 | 必做，2 分钟 |
| **🔑 核心词汇（10）** | 本单元最该记住的 10 个词，带搭配和例句 | 必看 |
| **🧩 短语与搭配（8）** | 背短语比背单词更贴高考 | 必看 |
| **📐 语法** | 结构式 + 形式表 + 易错边界 + 3 个练习 | 按自评结果决定 |
| **✍️ 写作** | 结构模板 + 5 个能整句背下来就用的句式 | 考前重点 |
| **📖 阅读技能** | 一条策略 + 一个操作动作 | 3 分钟 |
| **例题 1 / 2 / 3** | 词汇 → 语法 → 翻译，难度递增，每题带陷阱和变式 | 看年级 |
| **⏱️ 限时挑战** | 60 秒 3 小问，只练熟练度 | 建议做 |
| **✅ 接下来做什么** | 按自评对了几道，告诉你下一步走哪 | 必看 |
| **🧠 本单元必背 10 词** | 一行 10 个词，对应默写本里的那一页 | 每天默 |

| 标记 | 含义 |

## 三个年级怎么用

| 年级 | 建议做法 | 每张卡花多久 |
|---|---|---|
| **高一** | 跟着教材进度：概述 + 自评 + 核心词 + 短语，做例题 1；语法表读一遍 | 15 分钟 |
| **高二** | 全看，重点啃"易错边界"和写作句式，做例题 2；开始打 D0–D+7 的勾 | 20 分钟 |
| **高三** | 跳过概述，直接自评；全对就只做例题 3 + 变式，重点刷错词表 | 8–10 分钟 |

## 5 个勾怎么打（这是本书的核心）

单词表一行一个词：**左边英文 + 词性 ｜ 中间 5 个方框 ｜ 右边中文 + 词性**。

```
abandon  v.        ☐ ☐ ☐ ☐ ☐        放弃；抛弃  v.
```

- **盖住右边** → 英译中；**盖住左边** → 中译英。方向要交替，不能只做一个方向。
- 5 个方框不是"打五次"，而是 **5 个复习节点**：`D0 / D+1 / D+3 / D+7 / D+15`。
- 每次**双向都对**才打一个勾；哪一次没过，回到第 1 格重来。
- 5 个勾全满，这个词才算"背出来了"。
- 书末附一张可剪的**遮挡条**和一张**错词登记表**；HTML 版可以直接点方框，进度存在本机。

建议节奏：今天新词打 D0，明天复习打 D+1，第 4 天 D+3，第 8 天 D+7，第 16 天 D+15。每天新词 20–30 个就够，别贪多。

## 故事怎么读

每册词表前面有一篇英文故事，拆成 4 章，**一章正好对应一个 Unit 的词**，目标词加粗（如 `**kidnap**ped`，加粗的 `kidnap` 就是词表里的原形）。

读法：

1. 先通读一章，**不查词**，靠上下文猜；
2. 读完对照本章词表，把没认出来的词标出来；
3. 第二天再读一遍这一章，这次要求"看到加粗词就能说出中文"；
4. 读完一章，正好把这一章的词表默一遍。

故事的作用是"让词在语境里出现一次"，不是精读材料；读不懂的句子跳过，别停下来抠语法。

## 词汇默写本怎么用

单独一本，只有词表和故事，专门用来天天默：

- **单元词表**：跟着课走，本周学哪个 Unit 就默哪几页；
- **全书总表**：按字母排、去重，标了首现单元，适合月考/期末前滚动复习；
- **错词页**：任何一格没打上的词抄到这里，考前只看这一页；
- 打印建议：A4 单面，方框留白足够大，别缩印。

## 一周怎么安排（参考）

| 时间 | 做什么 | 多久 |
|---|---|---|
| 周一 | 新单元卡：概述 + 自评 + 核心词 + 短语，打 D0 | 20 分钟 |
| 周二 | 语法 + 写作句式，做例题 1、2；D+1 复习 | 20 分钟 |
| 周三 | 例题 3 + 变式；读本章故事 | 20 分钟 |
| 周四 | 默写本：本单元词表，双向各一遍 | 15 分钟 |
| 周五 | 限时挑战 + 错词回炉 | 15 分钟 |
| 周末 | 总表滚动复习（只抽错词 + 上周的词） | 20 分钟 |

## 三条使用建议

1. **不要从第一页读到最后一页。** 先自评，再决定读多少；全对就只做例题 3 + 变式。
2. **例题的答案不要提前看。** 遮住解析做一遍，再对照"陷阱"看自己是不是也那么想的。
3. **错词比新词值钱。** 同一个词错三次，说明它该进错词页，而不是该再背十遍。
