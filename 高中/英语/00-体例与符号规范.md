# 体例与符号规范（英语卷 · v1）

> 与物理、数学共用同一套"先测后学"骨架：**一张卡片 = 一个 Unit**，先自评、再决定读多少。
> 差别在于：物理/数学的"公式 + 例题"换成英语的"规则 + 搭配、词形 + 句式"，并多出两件专属产物——**《词汇默写本》**与**每册一篇的目标词故事**。
>
> 本文件是这套书的"立法"：改体例先改这里，再改卡片。

---

## 一、编号规则

| 对象 | 格式 | 示例 | 说明 |
|---|---|---|---|
| 册 | 数字 1–7 | `4` | 1–3 为必修，4–7 为选择性必修 |
| 单元 | `E-册.单元` | `E-4.2` | 每册 4 个 Unit，共 28 个 |

## 三、单元卡片固定结构（14 段）

每张卡从 `## E-x.y 话题` 开始，标题下是一行斜体元信息，然后固定 14 段：

```
## E-4.2 Making a difference

*选必一 Unit 2 ｜ Ⅱ · 考频高 ｜ 话题：…… ｜ 语法：…… ｜ 本单元 65 词*

**⚡ 先猜**：一句中式英语错句，判断对错（故意不给答案）
### 30 秒概述          3 句话：话题 + 语法主线 + 写作任务
### 30 秒自评          3 题（词义 / 语法 / 短语），答案紧跟其后
### 🔑 核心词汇（10）   词条 + 词性 + 释义 + 2 个搭配/例句
### 🧩 短语与搭配（8）  三列表：短语 / 意思 / 例句
### 📐 语法：……        结构式 + 形式表 + 用法 + 易错边界 + 3 个练习
### ✍️ 写作：……        结构模板 + 5 个可套用句式
### 📖 阅读技能：……    一条策略 + 怎么用
### 例题 1 · L1 词汇    5 题 + 解析 + 💥 陷阱 + 变式
### 例题 2 · L2 语法    3 题 + 解析 + 💥 陷阱 + 变式
### 例题 3 · L3 翻译    3 句 + 参考译文 + 采分点 + 💥 陷阱 + 变式
### ⏱️ 限时挑战（60 秒）
### ✅ 接下来做什么      按对题数给出走法 + 过关线
### 🧠 本单元必背 10 词
```

**硬约束**

- 元信息行必须是斜体，字段顺序固定：`册 Unit N ｜ 层级 · 考频 ｜ 话题 ｜ 语法 ｜ 本单元 N 词`。
- 每张卡必须包含：核心词 10 个、短语 8 条、语法练习 3 个、写作句式 5 个、例题 3 道（均带解析与陷阱）。
- 例题 3 必须给**采分点**与**变式**；变式是"真会"的判据。
- 卡片之间不互相引用页码，只引用单元号，便于单独打印。

## 四、词汇与标注

| 标记 | 含义 |
|---|---|
| **★** | 高考高频 / 教材标星（选择性必修要求） |
| **○** | 纲外词：教材有、考纲无 |
| `n.` `v.` `adj.` `adv.` `prep.` `conj.` `pron.` `num.` `int.` | 词性缩写，多词性用 `/` 连接 |
| ① ② ③ | 一词多义，按教材顺序编号 |
| `E-x.y` | 首现单元，用于总表回溯 |

**约定**

- 词条只收教材 Vocabulary 附录，**不自行扩充考纲词**；确需补充的标 ○ 并注明来源。
- 派生词与词族（`achieve / achievement / achievable`）并列一行，不拆散。
- 释义以教材中文为准，括号内的用法说明原样保留（如"（口）"）。
- **音标不收录**：沪教版词表音标使用特殊字体，从 PDF 提取会得到乱码（如 `9dIdZItl`），与其放错不如不放；如需音标另行人工校对。词典数据只保留 `word / pos / cn / star / unit / book`。

## 五、5 勾与间隔复习

一行一个词：**英文 + 词性 ｜ ☐ ☐ ☐ ☐ ☐ ｜ 中文 + 词性**。

| 勾 | 时间 | 要求 |
|---|---|---|
| 第 1 格 | D0 | 盖住右侧英译中，对 |
| 第 2 格 | D+1 | 盖住左侧中译英，对 |
| 第 3 格 | D+3 | 双向各一遍，都对 |
| 第 4 格 | D+7 | 双向各一遍，都对 |
| 第 5 格 | D+15 | 双向各一遍，都对 |

**规则**

- 5 勾不是"打五次"，是**五个复习节点**；中间任一节点没过，回到第 1 格重来。
- 答案对但拼写错，按没过算；只写对中文不算过。
- 单元表打的是"本周过关"，书末总表打的是"全书过关"，两套勾互不干扰。
- 任何一格没打上，该词进"错词登记表"；HTML 版可一键筛出未过词汇。

## 六、故事规范

- 每册 **1 篇**，拆 **4 章**，一章对应一个 Unit（读完一章默这一章的词）。
- 篇幅：每册 900–1500 词；目标词约占正文 14%–24%，其余为可读的叙事词。
- 题材：校园 / 城市 / 科技 / 伦理，符合高中生经验，不写低幼童话。
- 目标词加粗；屈折形只加粗**词根**，如 `**kidnap**ped`、`**hike**d`，让学生一眼认出词表里的原形。
- 词形必须合法：不规则动词用正确过去式（`bent`、`withdrew`），**不许**出现 `*bended`、`*withdrawed` 这类机械加 -ed 的形式。

### 覆盖判定口径（两个标准，别混用）

| 口径 | 判定 | 用途 |
|---|---|---|
| **词形覆盖**（默认） | 原形，或常见屈折/派生形（`-s/-es/-ed/-ing/-ly/-er/-est/-ies/-ied/-ion/-ment/-ness`）出现即算 | 阅读中自然出现，教学上够用 |
| **原形覆盖**（`--strict`） | 必须出现原形本身 | 逐词默写、教材对齐用 |

## 七、语言与标点

- 正文英文用**英式拼写**，与沪教版一致：`neighbour`、`colour`、`centre`、`behaviour`、`favour`。
- 英文句子用英文标点与直引号 `"..."`；中文说明用中文标点。中英混排时，英文词两侧不加空格，句末标点跟主句语言。
- 单句 ≤ 25 词；故事正文控制在 CEFR B1–B2。
- 中文释义里避免"等等""之类的"堆砌，一条释义 ≤ 3 个义项，超出用 ①②③ 拆行。

## 八、语法与写作写法

- 结构式一律纯文本：`am / is / are being + 过去分词`，不写 LaTeX。
- 形式表用三列：`主语 | 形式 | 例句`，例句中目标结构加粗。
- 错例标 `（×）`，正例标 `（√）`；一条"易错边界"只说一个错点，不超过 3 条。
- 写作给"结构模板 + 5 个可套用句式"，句式必须是能整句背下来直接用的，不写抽象要求。
- 阅读技能一条策略配一个操作动作（"用笔划出每段第一句"），不写空话。

## 九、难度与过关线

| 层级 | 定位 | 内容 |
|---|---|---|
| L1 | 词汇 | 方框选词填空，考"认不认识" |
| L2 | 语法 | 句型转换 / 单句填空，考"会不会用" |
| L3 | 翻译 | 3 句中译英，考"能不能输出" |

- **过关线**：期中做到例题 2；期末做到例题 3 + 变式。
- **限时挑战**：60 秒 3 小问，只考已学内容，超时也做完、不记分。
- 自评 3 题全对 → 直接做例题 3 + 变式；对 2 题 → 重读语法与写作；0–1 题 → 从核心词汇顺序读。

## 十、构建与产物

```bash
bash build/make.sh        # 8 步，一条命令重建全部产物
```

| 步骤 | 脚本 | 产物 |
|---|---|---|
| 1 | `parse.py` | `data/考点库.json` |
| 2–3 | `gen_html.py` / `gen_print.py` | 交互版 HTML、打印版 HTML |
| 4 | `gen_pdf.py` | 手册 PDF（Chrome headless 打印） |
| 5–6 | `gen_docx.py` / `gen_xlsx.py` | Word 手册、Excel 清单 |
| 7–8 | `gen_vocab_book.py` + `story_check.py` | 词汇默写本 HTML → PDF |

- 产物统一放 `输出/`，文件名固定，便于 README 与 Release 引用。
- 构建依赖：Python 3（标准库 + python-docx / openpyxl）、Chrome。
- 改卡片或词库后必须重跑 `make.sh`，并抽查 PDF 版面（方框对齐、长释义不溢出、表格不跨页断裂）。
