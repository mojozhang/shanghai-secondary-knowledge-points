## 词汇默写本（本书特色）

- **一行一个词**：左边英文 + 词性，中间 5 个方框，最右边中文 + 词性。
- **5 个勾 = 5 次间隔复习**：D0 / D+1 / D+3 / D+7 / D+15，双向都默对才打勾；哪次没过，回到 D0 重来。
- **盖住右边英译中，盖住左边中译英**；书末附可剪的遮挡条。
- **每册一篇英文故事**：把本册约 200 个目标词串成 4 章故事（每章对应一个 Unit），目标词加粗，先读故事再默词表。
- 每册单元词表 + 全书去重总表（按字母），总表标注首现册.单元。
