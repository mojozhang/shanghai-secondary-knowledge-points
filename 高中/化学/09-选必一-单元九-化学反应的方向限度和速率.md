## C-2.1 自发反应与焓判据、熵判据

*反应原理 › 选必一 第2章 化学反应的方向、限度和速率 ｜ Ⅱ · 考频中 ｜ 前置：必修 化学反应与能量 ｜ 关联：C-2.2、C-2.7*

**⚡ 先猜**：碳酸钙分解要吸收热量，常温下放着不会分解；送进 1200 ℃ 的窑里却分解了。既然吸热反应也能自发，"放热反应才能自发进行"这句话到底错在哪里？

### 30 秒概述

判断一个反应能否自发，不能只看它放不放热。放热（ΔH < 0）和熵增（ΔS > 0）是两股独立的"推力"：方向一致时，任何温度都自发；方向相反时，由温度裁决。复合判据是 ΔH − TΔS，小于 0 自发，等于 0 平衡，大于 0 非自发。判据只回答"往哪走"，不回答"走多快"。

### 30 秒自评

1. 判断：ΔH < 0 的反应一定自发进行。
2. 判断：CaCO₃(s) → CaO(s) + CO₂(g) 的 ΔS > 0，所以它要在高温下才能自发。
3. 计算：合成氨反应 ΔH = −92 kJ·mol⁻¹、ΔS = −198 J·mol⁻¹·K⁻¹，298 K 时 ΔH − TΔS 是多少？能否自发？

> **答案**：1. ✗（NH₄NO₃ 溶于水吸热却自发，焓变不是唯一判据）　2. ✓（吸热且熵增，要满足 TΔS > ΔH，只能靠高温）　3. −92 + 298 × 0.198 ≈ −33 kJ·mol⁻¹ < 0，能自发。

### 🔑 原理与方程式

**自发反应**：在给定条件下，不需要外界持续做功就能"自己"进行的反应。自发不等于快，也不等于一定能观察到明显现象——常温下 H₂ 与 O₂ 混合可以几年不反应。

**焓判据**：多数自发反应放热（ΔH < 0），因为体系趋向能量降低。

- 2H₂(g) + O₂(g) → 2H₂O(l)　ΔH = −572 kJ·mol⁻¹
- 2Na(s) + Cl₂(g) → 2NaCl(s)　ΔH = −822 kJ·mol⁻¹

反例：NH₄NO₃ 溶于水吸热却自发；CaCO₃ 在高温下分解吸热却自发。焓变只是一个因素。

**熵判据**：熵 S 描述体系的混乱程度，单位 J·mol⁻¹·K⁻¹；ΔS > 0 为熵增，ΔS < 0 为熵减。

- 2H₂O(l) → 2H₂(g) + O₂(g)　ΔS = +57 J·mol⁻¹·K⁻¹
- CaCO₃(s) → CaO(s) + CO₂(g)　ΔS = +160 J·mol⁻¹·K⁻¹

反例：4Fe(OH)₂(s) + 2H₂O(l) + O₂(g) → 4Fe(OH)₃(s) 的 ΔS = −278 J·mol⁻¹·K⁻¹，照样自发。熵变也不是唯一判据。

**复合判据**（等温等压、非体积功为零）

- ΔH − TΔS < 0：反应能自发进行
- ΔH − TΔS = 0：反应达到平衡状态
- ΔH − TΔS > 0：反应不能自发进行

**四种组合**

- ΔH < 0、ΔS > 0：任何温度都自发
- ΔH > 0、ΔS < 0：任何温度都不自发
- ΔH < 0、ΔS < 0：低温自发（合成氨）
- ΔH > 0、ΔS > 0：高温自发（碳酸钙分解）

**熵的大小规律**

- 同种物质：S(g) > S(l) > S(s)
- 有气体参加的反应：气体分子数增加，ΔS > 0；减少，ΔS < 0；不变，ΔS 很小
- 同类物质，摩尔质量越大，熵越大

**适用条件**：判据只在温度、压强一定且非体积功为零时适用；T 必须用热力学温度（K）；ΔH 与 ΔS 的单位要先统一，kJ·mol⁻¹ 与 J·mol⁻¹·K⁻¹ 不能直接相减。

**易错边界**
1. 把"自发"当成"快"或"一定发生"：2NO + 2CO → N₂ + 2CO₂ 的 K 高达 2.5×10⁶⁰，常温下却几乎不动，要靠催化剂才转化。
2. 单位不统一：把 ΔS = −198 J·mol⁻¹·K⁻¹ 直接与 −92 kJ·mol⁻¹ 相减，忘了乘 10⁻³。
3. 把 ΔS > 0 当成"一定自发"：NH₄Cl 分解熵增，却要高于 621 K 才自发；熵增只有与焓变配合，才决定方向。

### 例题 1 · L1 基础

判断下列过程的 ΔS 大于 0 还是小于 0，并说明理由。

(1) 2H₂O(l) → 2H₂(g) + O₂(g)

(2) CaCO₃(s) → CaO(s) + CO₂(g)

(3) 2NO₂(g) ⇌ N₂O₄(g)

(4) NaCl 从溶液中结晶析出

**解析**：
(1) ΔS > 0：液体变成气体，气体分子数由 0 增到 3。

(2) ΔS > 0：固体分解出 1 mol 气体。

(3) ΔS < 0：2 mol 气体变成 1 mol 气体。

(4) ΔS < 0：离子从无序的溶液进入有序的晶格。

**💥 陷阱**：用"吸热还是放热"去推断熵变。焓变与熵变是两个独立的判据，放热反应也可能熵减。

**变式**：N₂(g) + 3H₂(g) ⇌ 2NH₃(g) 的 ΔS 大于 0 还是小于 0？（小于 0，4 mol 气体变成 2 mol）

### 例题 2 · L2 常考

合成氨反应 N₂(g) + 3H₂(g) ⇌ 2NH₃(g) 的 ΔH = −92 kJ·mol⁻¹、ΔS = −198 J·mol⁻¹·K⁻¹，二者随温度变化很小，可视为常数。

(1) 计算 298 K 时的 ΔH − TΔS，判断反应能否自发；

(2) 室温下推动该反应自发进行的主要因素是焓变还是熵变？

(3) 温度升高，ΔH − TΔS 的值如何变化？这对反应的自发性是促进还是抑制？

**解析**：
(1) ΔS = −198 J·mol⁻¹·K⁻¹ = −0.198 kJ·mol⁻¹·K⁻¹。

ΔH − TΔS = −92 − 298 × (−0.198) = −92 + 59.0 = **−33 kJ·mol⁻¹ < 0**，能自发。

(2) 该反应放热（ΔH < 0）而熵减（ΔS < 0），熵变是不利因素；298 K 时 TΔS = −59 kJ·mol⁻¹，−TΔS 为 +59 kJ·mol⁻¹，抵不过 −92 kJ·mol⁻¹ 的放热，所以**主要推动因素是焓变**。

(3) 因为 ΔS < 0，−TΔS 为正值且随 T 增大而增大，ΔH − TΔS 由负向正变化，**升温抑制自发性**。

**💥 陷阱**：把 ΔS 的数值直接当 kJ 用，算出 −92 − 59 = −151 的假结果；或认为"放热反应升温更有利"。

**变式**：若升温到 773 K，ΔH − TΔS 约为多少？这是否说明 500 ℃ 下合成氨根本无法进行？（−92 + 0.198 × 773 ≈ +61 kJ·mol⁻¹ > 0；不能这样推论。判据给出的是标准态趋势，工业上靠高压和及时分离液氨把 Q 压到 K 以下，反应仍持续正移，高温换来的是速率与催化剂活性）

### 例题 3 · L3 综合

汽车尾气中的 NO 与 CO 可发生反应 2NO(g) + 2CO(g) → N₂(g) + 2CO₂(g)，ΔH < 0，298 K 时 K = 2.5×10⁶⁰。

(1) 判断该反应在常温下能否自发，并说明 ΔS 的正负；

(2) 该反应 K 如此之大，为什么常温下尾气中的 NO 和 CO 仍能直接排出？

(3) 三元催化转化器为什么能减少尾气污染？它能否提高 NO 的平衡转化率？

**解析**：
(1) 反应物共 4 mol 气体、生成物共 3 mol 气体，ΔS < 0。但 ΔH < 0 且数值很大，常温下 ΔH − TΔS < 0，**能自发**。

(2) 自发只说明方向，不说明速率。该反应活化能高，常温下活化分子极少，速率慢到几乎观察不到，NO 和 CO 来不及转化就排入大气。

(3) 催化剂改变反应历程、降低活化能，使活化分子百分数增大，速率大幅提高，尾气在通过催化床的短时间内即可转化。催化剂**同等程度加快正、逆反应**，不改变 K，也不改变平衡转化率，只缩短达到平衡的时间。

**💥 陷阱**：看到 K = 2.5×10⁶⁰ 就判断"反应瞬间完成"。K 衡量限度，活化能衡量速率，两者不能互换。

**变式**：三元催化器在冷启动后的头几十秒内净化效果很差，为什么？（催化剂需要达到一定温度才有活性；低温下活化分子少、速率慢，NO 和 CO 来不及转化）

### ⏱️ 限时挑战（90 秒）

① 判断反应自发方向的复合判据是什么？② NH₄NO₃ 溶于水吸热却自发，说明什么？③ 合成氨反应的 ΔS 大于 0 还是小于 0？

> **答案**：① ΔH − TΔS < 0 ② 焓变不是唯一判据，溶解后混乱度增大，熵增也是动力 ③ ΔS < 0（4 mol 气体变成 2 mol）

## C-2.2 化学平衡常数

*反应原理 › 选必一 第2章 化学反应的方向、限度和速率 ｜ Ⅱ · 考频高 ｜ 前置：C-2.1 ｜ 关联：C-2.3、C-2.6　★*

**⚡ 先猜**：同一个反应，从正反应开始、从逆反应开始、从中间某一点开始，到达平衡时各物质的浓度肯定不同。那么，有没有哪个量是无论怎么开始都一样的？

### 30 秒概述

平衡常数 K 只由温度和方程式决定，与起始浓度、投料顺序、是否使用催化剂都无关。它把"反应限度"变成一个可计算的数：K 越大，正反应进行得越完全。表达式必须与方程式一一对应，固体、纯液体和稀溶液中的水都不写进去。

### 30 秒自评

1. 判断：H₂(g) + I₂(g) ⇌ 2HI(g) 的 K 表达式，若把方程式改写成 2H₂(g) + 2I₂(g) ⇌ 4HI(g)，K 值不变。
2. 判断：K 只与温度有关，改变压强或加入催化剂都不改变 K。
3. 计算：某温度下 H₂(g) + I₂(g) ⇌ 2HI(g) 的 K = 49.0，平衡时 [H₂] = [I₂] = 0.10 mol·L⁻¹，求 [HI]。

> **答案**：1. ✗（方程式系数乘 2，K 变为原来的平方，即 K²）　2. ✓　3. [HI]² = 49.0 × 0.10 × 0.10 = 0.49，[HI] = 0.70 mol·L⁻¹。

### 🔑 原理与方程式

**定义**：对一般的可逆反应 aA + bB ⇌ cC + dD，一定温度下达到平衡时，生成物浓度幂之积与反应物浓度幂之积的比值是一个常数，叫平衡常数 K；幂指数就是方程式中的化学计量数。

以 N₂(g) + 3H₂(g) ⇌ 2NH₃(g) 为例：K = [NH₃]² ÷ ([N₂][H₂]³)

方括号表示**平衡浓度**，单位为 mol·L⁻¹；K 是纯数值，通常不写单位。

**书写规则**

- 固体、纯液体的浓度视为常数，不写入表达式。如 CaCO₃(s) ⇌ CaO(s) + CO₂(g) 的 K = [CO₂]，3Fe(s) + 4H₂O(g) ⇌ Fe₃O₄(s) + 4H₂(g) 的 K = [H₂]⁴ ÷ [H₂O]⁴
- 稀溶液中参加反应的水，浓度视为常数，不写入表达式
- 方程式方向相反，K 互为倒数；方程式系数乘 n，K 变为 K 的 n 次方
- 气态水要写进表达式，液态水才省略

**K 的意义**

- K > 10⁵：正反应进行得较完全；K < 10⁻⁵：正反应进行的程度非常小
- K 越大，正反应进行的程度越大，但不能说明反应快慢
- K 只随温度改变：放热反应升温 K 减小，吸热反应升温 K 增大

**浓度商 Q**：表达式与 K 相同，但代入任意时刻的浓度。

- Q < K：反应向正反应方向进行，直到 Q = K
- Q = K：反应达到平衡
- Q > K：反应向逆反应方向进行，直到 Q = K

**K 与转化率**：α = 转化量 ÷ 起始量 × 100%。K 与投料方式无关，反映反应的本质限度；α 随投料比、压强改变，是限度的表现形式。

**适用条件**：K 必须在指定温度下使用；表达式必须与所给方程式对应（方向、系数）；只能代入平衡浓度；反应前后气体分子数不等的反应，不能直接用物质的量之比代替浓度，因为体积 V 没有约掉。

**易错边界**
1. 把起始浓度代入 K 表达式——K 只认平衡浓度，起始浓度只能用来算 Q。
2. 对气体分子数改变的反应，拿物质的量直接代 K。如 N₂ + 3H₂ ⇌ 2NH₃，K = n(NH₃)²·V² ÷ [n(N₂)·n(H₂)³]，V 不能丢。
3. 方程式系数改变后仍用原 K；或认为加压、加催化剂能改变 K。

### 例题 1 · L1 基础

写出下列反应的平衡常数表达式。

(1) N₂(g) + 3H₂(g) ⇌ 2NH₃(g)

(2) 3Fe(s) + 4H₂O(g) ⇌ Fe₃O₄(s) + 4H₂(g)

(3) CaCO₃(s) ⇌ CaO(s) + CO₂(g)

(4) CO(g) + 2H₂(g) ⇌ CH₃OH(g)

**解析**：
(1) K = [NH₃]² ÷ ([N₂][H₂]³)

(2) K = [H₂]⁴ ÷ [H₂O]⁴

(3) K = [CO₂]

(4) K = [CH₃OH] ÷ ([CO][H₂]²)

**💥 陷阱**：把 Fe、Fe₃O₄、CaCO₃、CaO 写进表达式；第 (2) 题又把 H₂O(g) 当成水省略——气态水必须写。

**变式**：若把合成氨方程式写成 2NH₃(g) ⇌ N₂(g) + 3H₂(g)，K′ 与 K 是什么关系？（K′ = 1/K）

### 例题 2 · L2 常考

457.6 ℃ 时，H₂(g) + I₂(g) ⇌ 2HI(g) 的 K = 48.4。某 1 L 密闭容器中起始投入 0.0100 mol H₂ 和 0.0100 mol I₂，求平衡时各物质的浓度和 H₂ 的转化率。

**解析**：
起始浓度/（mol·L⁻¹）：c(H₂) = 0.0100，c(I₂) = 0.0100，c(HI) = 0

转化浓度/（mol·L⁻¹）：Δc(H₂) = x，Δc(I₂) = x，Δc(HI) = 2x

平衡浓度/（mol·L⁻¹）：c(H₂) = 0.0100 − x，c(I₂) = 0.0100 − x，c(HI) = 2x

K = (2x)² ÷ (0.0100 − x)² = 48.4

两边开平方：2x ÷ (0.0100 − x) = 6.96

解得 x = 0.00777，故 [H₂] = [I₂] = **0.00223 mol·L⁻¹**，[HI] = **0.0155 mol·L⁻¹**。

α(H₂) = 0.00777 ÷ 0.0100 × 100% = **77.7%**。

**💥 陷阱**：把 [HI] 写成 x 而不是 2x（转化量之比 1∶1∶2）；或忘记开方，硬解二次方程时算错。

**变式**：若起始 H₂、I₂ 的浓度都改为 0.0200 mol·L⁻¹，K 和 H₂ 的转化率如何变化？（K 不变；该反应前后气体分子数相等，转化率仍为 77.7%）

### 例题 3 · L3 综合

800 ℃ 时，CO(g) + H₂O(g) ⇌ CO₂(g) + H₂(g) 的 K = 1.0。在体积为 V L 的密闭容器中通入 2 mol CO、3 mol H₂O、2 mol CO₂ 和 2 mol H₂。

(1) 判断此时反应进行的方向；

(2) 求平衡时各物质的物质的量；

(3) 若把容器体积压缩到 V/2，平衡是否移动？为什么？

**解析**：
(1) 起始浓度/（mol·L⁻¹）：c(CO) = 2/V，c(H₂O) = 3/V，c(CO₂) = 2/V，c(H₂) = 2/V。

Q = [(2/V)(2/V)] ÷ [(2/V)(3/V)] = 2/3 < 1.0 = K，反应**向正反应方向进行**。

(2) 设 CO 转化了 x mol，按 CO、H₂O、CO₂、H₂ 的顺序列三段式。

起始浓度/（mol·L⁻¹）：2/V，3/V，2/V，2/V

转化浓度/（mol·L⁻¹）：x/V，x/V，x/V，x/V

平衡浓度/（mol·L⁻¹）：(2 − x)/V，(3 − x)/V，(2 + x)/V，(2 + x)/V

K = (2 + x)² ÷ [(2 − x)(3 − x)] = 1.0

展开得 4 + 4x + x² = 6 − 5x + x²，9x = 2，x ≈ 0.22。

平衡时：n(CO) = **1.78 mol**，n(H₂O) = **2.78 mol**，n(CO₂) = **2.22 mol**，n(H₂) = **2.22 mol**。

(3) 该反应前后气体分子数相等（2 → 2），压缩体积时各组分浓度同倍增大，Q 与 K 仍相等，**平衡不移动**。

**💥 陷阱**：体积 V 未知就不敢列式——其实 Δn(气) = 0 时 V 会在 K 表达式中约掉；但若换成合成氨这类 Δn ≠ 0 的反应，V 必须保留。

**变式**：若起始四种物质的量都加倍（仍为 V L），Q 与 K 的关系如何？（Q 仍为 2/3 < K，仍向正反应方向进行，x 加倍，约为 0.44 mol）

### ⏱️ 限时挑战（90 秒）

① 写出 N₂ + 3H₂ ⇌ 2NH₃ 的平衡常数表达式。② K 只与什么因素有关？③ H₂ + I₂ ⇌ 2HI 平衡时 [H₂] = [I₂] = 0.10 mol·L⁻¹、[HI] = 0.70 mol·L⁻¹，求 K。

## C-2.3 转化率与平衡计算（三段式）

*反应原理 › 选必一 第2章 化学反应的方向、限度和速率 ｜ Ⅱ · 考频高 ｜ 前置：C-2.2 ｜ 关联：C-2.6、C-2.7　★*

**⚡ 先猜**：向已经平衡的合成氨体系中再加入一些 N₂，平衡向正反应方向移动。那么，N₂ 自身的转化率是提高还是降低？

### 30 秒概述

三段式是平衡计算的通用语言：起始、转化、平衡三行，转化量之比等于化学计量数之比。转化率 α = 转化量 ÷ 起始量 × 100%。K 与 α 可以互推：由 α 得平衡浓度再代 K，或由 K 设转化量解方程。判断"加料后转化率怎么变"，一定要先问清是哪种反应物的转化率。

### 30 秒自评

1. 判断：增大某一反应物的浓度，该反应物自身的转化率一定提高。
2. 判断：两种反应物参加的可逆反应，增大一种反应物的浓度，另一种反应物的转化率提高。
3. 计算：2SO₂(g) + O₂(g) ⇌ 2SO₃(g)，起始 c(SO₂) = 2.0 mol·L⁻¹、c(O₂) = 1.0 mol·L⁻¹，平衡时 c(SO₂) = 0.8 mol·L⁻¹，求 SO₂ 的转化率和平衡时 c(SO₃)。

> **答案**：1. ✗（增大 N₂ 浓度时，N₂ 自身转化率反而下降）　2. ✓（平衡正移，另一种反应物被消耗得更多）　3. Δc(SO₂) = 1.2 mol·L⁻¹，α = 60%，c(SO₃) = 1.2 mol·L⁻¹。

### 🔑 原理与方程式

**三段式模板**（以 N₂ + 3H₂ ⇌ 2NH₃ 为例，起始 c(N₂) = 1.00 mol·L⁻¹、c(H₂) = 3.00 mol·L⁻¹，平衡时 c(NH₃) = 0.80 mol·L⁻¹）

起始浓度/（mol·L⁻¹）：c(N₂) = 1.00，c(H₂) = 3.00，c(NH₃) = 0

转化浓度/（mol·L⁻¹）：Δc(N₂) = 0.40，Δc(H₂) = 1.20，Δc(NH₃) = 0.80

平衡浓度/（mol·L⁻¹）：c(N₂) = 0.60，c(H₂) = 1.80，c(NH₃) = 0.80

**三条规则**

- 转化量之比 = 化学计量数之比：0.40∶1.20∶0.80 = 1∶3∶2
- 转化量不能超过起始量，否则说明题目数据有误
- 平衡量 = 起始量 ± 转化量：反应物减，生成物加

**转化率**

α = 转化量 ÷ 起始量 × 100% = (起始浓度 − 平衡浓度) ÷ 起始浓度 × 100%

气体也可以用物质的量、体积，溶液也可以用质量，但同一题中单位要统一；α 必须指明是哪种物质。

**K 与 α 的互推**

- 已知 α：算出平衡浓度 → 代入 K 表达式
- 已知 K：设转化量为 x → 列三段式 → 解方程 → 求 α

**加料与转化率**

- 增加一种反应物：平衡正移，另一种反应物的转化率提高，自身转化率降低
- 按化学计量数之比投料：平衡混合物中生成物的百分含量最大（合成氨 H₂∶N₂ = 3∶1）
- 恒容下按比例增加全部反应物：相当于加压，平衡向气体分子数减小的方向移动，转化率提高

**适用条件**：三段式只用于已经达到平衡的体系；恒容与恒压的结论不同，充惰性气体时要先判断各组分浓度是否改变；有固体参与时，固体不列入浓度三段式，但可以列物质的量。

**易错边界**
1. 把起始量之比或平衡量之比当成转化量之比。
2. 用"平衡量 ÷ 起始量"算转化率，正确算法是"转化量 ÷ 起始量"。
3. 认为"平衡正移"就等于"该反应物转化率提高"——增加 N₂ 时，N₂ 自身转化率反而下降。

### 例题 1 · L1 基础

在 2 L 密闭容器中进行 2SO₂(g) + O₂(g) ⇌ 2SO₃(g)，起始投入 4 mol SO₂ 和 2 mol O₂，平衡时生成 3 mol SO₃。求 SO₂ 的转化率、平衡时 O₂ 的物质的量。

**解析**：
先换成浓度：c(SO₂) = 2.0 mol·L⁻¹，c(O₂) = 1.0 mol·L⁻¹，平衡时 c(SO₃) = 1.5 mol·L⁻¹。按 SO₂、O₂、SO₃ 的顺序列三段式。

起始浓度/（mol·L⁻¹）：2.0，1.0，0

转化浓度/（mol·L⁻¹）：1.5，0.75，1.5

平衡浓度/（mol·L⁻¹）：0.5，0.25，1.5

α(SO₂) = 1.5 ÷ 2.0 × 100% = **75%**

n(O₂) = 0.25 mol·L⁻¹ × 2 L = **0.50 mol**

**💥 陷阱**：忘记除以体积 2 L，把 4 mol 当成 4 mol·L⁻¹，算出 α = 37.5% 的错误结果。

**变式**：该温度下反应的平衡常数是多少？（K = 1.5² ÷ (0.5² × 0.25) = 36）

### 例题 2 · L2 常考

在 1 L 密闭容器中进行 N₂(g) + 3H₂(g) ⇌ 2NH₃(g)，起始投入 1.0 mol N₂ 和 3.0 mol H₂，平衡时 NH₃ 为 0.80 mol。

(1) 求平衡时各物质的浓度、K，以及 N₂、H₂ 的转化率；

(2) 若起始改为 1.0 mol N₂ 和 6.0 mol H₂，N₂ 和 H₂ 的转化率分别怎样变化？

(3) 工业上为什么不用"过量很多 H₂"的办法来提高 N₂ 的转化率？

**解析**：
(1) 按 N₂、H₂、NH₃ 的顺序列三段式。

起始浓度/（mol·L⁻¹）：1.0，3.0，0

转化浓度/（mol·L⁻¹）：0.40，1.20，0.80

平衡浓度/（mol·L⁻¹）：0.60，1.80，0.80

K = 0.80² ÷ (0.60 × 1.80³) = 0.64 ÷ 3.50 ≈ **0.18**

α(N₂) = 0.40 ÷ 1.0 × 100% = **40%**；α(H₂) = 1.20 ÷ 3.0 × 100% = **40%**

(2) H₂ 过量，平衡正移，**N₂ 的转化率提高**；但 H₂ 的总量增加得更多，**H₂ 自身的转化率降低**。

**💥 陷阱**：认为"平衡正移，所以两种反应物的转化率都提高"。增加一种反应物，只有另一种的转化率提高。

**变式**：若起始改为 2.0 mol N₂ 和 6.0 mol H₂（体积不变），N₂ 的转化率如何变化？（投料比不变、浓度加倍，相当于加压，平衡正移，N₂ 转化率提高）

### 例题 3 · L3 综合

在 2 L 恒容密闭容器中进行 2SO₂(g) + O₂(g) ⇌ 2SO₃(g)，起始投入 2.0 mol SO₂ 和 1.0 mol O₂，平衡时 SO₃ 为 1.6 mol。

(1) 用三段式求平衡时各物质的浓度、K 和 SO₂ 的转化率；

## C-2.4 化学反应速率与活化能

*反应原理 › 选必一 第2章 化学反应的方向、限度和速率 ｜ Ⅱ · 考频高 ｜ 前置：必修 化学反应速率 ｜ 关联：C-2.5、C-2.7　★*

**⚡ 先猜**：同一个合成氨反应，用 N₂ 的浓度变化算出速率是 0.10 mol·L⁻¹·s⁻¹，用 H₂ 算却是 0.30 mol·L⁻¹·s⁻¹。两个数不一样，是实验做错了吗？

### 30 秒概述

速率必须指明"用哪种物质表示"，再用计量数归一，才能得到与物质种类无关的反应速率。速率是某段时间内的平均值；真正决定快慢的是活化能——活化能越低，活化分子百分数越大，有效碰撞越多，反应越快。

### 30 秒自评

1. 判断：同一反应中，用不同物质表示的反应速率数值一定相等。
2. 判断：N₂(g) + 3H₂(g) ⇌ 2NH₃(g) 中，若 v(N₂) = 0.10 mol·L⁻¹·s⁻¹，则 v(H₂) = 0.30 mol·L⁻¹·s⁻¹。
3. 计算：反应 2A → B 中，2 s 内 A 的浓度由 0.80 mol·L⁻¹ 降到 0.50 mol·L⁻¹，求 v(A) 和 v(B)。

> **答案**：1. ✗（数值之比等于化学计量数之比）　2. ✓（v(H₂) = 3v(N₂)）　3. v(A) = 0.30 ÷ 2 = 0.15 mol·L⁻¹·s⁻¹，v(B) = 0.075 mol·L⁻¹·s⁻¹。

### 🔑 原理与方程式

**定义**：v = Δc/Δt，Δc 取绝对值（浓度变化量），单位 mol·L⁻¹·s⁻¹ 或 mol·L⁻¹·min⁻¹。

**归一化**：对 aA + bB → cC + dD，

v = (1/a)·Δc(A)/Δt = (1/b)·Δc(B)/Δt = (1/c)·Δc(C)/Δt = (1/d)·Δc(D)/Δt

同一反应中，v(A)∶v(B)∶v(C)∶v(D) = a∶b∶c∶d；用不同物质表示时数值可以不同，但归一后的 v 相同。

**平均速率与瞬时速率**：Δt 内算出的是平均速率，不同时间段的平均速率不同；Δt 越小，越接近某一时刻的瞬时速率。

**测定方法**

- 量气法：测一定温度、压强下气体体积随时间的变化
- 分光光度法：测有色物质在特定波长下吸光度随时间的变化
- 电导法、pH 法：测导电能力或 pH 随时间的变化
- 化学法需要先中止反应，操作不便，现代测定多用上述方法

**基元反应与反应历程**：一步完成的反应叫基元反应，如 NO₂(g) + CO(g) → NO(g) + CO₂(g)；分几步完成的叫非基元反应，每一步都是基元反应，总速率由最慢的一步（决速步）决定。H₂ + I₂ → 2HI 分两步：① I₂ ⇌ 2I（快）；② 2I + H₂ → 2HI（慢）。

**速率常数**：对基元反应 aA + bB → 产物，速率与 c(A) 的 a 次方、c(B) 的 b 次方成正比，比例系数 k 叫速率常数。例如基元反应 NO₂(g) + CO(g) → NO(g) + CO₂(g)，v = k·c(NO₂)·c(CO)。k 由反应本身和温度决定，与浓度无关；温度升高，k 增大。

**活化能与碰撞理论**

- 反应物分子必须相互碰撞才可能反应，但只有能量足够、取向合适的碰撞才是有效碰撞
- 能发生有效碰撞的分子叫活化分子；活化分子的平均能量与反应物分子平均能量的差值叫活化能 E
- 活化能越低，活化分子所占百分数越大，单位时间内有效碰撞次数越多，反应越快

**适用条件**：v 是平均值，必须注明时间段和参照物质；固体、纯液体的浓度视为常数，不用来表示速率；恒压容器体积变化时，浓度变化不一定只由反应引起；速率方程必须由实验确定，不能由总方程式的系数直接写出。

**易错边界**
1. 比较速率大小时不除以计量数，直接拿 v(N₂) 与 v(H₂) 比大小。
2. 认为活化能越大反应越容易进行——恰好相反，活化能越大，活化分子越少，反应越慢。
3. 认为催化剂能改变 ΔH 或平衡转化率——催化剂只改变反应历程、降低活化能。

### 例题 1 · L1 基础

在 2 L 密闭容器中进行 N₂(g) + 3H₂(g) ⇌ 2NH₃(g)，反应 2 s 后测得 NH₃ 的物质的量增加了 0.80 mol。求 v(NH₃)、v(H₂)、v(N₂)。

**解析**：
Δc(NH₃) = 0.80 mol ÷ 2 L = 0.40 mol·L⁻¹

v(NH₃) = 0.40 ÷ 2 = **0.20 mol·L⁻¹·s⁻¹**

由 v(N₂)∶v(H₂)∶v(NH₃) = 1∶3∶2：

v(H₂) = 1.5 × 0.20 = **0.30 mol·L⁻¹·s⁻¹**

v(N₂) = 0.5 × 0.20 = **0.10 mol·L⁻¹·s⁻¹**

**💥 陷阱**：用 0.80 mol 直接除以 2 s 得 0.40 mol·L⁻¹·s⁻¹，漏掉了容器体积。

**变式**：2 s 内 N₂ 的浓度减少了多少？用归一化公式算出的总速率 v 是多少？（0.20 mol·L⁻¹；0.10 mol·L⁻¹·s⁻¹）

### 例题 2 · L2 常考

已知 H₂(g) + I₂(g) → 2HI(g) 的反应分两步进行：① I₂ ⇌ 2I（快）；② 2I + H₂ → 2HI（慢）。

(1) 哪一步是决速步？

(2) 加入合适的催化剂后，活化能、正反应速率、K、ΔH 分别怎样变化？

(3) 能否根据总方程式直接写出 v = k·c(H₂)·c(I₂)？为什么？

**解析**：
(1) 第 ② 步慢，是**决速步**，总反应速率由它决定。

(2) 催化剂改变反应历程，**降低活化能**；正、逆反应速率**同等加快**；**K 不变**，**ΔH 不变**（焓变只由始态和终态决定，与途径无关）。

(3) **不能**。总方程式只表示反应物与生成物之间的化学计量关系，不表示反应历程；速率方程必须由实验测定。本例中 I₂ 先解离成 I 原子，总速率受 2I + H₂ 这一步控制。

**💥 陷阱**：把总方程式的系数当成反应级数；或认为催化剂能降低 ΔH、提高转化率。

**变式**：升高温度时，速率常数 k 和活化分子百分数如何变化？（都增大，反应速率加快）

### 例题 3 · L3 综合

某同学在室温下测定 H₂O₂ 分解生成 H₂O 和 O₂ 的速率，数据如下：

| 时间/min | 0 | 20 | 40 | 60 | 80 |
|---|---|---|---|---|---|
| c(H₂O₂)/（mol·L⁻¹） | 0.80 | 0.40 | 0.20 | 0.10 | 0.050 |

(1) 分别计算 0～20 min、20～40 min、40～60 min 内 H₂O₂ 分解的平均速率；

(2) 比较三段时间的速率，归纳速率与浓度的关系，并解释原因；

(3) 若改用排水量气法测定，读数时要注意什么？

**解析**：
(1) 0～20 min：v = (0.80 − 0.40) ÷ 20 = **0.020 mol·L⁻¹·min⁻¹**

20～40 min：v = (0.40 − 0.20) ÷ 20 = **0.010 mol·L⁻¹·min⁻¹**

40～60 min：v = (0.20 − 0.10) ÷ 20 = **0.0050 mol·L⁻¹·min⁻¹**

(2) 每 20 min 浓度减半，速率也减半，说明**速率与 c(H₂O₂) 成正比**。原因是浓度降低后，单位体积内活化分子数减少，单位时间内有效碰撞次数减少。

(3) 装置气密性良好；待气体恢复至室温再读数；读数时量气管内外液面相平；视线与凹液面最低处相平；同温同压下测量。

**💥 陷阱**：用 c₀ ÷ t（如 0.80 ÷ 20 = 0.040）算速率，忘记减去末态浓度；把平均速率当成某一时刻的瞬时速率。

**变式**：80 min 时 H₂O₂ 是否已经分解完？为什么？（没有，仍有 0.050 mol·L⁻¹；速率随浓度降低而减小，理论上只能趋近于零）

### ⏱️ 限时挑战（90 秒）

① 化学反应速率的常用单位是什么？② 2A → B 中 v(A) 与 v(B) 是什么关系？③ 催化剂能否改变平衡常数 K？

> **答案**：① mol·L⁻¹·s⁻¹（或 mol·L⁻¹·min⁻¹）　② v(A) = 2v(B)　③ 不能，只改变反应历程和速率

- **3 道全对** → 直接做「例题 3」+ 变式，然后进入 C-2.5。
- **对 2 道** → 读「易错边界」，把"速率之比 = 计量数之比"再默写一遍。
- **对 0–1 道** → 从「原理与方程式」读起，先分清平均速率、瞬时速率、归一化速率三个概念。

> **过关线**：例题 3 做对 + 变式做对 = 过关；用不同物质表示速率时不除以计量数，按未过关处理。

## C-2.5 影响化学反应速率的因素

*反应原理 › 选必一 第2章 化学反应的方向、限度和速率 ｜ Ⅱ · 考频高 ｜ 前置：C-2.4 ｜ 关联：C-2.6、C-2.7*

**⚡ 先猜**：恒温恒容的密闭容器里，充入氦气，总压明显增大。此时容器内反应的速率会加快吗？

### 30 秒概述

浓度、温度、压强、催化剂，归根到底都在改变"单位体积内活化分子的数目"或"活化分子所占的百分数"。浓度和压缩体积改变的是前者，温度改变的是后者，催化剂改变的是活化能这道门槛。外界条件变了，速率不一定变——关键看有没有真正改变浓度或活化分子数。

### 30 秒自评

1. 判断：增大压强一定能加快反应速率。
2. 判断：升高温度，正反应和逆反应的速率都增大。
3. 简答：镁条分别与 5% 和 15% 的盐酸反应，速率不同的根本原因是什么？

> **答案**：1. ✗（恒容充惰性气体、或无气体参加时不一定）　2. ✓（吸热方向增大得更多）　3. c(H⁺) 不同，单位体积内活化分子数不同，有效碰撞频率不同。

### 🔑 原理与方程式

**浓度**：增大反应物浓度 → 单位体积内活化分子数增多 → 有效碰撞增多 → 速率加快。固体、纯液体的浓度是常数，改变用量不改变速率，但粉碎增大表面积可以加快。

**压强**：对有气体参加的反应，压缩体积 → 各组分浓度同倍增大 → 速率加快。恒容充惰性气体 → 各组分浓度不变 → 速率不变；恒压充惰性气体 → 体积增大 → 浓度减小 → 速率减慢。

**温度**：升高温度 → 分子平均能量升高 → 活化分子百分数增大 → 速率加快。无论放热反应还是吸热反应、正反应还是逆反应，升温都加快；经验上每升高 10 ℃，速率约增大到 2～4 倍。

**催化剂**：降低活化能、改变反应历程 → 活化分子百分数增大 → 正、逆反应速率同等加快 → 不改变 K、ΔH 和平衡转化率。催化剂有选择性，需要一定的活性温度，还可能被 CO、H₂S 等物质毒化。

**其他因素**：增大固体表面积、光照、超声波、溶剂性质等。

**适用条件**：浓度只对气体和溶液中的反应有效；压强只对气体有效，而且必须通过改变体积实现；催化剂在反应前后质量和性质不变，不进入总反应方程式。

**易错边界**
1. 认为升温只加快吸热方向——正、逆都加快，只是吸热方向增加得更多，所以平衡才向吸热方向移动。
2. 认为"加压一定加快"——恒容充惰性气体不改变各组分浓度，速率不变。
3. 认为催化剂能提高产率——催化剂只缩短达到平衡的时间，不改变平衡状态。

### 例题 1 · L1 基础

取两支试管，分别加入 5% 和 15% 的盐酸各 5 mL，再各放入大小相同的镁条。

(1) 哪支试管反应更快？为什么？

(2) 若把 15% 盐酸换成 15% 醋酸，速率怎样变化？

(3) 若把镁条换成等质量的镁粉，速率怎样变化？

**解析**：
(1) **15% 盐酸**更快。浓度大，单位体积内 H⁺ 数目多，活化分子数多，有效碰撞频率高。

(2) **变慢**。醋酸是弱酸，部分电离，c(H⁺) 远小于同浓度盐酸。

(3) **变快**。镁粉表面积大，与酸的接触面积增大，有效碰撞增多。

**💥 陷阱**：认为浓度大是因为"活化能低"。活化能由反应本身决定，改变浓度不改变活化能。

**变式**：向 15% 盐酸中加入少量 CuSO₄ 溶液，反应速率怎样变化？（镁置换出铜，镁与铜在酸中形成原电池，速率加快）

### 例题 2 · L2 常考

常温下，H₂O₂ 溶液几乎不分解；加入少量 MnO₂ 后迅速放出 O₂；加热也能加快分解。

(1) 从活化能角度解释 MnO₂ 的作用；

(2) 加热为什么也能加快分解？

(3) 能否说 MnO₂ 使 H₂O₂ 分解放出的热量更多？

**解析**：
(1) MnO₂ 作催化剂，改变反应历程，**降低活化能**，活化分子百分数增大，有效碰撞增多，速率加快。

(2) 升温使分子平均能量升高，活化分子百分数增大，单位时间内有效碰撞增多，速率加快。

(3) **不能**。催化剂不改变反应的始态和终态，ΔH 不变；它只改变反应途径和速率，不改变放热的多少。

**💥 陷阱**：认为催化剂"提供能量"或"使反应放热更多"；把"降低活化能"与"降低 ΔH"混为一谈。

**变式**：若把 MnO₂ 换成 FeCl₃ 溶液，H₂O₂ 的分解能否加快？（能，Fe³⁺ 也是 H₂O₂ 分解的催化剂）

### 例题 3 · L3 综合

某小组用锌与稀硫酸反应制氢气，用排水量气法测定相同时间内收集到的 H₂ 体积，探究浓度、温度、锌的表面积对反应速率的影响。

(1) 实验中必须控制哪些变量？

(2) 请设计三组对比实验（写出改变的条件和预期现象）；

(3) 测得 40 ℃ 时速率明显大于 20 ℃，能否说明升温降低了活化能？为什么？

(4) 用量气管读数时要注意什么？

**解析**：
(1) 锌的质量与表面积（探究表面积时除外）、硫酸的体积与浓度（探究浓度时除外）、温度（探究温度时除外）、收集时间、装置气密性。

(2) ① 浓度：同温下，等质量同表面积的锌粒分别与 20 mL 1 mol·L⁻¹ 和 2 mol·L⁻¹ 稀硫酸反应，浓度大的收集到更多 H₂；

② 温度：同浓度同体积硫酸、等质量锌粒，分别置于 20 ℃ 和 40 ℃ 水浴中，温度高的收集到更多 H₂；

③ 表面积：同温同浓度下，等质量的锌粒与锌粉分别反应，锌粉收集到更多 H₂。

(3) **不能**。升温提高的是分子的平均能量和活化分子百分数；活化能由反应本身和催化剂决定，不随温度改变。

(4) 待气体恢复至室温再读数；量气管内外液面相平；视线与凹液面最低处相平；检查装置气密性。

**💥 陷阱**：一组实验同时改变浓度和温度，无法判断是哪个因素起作用；把"升温加快"说成"升温降低活化能"。

**变式**：若把稀硫酸换成 98% 浓硫酸，能否用排水量气法收集到 H₂？为什么？（不能。浓硫酸与锌反应生成 SO₂ 而不是 H₂，且 SO₂ 溶于水，排水法收集不到；实验室制 H₂ 用稀硫酸）

### ⏱️ 限时挑战（90 秒）

① 升高温度，正、逆反应速率如何变化？② 恒容充入 Ar，反应速率变吗？③ 催化剂改变了什么？

> **答案**：① 都加快 ② 不变（各组分浓度不变）　③ 降低活化能、改变反应历程，不改变 ΔH 和 K

- **对 2 道** → 读「易错边界」，把"恒容充惰气"这一条单独抄一遍。

> **过关线**：例题 3 做对 + 变式做对 = 过关；把"加压"与"恒容充惰气"混为一谈，按未过关处理。

## C-2.6 勒夏特列原理与平衡移动

*反应原理 › 选必一 第2章 化学反应的方向、限度和速率 ｜ Ⅱ · 考频高 ｜ 前置：C-2.2、C-2.3 ｜ 关联：C-2.5、C-2.7　★*

**⚡ 先猜**：升高温度，平衡向吸热方向移动。这是否意味着，升温后放热反应的正反应速率会减小？

### 30 秒概述

勒夏特列原理只给方向，不给数量：改变一个条件，平衡向能削弱这种改变的方向移动。要算"移动多少"，得回到 Q 与 K 的比较。浓度、压强、温度能移动平衡，催化剂不能；"减弱"也不等于"抵消"，新平衡时被改变的量仍高于或低于原平衡。

### 30 秒自评

1. 判断：平衡向正反应方向移动，反应物的转化率一定提高。
2. 判断：升高温度，平衡向吸热方向移动，K 一定增大。
3. 选择：2NO₂(g) ⇌ N₂O₄(g) 达到平衡后压缩体积，混合气体的颜色如何变化？（A）变深　（B）变浅　（C）不变　（D）先变深后变浅，最终比原平衡深

> **答案**：1. ✗（增加一种反应物时，该反应物自身转化率下降）　2. ✗（只有正反应吸热时 K 才增大；正反应放热则 K 减小）　3. D

### 🔑 原理与方程式

**移动的本质**：Q ≠ K。Q < K 向正反应方向移动，Q > K 向逆反应方向移动，直到 Q = K。

**浓度**

- 增大反应物浓度或减小生成物浓度 → Q < K → 正移
- 减小反应物浓度或增大生成物浓度 → Q > K → 逆移

**压强**（通过改变体积实现）：各组分浓度同倍变化，Q 与 K 的大小取决于气体分子数之差 Δn。

- Δn < 0（正反应气体分子数减少）：加压正移
- Δn > 0：加压逆移
- Δn = 0：加压不移动

注意：恒容充惰性气体，各组分浓度不变，平衡不移动；恒压充惰性气体，体积增大，相当于减压，向气体分子数增大的方向移动。

**温度**：升温时正、逆反应速率都加快，吸热方向加快得更多，平衡向吸热方向移动。K 随温度改变：放热反应升温 K 减小，吸热反应升温 K 增大。

**催化剂**：同等加快正、逆反应，不移动平衡，不改变 K。

**勒夏特列原理**：在一个已经达到平衡的体系中，如果改变影响平衡的一个条件（浓度、压强或温度），平衡将向着能够削弱这种改变的方向移动。它只适用于已平衡的体系，且一次只改变一个条件。

**应用**

- 合成氨：及时分离液氨，平衡正移；未反应的 N₂、H₂ 循环使用
- 高炉炼铁：炉内存在 C + CO₂ ⇌ 2CO，高炉气中必然含一定比例的 CO
- CO 中毒急救：HbO₂ + CO ⇌ HbCO + O₂，高压氧使平衡逆向移动，把 CO 从血红蛋白上赶下来

**适用条件**：只用于已达平衡的体系；"减弱"不是"消除"；不能判断速率变化的幅度；对不改变各组分浓度的操作（恒容充惰气）不适用。

**易错边界**
1. 认为"平衡正移"就"转化率提高、产物浓度增大"——体积增大时，产物浓度可能反而减小。
2. 恒容充惰性气体误判为加压正移——总压增大，但各组分浓度不变。
3. 认为升温使放热反应的正反应速率减小——正、逆都增大，只是逆反应增大得更多。

### 例题 1 · L1 基础

已知 2NO₂(g)（红棕色）⇌ N₂O₄(g)（无色）　ΔH < 0，体系已达平衡。

(1) 压缩体积，混合气体的颜色如何变化？

(2) 升高温度，颜色如何变化？

(3) 加入催化剂，颜色如何变化？

**解析**：
(1) **先变深，后变浅，最终比原平衡深**。压缩瞬间 NO₂ 浓度骤增，颜色变深；平衡向气体分子数减小的方向（正反应）移动，消耗部分 NO₂，颜色回浅；但勒夏特列原理只能"减弱"不能"消除"，新平衡时 NO₂ 的浓度仍高于原平衡，所以最终仍比原来深。

(2) **变深**。正反应放热，升温使平衡向吸热的逆反应方向移动，NO₂ 增多。

(3) **不变**。催化剂不移动平衡，只是更快达到平衡。

**💥 陷阱**：第 (1) 问只答"变浅"或"不变"；第 (2) 问认为升温使 NO₂ 减少。

**变式**：保持体积不变，向体系中充入 N₂，颜色如何变化？（不移动，颜色不变）

### 例题 2 · L2 常考

合成氨反应 N₂(g) + 3H₂(g) ⇌ 2NH₃(g)　ΔH < 0 已达平衡。判断下列操作使平衡向哪个方向移动，并说明理由。

① 增大压强　② 升高温度　③ 及时分离出 NH₃　④ 加入铁催化剂　⑤ 恒容充入 Ar

**解析**：
① **正移**。正反应气体分子数由 4 减为 2，加压后 Q < K。

② **逆移**。正反应放热，升温使平衡向吸热方向（逆反应）移动，K 减小。

③ **正移**。减小生成物浓度，Q < K。

④ **不移动**。催化剂同等加快正、逆反应，K 不变。

⑤ **不移动**。恒容充 Ar 使总压增大，但 N₂、H₂、NH₃ 的浓度都不变，Q 仍等于 K。

**💥 陷阱**：第 ⑤ 问看到"压强增大"就答正移。判断平衡移动要看各组分浓度或分压，不看总压。

**变式**：若在恒压条件下充入 Ar，平衡向哪个方向移动？（体积增大，各组分浓度同倍减小，相当于减压，向气体分子数增大的方向即逆反应方向移动）

### 例题 3 · L3 综合

高炉炼铁中发生反应 FeO(s) + CO(g) ⇌ Fe(s) + CO₂(g)　ΔH > 0。

(1) 写出该反应的平衡常数表达式；升高温度，K 和 CO 的转化率如何变化？

(2) 已知 1100 ℃ 时 K = 0.263。该温度下测得高炉中 c(CO₂) = 0.025 mol·L⁻¹、c(CO) = 0.10 mol·L⁻¹，反应是否处于平衡状态？此时 v正 与 v逆 哪个大？

(3) 为什么把高炉加高，也不能使高炉气中的 CO 完全转化？

**解析**：
(1) K = [CO₂] ÷ [CO]。正反应吸热，升温 K 增大，CO 的转化率提高。

(2) Q = 0.025 ÷ 0.10 = 0.25 < 0.263 = K，**未达到平衡**，反应向正反应方向进行，所以 **v正 > v逆**。

(3) 高炉内还存在可逆反应 C + CO₂ ⇌ 2CO（氧化铁是该反应的催化剂），高炉气中必然含有一定比例的 CO。加高高炉只能延长气体与物料的接触时间，不能改变反应的平衡限度。

**💥 陷阱**：第 (2) 问把 Q 写成 [CO] ÷ [CO₂] = 4，误判为逆移；第 (3) 问把"反应不完全"归因于"接触时间不够"。

**变式**：若降低温度，K 如何变化？平衡向哪个方向移动？（K 减小，平衡逆移，CO 的转化率降低）

### ⏱️ 限时挑战（90 秒）

① 勒夏特列原理的内容是什么？② 恒容充入 Ar，平衡移动吗？③ 升高温度，K 一定增大吗？

> **答案**：① 改变影响平衡的一个条件，平衡向能削弱这种改变的方向移动 ② 不移动 ③ 不一定，只有正反应吸热时 K 才增大

### ✅ 接下来做什么

- **3 道全对** → 直接做「例题 3」+ 变式，然后进入 C-2.7。
- **对 2 道** → 读「易错边界」，把"先变深后变浅"的完整表述练一遍。
- **对 0–1 道** → 从「原理与方程式」读起，用 Q 与 K 的比较重做一遍例题 2。

> **过关线**：例题 3 做对 + 变式做对 = 过关；答"加压一定正移"或"升温只加快吸热方向"，按未过关处理。

## C-2.7 工业合成氨的条件选择

*反应原理 › 选必一 第2章 化学反应的方向、限度和速率 ｜ Ⅱ · 考频高 ｜ 前置：C-2.1、C-2.6 ｜ 关联：C-2.4、C-2.5　★*

**⚡ 先猜**：合成氨是放热反应，温度越低，平衡时氨的含量越高。那为什么工厂要把温度升到 500 ℃，而不是在室温下生产？

### 30 秒概述

合成氨把"方向—限度—速率"三张考卷叠在一起：热力学上低温高压有利，动力学上必须高温加催化剂。工业条件不是"最优解"，而是"最划算的解"——500 ℃ 左右、20～50 MPa、铁催化剂、H₂∶N₂ ≈ 2.8～2.9，同时分离液氨、循环原料气。

### 30 秒自评

1. 判断：合成氨是放热反应，所以温度越低越好。
2. 判断：增大压强既能加快合成氨的反应速率，又能提高氨的平衡含量。
3. 简答：为什么要把生成的氨液化分离，并把未反应的 N₂、H₂ 循环使用？

> **答案**：1. ✗（低温速率太慢，铁催化剂也要 400～500 ℃ 才有较高活性）　2. ✓　3. 分离液氨使生成物浓度降低，平衡正移；循环使用提高原料利用率、降低成本。

### 🔑 原理与方程式

**反应**：N₂(g) + 3H₂(g) ⇌ 2NH₃(g)　ΔH = −92 kJ·mol⁻¹，ΔS < 0，气体分子数 4 → 2。

**三个维度**

- 限度：加压正移；降温正移；移走 NH₃ 正移
- 速率：升温加快；加压加快；催化剂加快
- 矛盾：升温利于速率、不利于平衡；加压两头都利，但受设备与动力限制

**条件选择**

- 温度 500 ℃ 左右：铁催化剂在 400～500 ℃ 时活性较高，温度再高速率虽快，氨含量下降、催化剂也易老化
- 压强 20～50 MPa：压强越大氨含量越高，但动力、材料、设备成本随之上升；合成塔钢板已厚达 10 cm，压强再高，氢会穿透钢板泄漏
- 催化剂：以铁为主体的多成分催化剂（Fe₂O₃ 为主，加 Al₂O₃、K₂O、CaO 等助剂），降低活化能
- 投料比：H₂∶N₂ ≈ 2.8～2.9。理论 3∶1 时氨含量最大，但 N₂ 在催化剂表面的吸附活化是控速步骤，适当提高 N₂ 比例有利
- 分离与循环：降温液化分离 NH₃，未反应的 N₂、H₂ 循环使用

**生产流程**：造气 → 净化 → 合成

- 造气：CH₄ + H₂O →(高温) CO + 3H₂；CO + H₂O ⇌(高温、催化剂) CO₂ + H₂　(9-6)
- 净化：除去 H₂S、CO 等会使催化剂中毒的杂质
- 合成：压缩、预热后进入合成塔，出口气体中氨约占 10%～20%

**适用条件**：条件选择要同时考虑平衡转化率、反应速率、催化剂活性、设备耐压、能耗与成本；不能把实验室的"最优条件"直接搬进工厂。

**易错边界**
1. 认为温度越低越好——忽略速率和催化剂的活性温度。
2. 认为压强越大越好——忽略设备、动力与成本，实际采用 20～50 MPa。
3. 认为催化剂能提高氨的平衡含量——只加快达到平衡。

### 例题 1 · L1 基础

写出工业合成氨的化学方程式并注明条件；从平衡和速率两个角度说明增大压强为什么有利。

**解析**：
N₂(g) + 3H₂(g) ⇌ 2NH₃(g)　条件：高温、高压、铁催化剂。

速率角度：加压使 N₂、H₂ 的浓度增大，单位体积内活化分子数增多，有效碰撞增多，速率加快。

平衡角度：正反应气体分子数由 4 减为 2，加压后 Q < K，平衡向正反应方向移动，氨的含量提高。

**💥 陷阱**：漏写可逆号或漏写条件；只答"加压浓度大"，不答气体分子数减少。

**变式**：若把压强从 20 MPa 提高到 50 MPa，氨的平衡含量如何变化？（提高，但提高的幅度受温度制约）

### 例题 2 · L2 常考

在 1 L 密闭容器中进行 N₂(g) + 3H₂(g) ⇌ 2NH₃(g)，起始投入 1.0 mol N₂ 和 3.0 mol H₂，达到平衡时 NH₃ 为 0.60 mol。

(1) 用三段式求 N₂ 的转化率和该温度下的 K；

(2) 若把容器体积压缩到 0.5 L，通过比较 Q 与 K 判断平衡移动的方向，并说明 NH₃ 的物质的量如何变化。

**解析**：
(1) 按 N₂、H₂、NH₃ 的顺序列三段式。

起始浓度/（mol·L⁻¹）：1.0，3.0，0

转化浓度/（mol·L⁻¹）：0.30，0.90，0.60

平衡浓度/（mol·L⁻¹）：0.70，2.10，0.60

α(N₂) = 0.30 ÷ 1.0 × 100% = **30%**

K = 0.60² ÷ (0.70 × 2.10³) = 0.36 ÷ 6.48 ≈ **0.056**

(2) 体积减半，各组分浓度加倍：c(N₂) = 1.40，c(H₂) = 4.20，c(NH₃) = 1.20 mol·L⁻¹。

Q = 1.20² ÷ (1.40 × 4.20³) = 1.44 ÷ 103.7 ≈ 0.014 < 0.056 = K

所以平衡**向正反应方向移动**，NH₃ 的物质的量增大，但小于原来的 2 倍——勒夏特列原理只"减弱"压强增大的影响，不能完全抵消。

**💥 陷阱**：认为浓度加倍 Q 也加倍。Q 中含浓度的 2 次方与 4 次方，变化不是简单的倍数关系，必须代进去算。

**变式**：若温度、体积不变，只向容器中再充入 1.0 mol N₂，Q 与 K 的关系如何？（Q 减小，Q < K，平衡正移）

### 例题 3 · L3 综合

工业合成氨的生产流程为：造气 → 净化 → 合成 → 分离循环。

(1) 写出以天然气为原料造气的两个化学方程式；

(2) 为什么必须除去原料气中的 CO 和 H₂S？

(3) 从平衡和速率两个角度解释为什么选择 500 ℃ 左右、20～50 MPa；

(4) 合成塔出口气体中氨约占 10%～20%，为什么要分离并循环？

(5) 若某厂把压强提高到 100 MPa，可能带来哪些问题？

**解析**：
(1) CH₄ + H₂O →(高温) CO + 3H₂；CO + H₂O ⇌(高温、催化剂) CO₂ + H₂。

(2) CO、H₂S 会使铁催化剂中毒，降低活性甚至永久失活，所以原料气必须净化。

(3) 500 ℃：温度高则速率快，且铁催化剂在 400～500 ℃ 活性较高；代价是平衡时氨含量低于低温，属于"牺牲部分平衡换速率"。20～50 MPa：加压既加快速率，又使平衡向气体分子数减少的方向移动，提高氨含量；但压强再高，动力、材料与设备成本上升。

(4) 分离液氨使生成物浓度降低，Q < K，平衡正移，提高 N₂、H₂ 的转化率；未反应气循环使用，提高原料利用率、降低成本。

(5) 动力消耗剧增；设备、管道耐压要求提高，投资与维护成本上升；氢会穿透厚钢板造成泄漏；综合效益下降。

**💥 陷阱**：把"分离液氨"说成"加快反应速率"（主要作用是移动平衡、提高转化率）；把 500 ℃ 说成"因为高温有利于平衡"。

**变式**：我国科学家研制出在 350 ℃、1 MPa 下工作的新型催化剂，这一成果的意义是什么？（降低反应温度与压强，减少压缩功和能耗，降低设备要求，使合成氨更绿色低碳；说明催化剂研究能突破"高温高压"的限制）

① 写出工业合成氨的适宜条件。② 铁催化剂的作用是什么？③ 为什么要及时分离出液氨？
