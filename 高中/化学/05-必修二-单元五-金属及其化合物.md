## B-5.1 金属的通性与活动性顺序

*必修二 › 第5章 金属及其化合物 ｜ Ⅰ · 考频中 ｜ 前置：A-2 氧化还原反应 ｜ 关联：B-5.2、B-5.4、B-5.5*

**⚡ 先猜**：铁在氯气里点燃得到 FeCl₃，铁粉与硫粉共热却只得到 FeS。同样一个铁原子，为什么"交出去的电子"会从 3 个变成 2 个？

### 30 秒概述

金属原子最外层电子少、半径大，反应中只失电子，所以金属在化合物里只显正价。失电子的难易由活动性顺序决定：越靠前的金属还原性越强，能把后面的金属从盐溶液中置换出来。但"强"不等于"能置换"——钾、钙、钠太活泼，遇盐溶液先与水反应，根本轮不到置换金属。

### 30 秒自评

1. 判断：金属元素在化合物中只显正价，不可能显负价。
2. 判断：铁与稀盐酸反应生成 FeCl₃ 和 H₂。
3. 选择：下列金属投入 CuSO₄ 溶液后，不能置换出铜的是（A）Zn　（B）Fe　（C）Na　（D）Mg

> **答案**：1. ✓（金属无负价）　2. ✗（生成 FeCl₂）　3. C（钠先与水反应）

### 🔑 原理与方程式

**通性**：有金属光泽、有延展性、导电导热；密度和熔点差别极大（汞常温为液体，钨熔点最高）。合金由两种或两种以上元素（至少一种金属）组成，硬度一般大于成分金属，熔点一般低于成分金属。

**原子结构**：最外层电子数一般较少，易失电子；主族金属最高正价 = 最外层电子数；副族金属电子结构复杂，可显多种价态（如 Fe 的 +2、+3）。

**活动性顺序**：K　Ca　Na　Mg　Al　Zn　Fe　Sn　Pb　(H)　Cu　Hg　Ag　Pt　Au

- 与 O₂：4Na + O₂ → 2Na₂O；2Mg + O₂ →(点燃) 2MgO；2Cu + O₂ →(Δ) 2CuO
- 与 Cl₂、S：2Fe + 3Cl₂ →(点燃) 2FeCl₃，而 Fe + S →(Δ) FeS
- 与酸：氢前金属置换出 H₂，Fe + 2HCl → FeCl₂ + H₂↑；氢后金属不与稀盐酸、稀硫酸反应
- 与盐溶液：Zn + CuSO₄ → ZnSO₄ + Cu（强制弱）
- 与水：2Na + 2H₂O → 2NaOH + H₂↑；3Fe + 4H₂O(g) →(高温) Fe₃O₄ + 4H₂

**两处"例外"**：常温下 Fe、Al 遇浓硫酸、浓硝酸会钝化（表面生成致密氧化膜，不是不反应）；浓硫酸、硝酸有强氧化性，与金属反应**不放出 H₂**。

**适用条件**：活动性顺序只适用于水溶液中的置换反应，且 K、Ca、Na 因先与水反应而不能置换盐溶液里的金属；铁与非氧化性酸生成 +2 价，与 Cl₂、硝酸等强氧化剂才生成 +3 价。

**易错边界**
1. 把"金属性强"与"还原性强"当成两回事——活动性顺序越靠前，金属还原性越强，对应阳离子的氧化性越弱。
2. 认为铁与盐酸、氯气都生成 FeCl₃——盐酸只能把铁氧化到 +2，氯气才能到 +3。
3. 认为钠能从 CuSO₄ 溶液置换出铜——钠先与水生成 NaOH，再与 CuSO₄ 生成 Cu(OH)₂ 蓝色沉淀，得不到铜。

### 例题 1 · L1 基础

写出铁分别与氯气、硫反应的化学方程式，指出氧化剂；0.10 mol 铁与足量氯气完全反应，转移电子多少摩尔？

**解析**：
2Fe + 3Cl₂ →(点燃) 2FeCl₃，氧化剂是 **Cl₂**（Cl 由 0 降到 −1）。
Fe + S →(Δ) FeS，氧化剂是 **S**（S 由 0 降到 −2）。
铁与氯气反应时由 0 升到 +3：n(e⁻) = 0.10 × 3 = **0.30 mol**。

**💥 陷阱**：写成 Fe + Cl₂ → FeCl₂，或按 +2 价算电子得 0.20 mol。氯气是强氧化剂，铁一定被氧化到 +3。

**变式**：0.10 mol 铁与足量硫完全反应，转移电子多少摩尔？（0.20 mol）

### 例题 2 · L2 常考

把一小块钠投入盛有 CuSO₄ 溶液的烧杯中。描述现象，写出有关反应的方程式，并说明为什么不能用钠从 CuSO₄ 溶液中置换铜。

**解析**：
现象：钠浮在液面上、熔成光亮小球、四处游动并发出嘶嘶声，溶液中出现**蓝色絮状沉淀**，没有红色固体析出。
2Na + 2H₂O → 2NaOH + H₂↑；CuSO₄ + 2NaOH → Cu(OH)₂↓ + Na₂SO₄。
钠的还原性太强，先与水反应；生成的 NaOH 再与 CuSO₄ 反应，Cu²⁺ 遇到 OH⁻ 就沉淀，轮不到被钠置换。

**💥 陷阱**：直接写 2Na + CuSO₄ → Na₂SO₄ + Cu。水溶液里钠永远先与水反应，置换规律被水的 H⁺ 抢先。

**变式**：把钠换成铁片投入 CuSO₄ 溶液，现象和方程式是什么？（铁片表面析出红色铜，Fe + CuSO₄ → FeSO₄ + Cu）

### 例题 3 · L3 综合

3.9 g Mg-Al 合金与足量稀盐酸完全反应，标准状况下收集到 4.48 L 气体。
(1) 求合金中 Mg、Al 的物质的量；
(2) 求合金中铝的质量分数；
(3) 若把等质量的该合金投入足量 NaOH 溶液，标准状况下气体体积是多少？

**解析**：
(1) n(H₂) = 4.48 ÷ 22.4 = 0.20 mol，转移电子 0.40 mol。
设 n(Mg) = x、n(Al) = y：电子守恒 2x + 3y = 0.40，质量守恒 24x + 27y = 3.90。
解得 x = 0.050、y = 0.10 ⇒ **Mg 0.050 mol、Al 0.10 mol**。
(2) m(Al) = 0.10 × 27 = 2.7 g，w(Al) = 2.7 ÷ 3.9 = **69.2%**（Mg 1.2 g，占 30.8%）。
(3) NaOH 溶液只与铝反应：2Al + 2NaOH + 6H₂O → 2Na[Al(OH)₄] + 3H₂↑
n(H₂) = 0.10 × 3/2 = 0.15 mol，V = 0.15 × 22.4 = **3.36 L**。

**💥 陷阱**：用"平均摩尔质量"硬套；或忘记镁不与 NaOH 溶液反应，把 4.48 L 照搬过来。

**变式**：另取 2.55 g Mg-Al 合金，其中 Mg、Al 的物质的量之比为 1∶1，与足量盐酸反应生成 H₂ 多少升（标准状况）？（设各 a mol，51a = 2.55 ⇒ a = 0.050；n(H₂) = 0.050 + 0.075 = 0.125 mol ⇒ **2.80 L**）

> **答案**：① 只显正价　② 2Fe + 3Cl₂ →(点燃) 2FeCl₃　③ 0.10 mol Mg ⇒ 0.10 mol H₂ ⇒ **2.24 L**

## B-5.2 钠及其化合物

*必修二 › 第5章 金属及其化合物 ｜ Ⅱ · 考频高 ｜ 前置：B-5.1 ｜ 关联：B-5.3、B-5.6　★*

**⚡ 先猜**：把一小匙 Na₂O₂ 投入滴过酚酞的水中，溶液先变红，振荡一会儿红色又褪掉了。红色是谁染上的，又是谁把它抹掉的？

### 30 秒概述

钠的化合物可以排成一条链：Na₂O（氧为 −2 价）— Na₂O₂（氧为 −1 价）— NaOH — Na₂CO₃ — NaHCO₃。Na₂O₂ 不是碱性氧化物，它的强氧化性来自 −1 价的氧，遇水、遇 CO₂ 都放出 O₂。Na₂CO₃ 与 NaHCO₃ 的差别集中在三处：溶解度、热稳定性、与酸反应速率，鉴别与除杂的题全从这里出。

### 30 秒自评

1. 判断：Na₂O₂ 是碱性氧化物，与水反应只生成 NaOH。
2. 判断：Na₂CO₃ 固体中混有少量 NaHCO₃，可用加热的方法除去。
3. 选择：把 Na₂O₂ 投入滴有紫色石蕊试液的水中，现象是（A）只变蓝　（B）先变蓝后褪色　（C）只褪色　（D）无明显变化

> **答案**：1. ✗（过氧化物，还放出 O₂）　2. ✓　3. B（先显碱性变蓝，随后被强氧化性漂白）

### 🔑 原理与方程式

**钠**：银白色、质软、密度 0.968 g·cm⁻³（比水小）、熔点 97.8 ℃（低）。常温下与 O₂ 生成 Na₂O，加热燃烧发出**黄色火焰**生成 Na₂O₂；与水剧烈反应（浮、熔、游、响、红）。保存在煤油中，着火时用干沙扑灭，不能用水或泡沫灭火剂。

- 4Na + O₂ → 2Na₂O（白色）
- 2Na + O₂ →(Δ) Na₂O₂（淡黄色）
- 2Na + 2H₂O → 2NaOH + H₂↑

**Na₂O（白色，碱性氧化物）**

- Na₂O + H₂O → 2NaOH
- Na₂O + CO₂ → Na₂CO₃
- 2Na₂O + O₂ →(Δ) 2Na₂O₂

**Na₂O₂（淡黄色，过氧化物）**：氧为 −1 价，阴、阳离子个数比为 1∶2；强氧化性，可作漂白剂、消毒剂、供氧剂。

- 2Na₂O₂ + 2H₂O → 4NaOH + O₂↑
- 2Na₂O₂ + 2CO₂ → 2Na₂CO₃ + O₂

**NaOH**：白色固体，易潮解，溶于水放热，强碱、有腐蚀性。

- 2NaOH + CO₂ → Na₂CO₃ + H₂O（CO₂ 少量）
- NaOH + CO₂ → NaHCO₃（CO₂ 过量）
- 2Al + 2NaOH + 6H₂O → 2Na[Al(OH)₄] + 3H₂↑

**Na₂CO₃ 与 NaHCO₃**

- 俗名与外观：纯碱、苏打，白色粉末；小苏打，白色晶体
- 溶解性：Na₂CO₃ 易溶，NaHCO₃ 可溶但溶解度明显小
- 水溶液：都显碱性，Na₂CO₃ 碱性强
- 热稳定性：2NaHCO₃ →(Δ) Na₂CO₃ + CO₂↑ + H₂O，Na₂CO₃ 受热不分解
- 与盐酸：Na₂CO₃ 分两步（CO₃²⁻ + H⁺ → HCO₃⁻，HCO₃⁻ + H⁺ → H₂O + CO₂↑），NaHCO₃ 一步且更剧烈
- 相互转化：Na₂CO₃ + CO₂ + H₂O → 2NaHCO₃；NaHCO₃ + NaOH → Na₂CO₃ + H₂O
- 鉴别：加热法；加 CaCl₂ 或 BaCl₂ 溶液（有白色沉淀的是 Na₂CO₃）；逐滴加盐酸（立即冒泡的是 NaHCO₃）
- 除杂：Na₂CO₃ 固体中混 NaHCO₃ 用加热；NaHCO₃ 溶液中混 Na₂CO₃ 通足量 CO₂；Na₂CO₃ 溶液中混 NaHCO₃ 加适量 NaOH

**侯氏制碱法**：NaCl + NH₃ + CO₂ + H₂O → NaHCO₃↓ + NH₄Cl；2NaHCO₃ →(Δ) Na₂CO₃ + CO₂↑ + H₂O。先通 NH₃ 后通 CO₂，让溶液呈碱性以增大 CO₂ 的溶解量。

**适用条件**：Na₂O₂ 与 H₂O、CO₂ 反应时，每 2 mol Na₂O₂ 转移 2 mol 电子、放出 1 mol O₂；只有"逐滴加酸、酸量不足"时才看得到 Na₂CO₃ 的分步反应；NaHCO₃ 与 NaOH 反应需 NaOH 足量才生成 Na₂CO₃。

**易错边界**
1. 把 Na₂O₂ 当碱性氧化物——它与水生成 NaOH 和 O₂，属过氧化物，氧为 −1 价而不是 −2 价。
2. 认为 Na₂CO₃ 遇盐酸一步冒泡——逐滴加酸时先无气泡，生成 HCO₃⁻ 后才冒泡；反过来把 NaHCO₃ 滴入盐酸则立即冒泡。
3. 用 Ca(OH)₂ 溶液鉴别 Na₂CO₃ 与 NaHCO₃——两者都生成白色沉淀 CaCO₃，应改用 CaCl₂ 溶液或加热法。

### 例题 1 · L1 基础

7.8 g Na₂O₂ 与足量水完全反应。求标准状况下生成 O₂ 的体积，以及反应中转移电子的物质的量。

**解析**：
n(Na₂O₂) = 7.8 ÷ 78 = 0.10 mol。
2Na₂O₂ + 2H₂O → 4NaOH + O₂↑ ⇒ n(O₂) = 0.050 mol，V = 0.050 × 22.4 = **1.12 L**。
氧由 −1 价歧化为 0 价和 −2 价：每 2 mol Na₂O₂ 转移 2 mol e⁻，故转移 **0.10 mol** 电子。

**💥 陷阱**：把 O₂ 的系数按 2 算得 2.24 L；或以为氧是 −2 价、反应中没有电子转移。

**变式**：同质量 Na₂O₂ 与足量 CO₂ 完全反应，生成 O₂ 多少摩尔？（0.050 mol）

### 例题 2 · L2 常考

鉴别 Na₂CO₃ 和 NaHCO₃ 时，四位同学设计了如下方案：
甲：分别取少量固体加热，将气体通入澄清石灰水，变浑浊的是 NaHCO₃；
乙：分别配成溶液，滴加 BaCl₂ 溶液，产生白色沉淀的是 Na₂CO₃；
丙：分别配成溶液，滴加酚酞，红色较深的是 NaHCO₃；
丁：分别配成溶液，逐滴加入同浓度盐酸，立即产生气泡的是 NaHCO₃。
(1) 判断各方案是否可行并说明理由；
(2) 再写出一种可行的鉴别方法。

**解析**：
甲**可行**：2NaHCO₃ →(Δ) Na₂CO₃ + CO₂↑ + H₂O，Na₂CO₃ 受热不分解。
乙**可行**：Ba²⁺ + CO₃²⁻ → BaCO₃↓，而 Ba(HCO₃)₂ 可溶，无沉淀。
丙**不可行**：Na₂CO₃ 溶液碱性更强，红色更深的应是 Na₂CO₃，判断正好颠倒。
丁**可行**：Na₂CO₃ 逐滴加酸先发生 CO₃²⁻ + H⁺ → HCO₃⁻，无气泡；NaHCO₃ 立即冒泡。
(2) 用 pH 试纸测定同浓度两种溶液的 pH，pH 大的是 Na₂CO₃。

**💥 陷阱**：认为丙可行，把"小苏打碱性弱"记反；或用 Ca(OH)₂ 鉴别——两者都生成白色沉淀。

**变式**：除去 Na₂CO₃ 溶液中少量的 NaHCO₃，应如何操作？（加入适量 NaOH 溶液：NaHCO₃ + NaOH → Na₂CO₃ + H₂O）

### 例题 3 · L3 综合

将 19.0 g Na₂CO₃ 与 NaHCO₃ 的混合物加热至质量不再变化，冷却后称得固体 15.9 g。
(1) 求原混合物中 NaHCO₃ 的质量；
(2) 求原混合物中 Na₂CO₃ 的质量分数；
(3) 若把 19.0 g 原混合物与足量盐酸反应，标准状况下生成 CO₂ 多少升？

**解析**：
(1) 减重 19.0 − 15.9 = 3.1 g，即 NaHCO₃ 分解出的 CO₂ 与 H₂O 质量之和。
2NaHCO₃ →(Δ) Na₂CO₃ + CO₂↑ + H₂O，每 2 mol（168 g）NaHCO₃ 减重 44 + 18 = 62 g。
n(NaHCO₃) = 2 × 3.1 ÷ 62 = 0.10 mol，m = 0.10 × 84 = **8.4 g**。
(2) m(Na₂CO₃) = 19.0 − 8.4 = 10.6 g，w = 10.6 ÷ 19.0 = **55.8%**。
(3) 碳守恒：n(CO₂) = 0.10 + 0.10 = 0.20 mol，V = 0.20 × 22.4 = **4.48 L**。

**💥 陷阱**：把 3.1 g 全当成 CO₂ 去算；或把 15.9 g 当成 Na₂CO₃ 的总量，忘了其中还包含原混合物里的 Na₂CO₃。

**变式**：若改为把 8.4 g NaHCO₃ 与 10.6 g Na₂CO₃ 的混合物直接与足量盐酸反应，生成 CO₂ 多少摩尔？（碳守恒，仍为 **0.20 mol**）

### ⏱️ 限时挑战（90 秒）

① Na₂O₂ 中氧元素的化合价是多少？② 写出 NaHCO₃ 受热分解的方程式。③ 4.0 g NaOH 与足量 CO₂ 反应生成 NaHCO₃，消耗 CO₂ 多少摩尔？

> **答案**：① −1 价　② 2NaHCO₃ →(Δ) Na₂CO₃ + CO₂↑ + H₂O　③ 0.10 mol NaOH ⇒ **0.10 mol CO₂**

## B-5.3 铝及两性

*必修二 › 第5章 金属及其化合物 ｜ Ⅱ · 考频高 ｜ 前置：B-5.1 ｜ 关联：B-5.2、B-5.6　★*

**⚡ 先猜**：铝锅烧水、煮饭都没事，可一旦用来煮加了小苏打或纯碱的食物，锅壁很快发暗、变薄。同样是"用水煮"，差别出在哪里？

### 30 秒概述

铝是活泼金属，却因为表面那层致密的 Al₂O₃ 薄膜而"看起来不活泼"——这就是钝化。除去氧化膜后，铝既能与酸反应，也能与强碱反应，根子在 Al₂O₃ 与 Al(OH)₃ 都是两性的：既溶于强酸，也溶于强碱。铝热反应把铝的还原性用到极致，用铝把铁、铬、锰从氧化物里"抢"出来。

### 30 秒自评

1. 判断：Al₂O₃ 既能与盐酸反应，又能与 NaOH 溶液反应，是两性氧化物。
2. 判断：实验室制备 Al(OH)₃ 时，用 NaOH 溶液代替氨水可以提高产率。
3. 选择：除去 MgO 粉末中混有的少量 Al₂O₃，应选用的试剂是（A）稀盐酸　（B）NaOH 溶液　（C）稀硫酸　（D）氨水

> **答案**：1. ✓　2. ✗（NaOH 过量会使 Al(OH)₃ 溶解，产率反而低）　3. B

### 🔑 原理与方程式

**铝**：银白色、密度 2.70 g·cm⁻³、熔点 660 ℃；表面易生成致密氧化膜，常温下遇浓硫酸、浓硝酸钝化。

- 4Al + 3O₂ →(点燃) 2Al₂O₃
- 2Al + 6HCl → 2AlCl₃ + 3H₂↑
- 2Al + 2NaOH + 6H₂O → 2Na[Al(OH)₄] + 3H₂↑
- 2Al + Fe₂O₃ →(高温) 2Fe + Al₂O₃

**两性氧化物 Al₂O₃**（白色，熔点高，耐火材料）

- Al₂O₃ + 6HCl → 2AlCl₃ + 3H₂O
- Al₂O₃ + 2NaOH + 3H₂O → 2Na[Al(OH)₄]

**两性氢氧化物 Al(OH)₃**（白色胶状沉淀）

- Al(OH)₃ + 3HCl → AlCl₃ + 3H₂O
- Al(OH)₃ + NaOH → Na[Al(OH)₄]
- 制备：Al³⁺ + 3NH₃·H₂O → Al(OH)₃↓ + 3NH₄⁺（用氨水而不用 NaOH，防止沉淀溶解）
- 受热分解：2Al(OH)₃ →(Δ) Al₂O₃ + 3H₂O

**铝热反应**：铝与 Fe₂O₃、Fe₃O₄、Cr₂O₃、MnO₂ 等在高温下反应，放出大量热，生成 Al₂O₃ 和相应的金属。

- 8Al + 3Fe₃O₄ →(高温) 9Fe + 4Al₂O₃
- 用途：焊接钢轨，冶炼铬、锰、钒等难熔金属
- 现象：剧烈反应、放出大量热、纸漏斗被烧穿，有熔融物落入砂中

**适用条件**：铝与强碱反应时，氧化剂是**水**而不是 NaOH，NaOH 只起破坏氧化膜、提供碱性环境的作用；Al(OH)₃ 只溶于强酸、强碱，不溶于弱酸（如碳酸）、弱碱（如氨水），所以用氨水制备不会把它溶掉；铝热反应需高温引燃（镁条 + 氯酸钾），铝粉与金属氧化物必须干燥。

**易错边界**
1. 把铝与 NaOH 的反应写成 2Al + 2NaOH → 2Na[Al(OH)₄] + H₂↑——漏掉 6H₂O，氢、氧都不守恒。
2. 认为 Al(OH)₃ 能溶于氨水——氨水是弱碱，Al(OH)₃ 只溶于强碱。
3. 把铝热反应写成 Al + Fe₂O₃ → Fe + Al₂O₃——系数没有配平，且"高温"条件不能漏。

### 例题 1 · L1 基础

2.7 g 铝与足量 NaOH 溶液完全反应。求标准状况下生成 H₂ 的体积、转移电子的物质的量，并指出氧化剂。

**解析**：
n(Al) = 2.7 ÷ 27 = 0.10 mol。
2Al + 2NaOH + 6H₂O → 2Na[Al(OH)₄] + 3H₂↑
n(H₂) = 0.10 × 3/2 = 0.15 mol，V = 0.15 × 22.4 = **3.36 L**；转移电子 0.10 × 3 = **0.30 mol**。
氧化剂是 **H₂O**（H 由 +1 降到 0），NaOH 既不是氧化剂也不是还原剂。

**💥 陷阱**：把 NaOH 当氧化剂；或漏写 6H₂O 导致配平错，算出 H₂ 只有 0.10 mol。

**变式**：同质量铝与足量盐酸反应，生成 H₂ 多少升？（同样 **3.36 L**；等量的铝无论与酸还是与强碱反应，失电子数相同）

### 例题 2 · L2 常考

向 2 mL 0.1 mol·L⁻¹ AlCl₃ 溶液中逐滴加入 0.1 mol·L⁻¹ NaOH 溶液至过量。
(1) 描述整个过程中的现象，写出对应的离子方程式；
(2) 实验室制备 Al(OH)₃ 时为什么改用氨水？
(3) 若把 AlCl₃ 溶液换成 Al₂(SO₄)₃ 溶液，现象是否相同？

**解析**：
(1) 开始出现白色胶状沉淀：Al³⁺ + 3OH⁻ → Al(OH)₃↓；
继续滴加，沉淀逐渐溶解、溶液变澄清：Al(OH)₃ + OH⁻ → [Al(OH)₄]⁻。
(2) 氨水是弱碱，只能把 Al³⁺ 沉淀成 Al(OH)₃，不能继续溶解它：Al³⁺ + 3NH₃·H₂O → Al(OH)₃↓ + 3NH₄⁺。用 NaOH 时稍一过量沉淀就溶解，产率低且难控制。
(3) 现象相同，离子方程式完全一样，SO₄²⁻ 不参与反应。

**💥 陷阱**：只写第一步沉淀，漏掉"过量时沉淀溶解"；或把氨水直接写成 OH⁻，混淆强弱碱。

**变式**：向 Na[Al(OH)₄] 溶液中逐滴加入稀盐酸至过量，现象如何？（先出现白色沉淀：[Al(OH)₄]⁻ + H⁺ → Al(OH)₃↓ + H₂O；盐酸过量后沉淀溶解：Al(OH)₃ + 3H⁺ → Al³⁺ + 3H₂O）

### 例题 3 · L3 综合

5.1 g Mg-Al 合金投入足量 NaOH 溶液中，充分反应后剩余固体 2.4 g。
(1) 求合金中铝的质量分数；
(2) 求标准状况下生成 H₂ 的体积；
(3) 若把 5.1 g 同种合金投入足量稀盐酸，标准状况下生成 H₂ 多少升？

**解析**：
(1) 镁不与 NaOH 溶液反应，剩余的 2.4 g 固体就是镁，m(Al) = 5.1 − 2.4 = 2.7 g，w(Al) = 2.7 ÷ 5.1 = **52.9%**。
(2) n(Al) = 0.10 mol ⇒ n(H₂) = 0.15 mol ⇒ V = **3.36 L**。
(3) n(Mg) = 2.4 ÷ 24 = 0.10 mol ⇒ H₂ 0.10 mol；加上铝的 0.15 mol，共 0.25 mol ⇒ V = 0.25 × 22.4 = **5.60 L**。

**💥 陷阱**：把 2.4 g 当成铝；或第(3)问只算镁、漏掉铝也与盐酸反应。

**变式**：若把 NaOH 溶液换成足量稀硫酸，剩余固体是多少克？（镁、铝都溶解，**无固体剩余**，生成 H₂ 5.60 L）

### ⏱️ 限时挑战（90 秒）

① Al(OH)₃ 属于哪类氢氧化物？② 铝热反应需要什么条件？③ 5.4 g 铝与足量 NaOH 溶液反应，生成 H₂ 多少摩尔？

> **答案**：① 两性氢氧化物（既溶于强酸又溶于强碱）　② 高温（镁条引燃）　③ 0.20 mol Al ⇒ **0.30 mol H₂**

### ✅ 接下来做什么

- **3 道全对** → 做「例题 3」+ 变式，进入 B-5.4。
- **对 2 道** → 读「易错边界」，重点记 Al(OH)₃ 的两条溶解方程式。
- **对 0–1 道** → 从「原理与方程式」读起，先把"铝 → 氧化铝 → 氢氧化铝"的两性各配一个酸、一个碱的方程式。

## B-5.4 铁及铁的化合物

*必修二 › 第5章 金属及其化合物 ｜ Ⅱ · 考频高 ｜ 前置：B-5.1 ｜ 关联：B-5.3、B-5.5、B-5.7　★*

**⚡ 先猜**：新制的 Fe(OH)₂ 是白色的，可几乎没人在试管里把它"白"着看满一分钟。白色是被谁偷走的？

### 30 秒概述

铁的化合物按价态分两支：+2 支（FeO、Fe(OH)₂、Fe²⁺）与 +3 支（Fe₂O₃、Fe(OH)₃、Fe³⁺），Fe₃O₄ 是两支的"合体"。Fe³⁺ 有氧化性，能被 Fe、Cu、I⁻ 还原；Fe²⁺ 以还原性为主，遇 O₂、Cl₂、酸性 KMnO₄ 就变 +3。KSCN 只认 Fe³⁺，所以检验 Fe²⁺ 要走"先加 KSCN 不变红、再加氧化剂变红"这条两步路。

### 30 秒自评

1. 判断：Fe₃O₄ 与足量盐酸反应只生成 FeCl₂。
2. 判断：向某溶液中滴加 KSCN 溶液不变红，再滴加氯水变红，说明原溶液中含有 Fe²⁺。
3. 选择：除去 FeCl₂ 溶液中少量的 FeCl₃，应加入（A）铁粉　（B）氯水　（C）NaOH 溶液　（D）铜粉

> **答案**：1. ✗（同时生成 FeCl₂ 和 FeCl₃）　2. ✓　3. A

### 🔑 原理与方程式

**三种氧化物**

- FeO：黑色粉末，碱性氧化物。FeO + 2H⁺ → Fe²⁺ + H₂O；在空气中受热易被氧化
- Fe₂O₃：红棕色粉末，俗称铁红，可作颜料。Fe₂O₃ + 6H⁺ → 2Fe³⁺ + 3H₂O
- Fe₃O₄：黑色晶体，有磁性，俗称磁性氧化铁，可看作 FeO·Fe₂O₃。Fe₃O₄ + 8H⁺ → Fe²⁺ + 2Fe³⁺ + 4H₂O

**两种氢氧化物**

- Fe(OH)₂：白色絮状沉淀。Fe²⁺ + 2OH⁻ → Fe(OH)₂↓；被氧化时"白色 → 灰绿色 → 红褐色"：4Fe(OH)₂ + O₂ + 2H₂O → 4Fe(OH)₃
- Fe(OH)₃：红褐色沉淀。Fe³⁺ + 3OH⁻ → Fe(OH)₃↓；受热分解 2Fe(OH)₃ →(Δ) Fe₂O₃ + 3H₂O
- 制备 Fe(OH)₂ 必须隔绝氧气：用煮沸过的蒸馏水配溶液，先把装置内空气排尽，滴管伸入液面下滴加

**Fe²⁺ 与 Fe³⁺ 的转化**

- Fe³⁺ → Fe²⁺（加强还原剂）：2Fe³⁺ + Fe → 3Fe²⁺；2Fe³⁺ + Cu → 2Fe²⁺ + Cu²⁺；2Fe³⁺ + 2I⁻ → 2Fe²⁺ + I₂
- Fe²⁺ → Fe³⁺（加强氧化剂）：2Fe²⁺ + Cl₂ → 2Fe³⁺ + 2Cl⁻；4Fe²⁺ + O₂ + 4H⁺ → 4Fe³⁺ + 2H₂O；5Fe²⁺ + MnO₄⁻ + 8H⁺ → 5Fe³⁺ + Mn²⁺ + 4H₂O

**检验**

- Fe³⁺：滴加 KSCN 溶液变血红色，Fe³⁺ + 3SCN⁻ → Fe(SCN)₃
- Fe²⁺：先加 KSCN 溶液不变红，再滴加氯水（或 H₂O₂）变血红色

**应用**：配制 FeSO₄ 溶液加少量铁粉（防止 Fe²⁺ 被氧化）和稀硫酸（抑制 Fe²⁺ 水解）；FeCl₃ 溶液蚀刻铜箔制印制电路板。

**适用条件**：KSCN 只能检验 Fe³⁺，不能直接检验 Fe²⁺；用氯水氧化 Fe²⁺ 会引入 Cl⁻，若原溶液含 Fe³⁺ 或有其他还原性离子，必须先排除干扰；观察 Fe(OH)₂ 的白色必须用新制溶液并隔绝空气。

**易错边界**
1. 认为 Fe₃O₄ 与盐酸只生成 FeCl₂——它同时含 +2、+3 价铁，生成两种盐。
2. 认为 KSCN 能直接检验 Fe²⁺——KSCN 只与 Fe³⁺ 显色；检验 Fe²⁺ 必须"先不变红、再加氧化剂变红"。
3. 认为铁与足量稀硝酸也生成 Fe²⁺——稀硝酸是强氧化剂，铁少量时生成 Fe³⁺；只有铁过量，多余的铁才把 Fe³⁺ 还原成 Fe²⁺。

### 例题 1 · L1 基础

向 FeSO₄ 溶液中滴加 NaOH 溶液，白色沉淀迅速变灰绿色，最后变红褐色。
(1) 写出生成沉淀与被氧化的化学方程式；
(2) 0.10 mol FeSO₄ 完全转化为 Fe(OH)₃，消耗 O₂ 多少摩尔？

**解析**：
(1) FeSO₄ + 2NaOH → Fe(OH)₂↓ + Na₂SO₄；4Fe(OH)₂ + O₂ + 2H₂O → 4Fe(OH)₃。
(2) 由 4Fe(OH)₂ ～ O₂ 得 n(O₂) = 0.10 ÷ 4 = **0.025 mol**。

**💥 陷阱**：按 2Fe(OH)₂ + O₂ 计算得 0.050 mol。系数 4 不能丢。

**变式**：这些 Fe(OH)₃ 受热完全分解，可得 Fe₂O₃ 多少摩尔？（铁守恒，0.10 ÷ 2 = **0.050 mol**）

### 例题 2 · L2 常考

某 FeSO₄ 溶液敞口放置一段时间后颜色变黄。
(1) 用离子方程式解释变黄的原因；
(2) 设计实验证明该溶液中既有 Fe³⁺ 又有 Fe²⁺，写出操作、现象与结论；
(3) 实验室配制 FeSO₄ 溶液时，常加入少量铁粉和稀硫酸，各起什么作用？

**解析**：
(1) 4Fe²⁺ + O₂ + 4H⁺ → 4Fe³⁺ + 2H₂O，Fe²⁺ 被溶解氧氧化成黄色的 Fe³⁺。
(2) 取少量溶液，滴加 KSCN 溶液，变血红色 ⇒ 含 **Fe³⁺**；另取少量溶液，滴加酸性 KMnO₄ 溶液，紫红色褪去 ⇒ 含 **Fe²⁺**（Fe²⁺ 被氧化，MnO₄⁻ 被还原）。
(3) 铁粉把 Fe³⁺ 还原为 Fe²⁺（2Fe³⁺ + Fe → 3Fe²⁺），防止 Fe²⁺ 被氧化；稀硫酸抑制 Fe²⁺ 水解，保持溶液澄清。

**💥 陷阱**：只加 KSCN 变红就断定"只有 Fe³⁺"；或用 NaOH 溶液检验 Fe²⁺——白色沉淀被氧化太快，现象难观察。

**变式**：若向该变黄的溶液中加入足量铁粉、充分反应后过滤，滤液中主要含哪种阳离子？（Fe²⁺，Fe³⁺ 全部被还原）

### 例题 3 · L3 综合

用 2.0 L 0.50 mol·L⁻¹ 的 FeCl₃ 溶液蚀刻铜箔（2Fe³⁺ + Cu → 2Fe²⁺ + Cu²⁺）。
(1) 指出氧化剂；
(2) 最多能溶解铜多少克？
(3) 蚀刻后（Fe³⁺ 恰好完全反应）溶液中主要阳离子有哪些？物质的量各是多少？
(4) 要使蚀刻液再生，可通入足量 Cl₂，需 Cl₂ 多少摩尔？

**解析**：
(1) Fe³⁺ 由 +3 降到 +2，氧化剂是 **Fe³⁺**。
(2) n(FeCl₃) = 2.0 × 0.50 = 1.0 mol ⇒ n(Cu) = 0.50 mol，m = 0.50 × 64 = **32 g**。
(3) Fe²⁺ **1.0 mol**、Cu²⁺ **0.50 mol**（阴离子为 Cl⁻ 3.0 mol）。
(4) 2Fe²⁺ + Cl₂ → 2Fe³⁺ + 2Cl⁻ ⇒ n(Cl₂) = **0.50 mol**。

**💥 陷阱**：按 Fe³⁺ 与 Cu 为 1∶1 算铜（得 64 g）；第(4)问把 Cu²⁺ 也算进去，多耗 Cl₂。

**变式**：向蚀刻后的废液中加入过量铁粉，过滤，滤渣的成分是什么？（置换出的铜和过量的铁；滤液主要是 FeCl₂）

### ⏱️ 限时挑战（90 秒）

① 检验 Fe³⁺ 用什么试剂？② Fe(OH)₂ 被氧化时的颜色变化顺序是什么？③ 2.0 mol FeCl₃ 与足量铜反应，最多溶解铜多少摩尔？

> **答案**：① KSCN 溶液（变血红色）　② 白色 → 灰绿色 → 红褐色　③ **1.0 mol**

### ✅ 接下来做什么

- **对 2 道** → 读「易错边界」，把 Fe²⁺、Fe³⁺ 的转化各写两条方程式并标电子数。
- **对 0–1 道** → 从「原理与方程式」读起，先做一张"价态—物质—颜色"对照表，再记 KSCN 的用法。

## B-5.5 铜与金属冶炼

*必修二 › 第5章 金属及其化合物 ｜ Ⅰ · 考频中 ｜ 前置：B-5.1 ｜ 关联：B-5.4、B-5.6*

**⚡ 先猜**：铜排在氢的后面，却偏偏能溶于稀硝酸，还能被热的浓硫酸"吃掉"。同样是酸，差别到底出在谁身上？

### 30 秒概述

铜是不活泼金属的代表：不与稀盐酸、稀硫酸反应，却能与浓硫酸、硝酸这些强氧化性酸反应，也能被 Fe³⁺ 氧化。正因为金属离子被还原的难易不同，冶炼才分成几路：热分解法（Hg、Ag）、热还原法（Fe、Cu、W）、电解法（Na、Mg、Al），以及金、铂以游离态直接获取。"活动性越弱越容易还原"，是这一整节的判断轴。

### 30 秒自评

1. 判断：所有金属都能用热还原法冶炼。
2. 判断：金、铂化学性质稳定，在自然界中能以游离态存在。
3. 选择：工业上冶炼铝采用的方法是（A）热分解法　（B）热还原法　（C）电解法　（D）置换法

> **答案**：1. ✗（活泼金属只能电解）　2. ✓　3. C

### 🔑 原理与方程式

**铜**：紫红色、有金属光泽，导电导热性仅次于银；不与稀盐酸、稀硫酸反应。

- 2Cu + O₂ →(Δ) 2CuO（黑色）
- 2Cu + S →(Δ) Cu₂S
- Cu + Cl₂ →(点燃) CuCl₂
- Cu + 2H₂SO₄(浓) →(Δ) CuSO₄ + SO₂↑ + 2H₂O
- 3Cu + 8HNO₃(稀) → 3Cu(NO₃)₂ + 2NO↑ + 4H₂O
- 2Cu + O₂ + CO₂ + H₂O → Cu₂(OH)₂CO₃（铜绿）

**铜的化合物**：CuO 黑色、Cu₂O 红色、Cu(OH)₂ 蓝色沉淀、CuSO₄·5H₂O 蓝色晶体（胆矾）；Cu²⁺ 溶液显蓝色。

**冶炼方法**

- 热分解法（不活泼金属）：2HgO →(Δ) 2Hg + O₂↑；HgS + O₂ →(焙烧) Hg + SO₂
- 热还原法（较活泼金属）：Fe₂O₃ + 3CO →(高温) 2Fe + 3CO₂；CuO + H₂ →(Δ) Cu + H₂O；WO₃ + 3H₂ →(高温) W + 3H₂O
- 电解法（活泼金属）：2NaCl(熔融) →(通直流电) 2Na + Cl₂↑；2Al₂O₃ →(通直流电、冰晶石) 4Al + 3O₂↑；MgCl₂(熔融) →(通直流电) Mg + Cl₂↑
- 游离态直接获取：金、铂（以及少量银、铜）

**炼铁与炼钢**：铁矿石（赤铁矿 Fe₂O₃、磁铁矿 Fe₃O₄、菱铁矿 FeCO₃）与焦炭、石灰石在高炉中反应得到生铁（含碳 2%～4.3%，硬而脆）；再降低含碳量、除去杂质得到钢（含碳 0.03%～2%，硬而韧、有弹性）。在碳钢中加入一种或几种合金元素，得到合金钢。

**适用条件**：热还原法要求金属的活动性弱于所用还原剂；电解法必须用**熔融态**（水溶液中得不到 Na、Mg、Al）；Al₂O₃ 熔点高，需加冰晶石助熔；铜与浓硫酸反应需加热，且随硫酸变稀反应会自行停止。

**易错边界**
1. 认为电解法可以在水溶液中进行——Na、Mg、Al 会先与水反应，必须电解熔融的氯化钠、氯化镁、氧化铝。
2. 认为铜与稀硫酸反应放出 H₂——铜在氢后不与稀硫酸反应；与浓硫酸反应放的是 SO₂。
3. 认为热还原法适用于所有金属——活泼金属离子氧化性太弱，只能用还原能力最强的电解法。

### 例题 1 · L1 基础

写出下列冶炼反应的化学方程式，并指出还原剂：① 电解熔融氯化钠制钠；② 一氧化碳还原赤铁矿；③ 电解熔融氧化铝制铝。

**解析**：
① 2NaCl(熔融) →(通直流电) 2Na + Cl₂↑，Na⁺ 被还原、Cl⁻ 被氧化，NaCl 既是氧化剂又是还原剂，没有外加还原剂。
② Fe₂O₃ + 3CO →(高温) 2Fe + 3CO₂，还原剂是 **CO**。
③ 2Al₂O₃ →(通直流电、冰晶石) 4Al + 3O₂↑，Al³⁺ 被还原、O²⁻ 被氧化。

**💥 陷阱**：把电解反应说成"没有氧化还原"；或硬给电解熔融 NaCl 安一个还原剂。

**变式**：工业上为什么不用电解熔融 AlCl₃ 的方法制铝？（AlCl₃ 是共价化合物，熔融时不导电，只能电解熔融的 Al₂O₃）

### 例题 2 · L2 常考

由铜制取硫酸铜有三种方案：
① Cu 与浓硫酸共热；② Cu 在空气中灼烧成 CuO，再加稀硫酸；③ Cu 直接加入稀硫酸。
(1) 写出①②的化学方程式，说明③能否进行；
(2) 从原料利用率、环境保护两个角度评价三种方案，指出最合理的一种。

**解析**：
(1) ① Cu + 2H₂SO₄(浓) →(Δ) CuSO₄ + SO₂↑ + 2H₂O；② 2Cu + O₂ →(Δ) 2CuO，CuO + H₂SO₄ → CuSO₄ + H₂O。③ 不能，铜在氢后，不与稀硫酸反应。
(2) ① 每生成 1 mol CuSO₄ 要消耗 2 mol H₂SO₄，其中一半被还原成 SO₂ 逸出，酸利用率低且污染空气；② 每生成 1 mol CuSO₄ 只消耗 1 mol H₂SO₄，无污染性气体，原子利用率高，但要灼烧耗能。综合看 **② 最合理**。

**💥 陷阱**：只比"反应快慢"，忽略 SO₂ 污染与硫酸用量；或认为③可行，把浓硫酸的反应条件张冠李戴。

**变式**：方案②中 1.0 mol 铜完全转化，理论上消耗 O₂ 和 H₂SO₄ 各多少摩尔？（**0.50 mol O₂、1.0 mol H₂SO₄**）

### 例题 3 · L3 综合

用 100 t 含 Fe₂O₃ 80%（质量分数）的赤铁矿炼铁。
(1) 理论上可炼得铁多少吨？
(2) 需消耗 CO 多少吨？
(3) 若所得生铁含铁 96%，可得生铁多少吨？
(4) 生铁与钢的主要差别是什么？

**解析**：
(1) m(Fe₂O₃) = 100 × 80% = 80 t，n = 80 × 10⁶ g ÷ 160 g·mol⁻¹ = 5.0 × 10⁵ mol。
Fe₂O₃ + 3CO →(高温) 2Fe + 3CO₂ ⇒ n(Fe) = 1.0 × 10⁶ mol，m = 1.0 × 10⁶ × 56 = 5.6 × 10⁷ g = **56 t**。
(2) n(CO) = 1.5 × 10⁶ mol，m = 1.5 × 10⁶ × 28 = 4.2 × 10⁷ g = **42 t**。
(3) 生铁质量 = 56 ÷ 0.96 = **58.3 t**。
(4) 差别在含碳量：生铁 2%～4.3%，硬而脆；钢 0.03%～2%，硬而韧、有弹性。

**💥 陷阱**：把 100 t 矿石直接当 Fe₂O₃；忘记 Fe₂O₃ 中 Fe 的系数 2；t 与 g 换算差 10⁶ 倍。

**变式**：若改用 100 t 含 Fe₃O₄ 80% 的磁铁矿，理论上可炼得铁多少吨？（Fe₃O₄ 中 Fe 占 168/232 ≈ 72.4%，80 × 72.4% ≈ **57.9 t**）

> **答案**：① 电解熔融 Al₂O₃（加冰晶石助熔）　② SO₂　③ **56 t**

## B-5.6 化学反应中的能量变化

*必修二 › 第5章 金属及其化合物 ｜ Ⅱ · 考频高 ｜ 前置：A-4 化学键 ｜ 关联：B-5.3、B-5.7　★*

**⚡ 先猜**：木炭要点燃才能烧，碳酸钙要高温才分解。同样都"要加热"，为什么一个放热、一个吸热？

### 30 秒概述

化学反应的能量变化，根子在化学键：断键要吸能，成键会放能，两者之差就是反应热。断键吸收的总能量小于成键放出的总能量，反应放热，ΔH < 0；反之吸热。用"反应物总能量"与"生成物总能量"的高低来比，结论完全一样，这是判断吸放热最快的一把尺子。

### 30 秒自评

1. 判断：需要加热才能发生的反应一定是吸热反应。
2. 判断：化学键断裂吸收能量，化学键形成放出能量。
3. 选择：下列反应属于吸热反应的是（A）铝热反应　（B）生石灰与水反应　（C）Ba(OH)₂·8H₂O 与 NH₄Cl 反应　（D）铁与盐酸反应

> **答案**：1. ✗（加热只是引发条件）　2. ✓　3. C

### 🔑 原理与方程式

**放热反应**：燃烧（CH₄ + 2O₂ →(点燃) CO₂ + 2H₂O）、中和（NaOH + HCl → NaCl + H₂O）、金属与酸、大多数化合反应、铝热反应、生石灰与水（CaO + H₂O → Ca(OH)₂）、Na₂O₂ 与水。

**吸热反应**：大多数分解反应（CaCO₃ →(Δ) CaO + CO₂↑、2NaHCO₃ →(Δ) Na₂CO₃ + CO₂↑ + H₂O）、灼热的炭与二氧化碳（C + CO₂ →(高温) 2CO）、Ba(OH)₂·8H₂O 与 NH₄Cl、炭与水蒸气（C + H₂O(g) →(高温) CO + H₂）。

**键能解释**：ΔH = 反应物键能总和 − 生成物键能总和；也等于 生成物总能量 − 反应物总能量。

- 断键吸能、成键放能；断键吸收 < 成键放出 ⇒ 放热，ΔH < 0
- 反应物总能量 > 生成物总能量 ⇒ 放热；反应物总能量 < 生成物总能量 ⇒ 吸热
- 能量变化图（文字描述）：纵轴为能量，反应物一条水平线、生成物一条水平线；放热时生成物线在下方，吸热时在上方

**能量转化**：化学能可转化为热能、光能、电能。化学能→电能靠原电池，电能→化学能靠电解池。

**适用条件**：反应吸热还是放热与"是否需要加热"无关（燃烧需点燃，仍是放热反应）；ΔH 的符号与吸放热一一对应，放热为负；用键能计算时，必须取气态物质的键能，且每种键要乘上键的数目。

**易错边界**
1. 把"需要加热"当成"吸热反应"——加热只是引发条件，煤的燃烧、铝热反应都要引发，却都是放热反应。
2. 计算键能时漏乘键的个数——2H₂ + O₂ → 2H₂O 中 H—O 键共 4 个，不是 2 个。
3. 把 ΔH 的正负记反——放热 ΔH < 0、吸热 ΔH > 0；热化学方程式中还要标出物质状态。

### 例题 1 · L1 基础

判断下列反应是放热反应还是吸热反应，并说明依据：① 甲烷燃烧；② 碳酸钙高温分解；③ 盐酸与氢氧化钠溶液中和；④ 灼热的炭与二氧化碳反应。

**解析**：
① **放热**（燃烧）；② **吸热**（分解，需持续高温）；③ **放热**（中和反应）；④ **吸热**（C + CO₂ →(高温) 2CO）。
依据：比较反应物总能量与生成物总能量的高低，放热反应中反应物总能量高于生成物。

**💥 陷阱**：拿"是否需要加热"当依据，把②③判反，或把①判成吸热。

**变式**：把②改成"铝热反应"，判断结果是什么？（**放热**；铝热反应虽要镁条引燃，但反应本身放出大量热）

### 例题 2 · L2 常考

已知 H—H 键能 436 kJ·mol⁻¹、Cl—Cl 键能 243 kJ·mol⁻¹、H—Cl 键能 431 kJ·mol⁻¹。
(1) 写出 H₂ 与 Cl₂ 反应生成 HCl 的化学方程式；
(2) 计算该反应的 ΔH；
(3) 1 mol H₂ 完全反应，放出或吸收多少热量？

**解析**：
(1) H₂ + Cl₂ →(点燃) 2HCl。
(2) 断键吸收 436 + 243 = 679 kJ；成键放出 2 × 431 = 862 kJ。
ΔH = 679 − 862 = **−183 kJ·mol⁻¹**（放热）。
(3) 按方程式，1 mol H₂ 对应 2 mol HCl，放热 **183 kJ**。

**💥 陷阱**：只算 1 个 H—Cl 键，得 679 − 431 = +248 kJ·mol⁻¹ 的吸热结论；或把 ΔH 写成 +183。

**变式**：若 H—Cl 键能改为 400 kJ·mol⁻¹，反应是放热还是吸热？（679 − 800 = −121 kJ·mol⁻¹，**仍放热**）

### 例题 3 · L3 综合

已知键能：H—H 436 kJ·mol⁻¹、O=O 498 kJ·mol⁻¹、O—H 463 kJ·mol⁻¹。
(1) 写出氢气燃烧生成气态水的化学方程式，计算 ΔH；
(2) 1 kg 氢气完全燃烧生成气态水，放出多少热量？
(3) 若生成的是液态水，放出的热量比(2)多还是少？为什么？

**解析**：
(1) 2H₂ + O₂ →(点燃) 2H₂O(g)
断键吸收 2 × 436 + 498 = 1370 kJ；成键放出 4 × 463 = 1852 kJ。
ΔH = 1370 − 1852 = **−482 kJ·mol⁻¹**。
(2) 1 kg H₂ 为 1000 ÷ 2 = 500 mol。每 2 mol H₂ 放热 482 kJ，即每 1 mol H₂ 放热 241 kJ。
Q = 500 × 241 = **1.205 × 10⁵ kJ**。
(3) **多**。气态水变成液态水还要放出液化热，生成液态水时放出的总热量更大，ΔH 更负。

**💥 陷阱**：把 482 kJ 当成 1 mol H₂ 的放热量，结果翻倍成 2.41 × 10⁵ kJ；或成键时只算 2 个 O—H。

**变式**：若 1 mol H₂ 燃烧生成液态水放出 286 kJ 热量，1 kg 氢气生成液态水放热多少？（500 × 286 = **1.43 × 10⁵ kJ**）

### ⏱️ 限时挑战（90 秒）

① 放热反应的 ΔH 是正还是负？② 断键吸能还是放能？③ 1 mol CH₄ 完全燃烧放出 890 kJ 热量，4 g CH₄ 燃烧放出多少热量？

> **答案**：① **负**　② 吸能　③ 0.25 mol ⇒ **222.5 kJ**

## B-5.7 原电池与金属腐蚀的初步

*必修二 › 第5章 金属及其化合物 ｜ Ⅱ · 考频高 ｜ 前置：B-5.1、B-5.6 ｜ 关联：B-5.4　★*

**⚡ 先猜**：把铜片单独插进稀硫酸，什么也不发生；一旦用导线把铜片和锌片连起来，气泡却从铜片表面冒了出来。铜是什么时候学会"放氢气"的？

### 30 秒概述

原电池把化学能直接变成电能。它由两极、电解质溶液和闭合回路组成，本质是一个自发的氧化还原反应被"拆成两半"：负极失电子发生氧化，正极得电子发生还原；电子走外电路，离子走内电路。钢铁的腐蚀就是无数个微原电池在起作用，所以防护思路同样来自原电池——让更活泼的金属替铁"挨氧化"。

### 30 秒自评

1. 判断：原电池中电子由负极经外电路流向正极，电流方向与电子流向相反。
2. 判断：铜锌稀硫酸原电池中，铜片是正极，发生氧化反应。
3. 选择：下列装置能构成原电池的是（A）两片锌片插入稀硫酸并用导线连接　（B）锌片与铜片插入乙醇中并用导线连接　（C）锌片与铜片插入稀硫酸并用导线连接　（D）锌片与铜片插入稀硫酸但不连接

> **答案**：1. ✓　2. ✗（正极发生还原反应）　3. C

### 🔑 原理与方程式

**构成条件**：① 两个活泼性不同的电极（金属与金属，或金属与石墨）；② 电极插入电解质溶液中；③ 形成闭合回路；④ 能自发进行的氧化还原反应。

**Cu-Zn 稀硫酸原电池**

- 负极（锌，较活泼）：Zn − 2e⁻ → Zn²⁺，氧化反应，锌片逐渐溶解
- 正极（铜，较不活泼）：2H⁺ + 2e⁻ → H₂↑，还原反应，铜片表面冒气泡
- 总反应：Zn + 2H⁺ → Zn²⁺ + H₂↑（Zn + H₂SO₄ → ZnSO₄ + H₂↑）
- 电子：负极 → 导线 → 正极；电流：正极 → 负极（外电路）
- 离子：溶液中阳离子移向正极，阴离子移向负极

**电池分类**：一次电池（锌锰干电池、锌银纽扣电池，放电后不可充电）；二次电池（铅酸蓄电池、锂离子电池，可反复充放电）；燃料电池（氢氧燃料电池、甲醇燃料电池，燃料由外部供给）。

**电解池**：把电能转化为化学能的装置，如电解饱和食盐水、电解熔融氯化钠。

**金属腐蚀**

- 化学腐蚀：金属与接触到的物质直接发生氧化还原反应
- 电化学腐蚀：不纯金属在电解质溶液中形成微原电池
- 钢铁在潮湿空气中主要发生**吸氧腐蚀**：负极 2Fe − 4e⁻ → 2Fe²⁺；正极 O₂ + 2H₂O + 4e⁻ → 4OH⁻；总反应 2Fe + O₂ + 2H₂O → 2Fe(OH)₂，再被氧化为 Fe(OH)₃，脱去部分水后成为铁锈 Fe₂O₃·xH₂O
- 酸性较强的环境中发生**析氢腐蚀**：正极 2H⁺ + 2e⁻ → H₂↑
- 防护：涂油漆、镀锌等镀层、制成不锈钢；牺牲阳极法（连接比铁活泼的锌、镁）；外加电流法（把钢铁接电源负极）

**适用条件**：原电池必须有自发进行的氧化还原反应，电极插入电解质溶液并形成闭合回路；乙醇、蔗糖溶液等非电解质溶液不导电，不能构成原电池；两个电极材料相同时没有活泼性差异，也不能构成原电池。

**易错边界**
1. 把正极、负极与氧化、还原对应错——负极失电子发生氧化，正极得电子发生还原。
2. 认为电子通过溶液从负极流向正极——电子只走外电路，溶液中靠离子定向移动导电。
3. 认为原电池中一定是较活泼的金属被消耗——Mg-Al-NaOH 溶液中原电池里，铝才作负极，因为铝与碱反应而镁不与碱反应。

### 例题 1 · L1 基础

以锌片、铜片、稀硫酸组成原电池。
(1) 指出正负极并写出电极反应式；
(2) 写出总反应的离子方程式；
(3) 外电路中电子和电流的方向分别是什么？

**解析**：
(1) 锌比铜活泼，**锌是负极**：Zn − 2e⁻ → Zn²⁺；**铜是正极**：2H⁺ + 2e⁻ → H₂↑。
(2) Zn + 2H⁺ → Zn²⁺ + H₂↑。
(3) 电子由锌片经导线流向铜片；电流由铜片经外电路流向锌片。

**💥 陷阱**：把铜写成负极；或把正极反应写成 Cu − 2e⁻ → Cu²⁺，忘了铜不与稀硫酸反应。

**变式**：把铜片换成石墨棒，能否构成原电池？（能；石墨导电且比锌不活泼，作正极，反应不变）

### 例题 2 · L2 常考

某同学用铁片、铜片、稀硫酸和灵敏电流计组装原电池。
(1) 观察到的现象有哪些？
(2) 写出电极反应式和总反应；
(3) 若把稀硫酸换成乙醇，电流计指针是否偏转？为什么？
(4) 若把铜片换成锌片，电流计指针是否偏转？为什么？

**解析**：
(1) 铁片逐渐溶解，铜片表面有气泡冒出，电流计指针偏转。
(2) 负极：Fe − 2e⁻ → Fe²⁺；正极：2H⁺ + 2e⁻ → H₂↑；总反应：Fe + 2H⁺ → Fe²⁺ + H₂↑。
(3) **不偏转**。乙醇是非电解质，溶液不导电，回路断开。
(4) **不偏转**。两个电极材料相同，没有活泼性差异，形不成电势差。

**💥 陷阱**：认为"有导线、有溶液"就是原电池，忽略电极材料必须不同、溶液必须导电。

**变式**：若把稀硫酸换成 CuSO₄ 溶液，铜片上发生什么反应？（Cu²⁺ + 2e⁻ → Cu，铜片增重，不再放出 H₂）

### 例题 3 · L3 综合

用锌片、铜片和稀硫酸构成原电池，工作一段时间后锌片质量减少了 3.25 g。
(1) 写出负极反应式，求转移电子的物质的量和数目；
(2) 求标准状况下正极生成 H₂ 的体积；
(3) 若把稀硫酸换成 CuSO₄ 溶液，正极反应式如何改变？铜片质量增加多少？

**解析**：
(1) n(Zn) = 3.25 ÷ 65 = 0.050 mol，Zn − 2e⁻ → Zn²⁺ ⇒ n(e⁻) = **0.10 mol**，
N = 0.10 × 6.02 × 10²³ = **6.02 × 10²²** 个。
(2) 正极 2H⁺ + 2e⁻ → H₂↑ ⇒ n(H₂) = 0.050 mol，V = 0.050 × 22.4 = **1.12 L**。
(3) 正极变为 Cu²⁺ + 2e⁻ → Cu，总反应为 Zn + Cu²⁺ → Zn²⁺ + Cu；
析出铜 n(Cu) = 0.050 mol，铜片增重 0.050 × 64 = **3.20 g**。

**💥 陷阱**：用 64 代替 65 算锌；或第(3)问仍按生成 H₂ 计算，忘了正极反应已换。

**变式**：若外电路转移 0.20 mol 电子，锌片质量减少多少克？（0.10 mol Zn ⇒ **6.5 g**）

### ⏱️ 限时挑战（90 秒）

> **答案**：① 氧化反应　② 锌（负极）　③ **0.10 mol**
