## A-2.1 粗盐提纯与氯气的制备

*必修一 › 第2章 海洋中的卤素资源 ｜ Ⅱ · 考频高 ｜ 前置：A-1.3 化学中常用的实验方法 ｜ 关联：A-2.2、A-2.6*

**⚡ 先猜**：粗盐提纯时，把 Na₂CO₃ 溶液加在 BaCl₂ 溶液**之前**，最后再过滤，杂质离子一样能除干净吗？

### 30 秒概述

海水晒盐得到的粗盐含泥沙与 Ca²⁺、Mg²⁺、SO₄²⁻。泥沙靠过滤，三种离子靠"沉淀 → 过滤 → 调 pH"三步除去。精盐配成饱和溶液电解，就得到氯碱工业的三大产品：Cl₂、H₂、NaOH。

### 30 秒自评

1. 粗盐提纯时，Na₂CO₃ 必须加在 BaCl₂ 之后、过滤之前。
2. 电解饱和食盐水时，与电源正极相连的石墨棒上产生的是氢气。
3. 电解 117 g NaCl，理论上可得标准状况下 Cl₂ 22.4 L。

> **答案**：1. ✓（否则过量的 Ba²⁺ 没有试剂除去）　2. ✗（阳极得 Cl₂，阴极得 H₂）　3. ✓（n(NaCl) = 2 mol，Cl₂ 为 1 mol，22.4 L）

### 🔑 原理与方程式

**一、粗盐提纯（化学沉淀法）**

- 不溶性杂质（泥沙）：溶解后**过滤**除去
- 可溶性杂质离子，按"只加过量、过量能除、最后能走"三条原则选试剂：

| 杂质离子 | 沉淀剂 | 沉淀 | 过量试剂怎么处理 |
|---|---|---|---|
| SO₄²⁻ | BaCl₂ 溶液 | BaSO₄↓ | 由后面的 Na₂CO₃ 除去 Ba²⁺ |
| Mg²⁺ | NaOH 溶液 | Mg(OH)₂↓ | 由后面的盐酸中和 OH⁻ |
| Ca²⁺ | Na₂CO₃ 溶液 | CaCO₃↓ | 由后面的盐酸除去 CO₃²⁻ |

- **唯一硬约束**：Na₂CO₃ 一定在 BaCl₂ **之后**、过滤**之前**；盐酸一定在过滤**之后**。三种可行顺序：
  ① BaCl₂ → NaOH → Na₂CO₃ → 过滤 → 盐酸
  ② NaOH → BaCl₂ → Na₂CO₃ → 过滤 → 盐酸
  ③ BaCl₂ → Na₂CO₃ → NaOH → 过滤 → 盐酸

**二、电解饱和食盐水（氯碱工业）**

- 总反应：2NaCl + 2H₂O →(电解) 2NaOH + H₂↑ + Cl₂↑　（2-1）
- 阳极（接电源正极，Cl⁻ 放电）：2Cl⁻ − 2e⁻ → Cl₂↑　（2-2）
- 阴极（接电源负极，H₂O 放电）：2H₂O + 2e⁻ → H₂↑ + 2OH⁻　（2-3）
- 电解后阴极区因生成 OH⁻ 而使酚酞变红；阳极区产生黄绿色气体，能使湿润的淀粉碘化钾试纸变蓝

**三、实验室制法**

- MnO₂ + 4HCl(浓) →(Δ) MnCl₂ + Cl₂↑ + 2H₂O　（2-4）
- 尾气必须用 NaOH 溶液吸收：Cl₂ + 2NaOH → NaCl + NaClO + H₂O　（2-9）

**适用条件**：电解必须用**直流电**与**饱和**食盐水（提高 Cl⁻ 浓度、减少 Cl₂ 溶解损失）；MnO₂ 法必须用**浓盐酸并加热**，稀盐酸不反应。

**易错边界**
1. Na₂CO₃ 写在 BaCl₂ 前面——过量的 Ba²⁺ 留在滤液中，成为新杂质
2. 盐酸加在过滤之前——刚沉淀的 CaCO₃、Mg(OH)₂ 又被溶解，前功尽弃
3. 用稀盐酸代替浓盐酸制 Cl₂，或忘写加热条件——方程式直接判错

### 例题 1 · L1 基础

写出电解饱和食盐水的化学方程式；若有 1 mol NaCl 完全电解，求标准状况下生成 Cl₂ 的体积。

**解析**：
方程式：2NaCl + 2H₂O →(电解) 2NaOH + H₂↑ + Cl₂↑
计量关系：2 mol NaCl ～ 1 mol Cl₂
n(Cl₂) = 1 mol ÷ 2 = 0.5 mol
V(Cl₂) = 0.5 mol × 22.4 L·mol⁻¹ = **11.2 L**

**💥 陷阱**：把 1 mol NaCl 直接当成 1 mol Cl₂ 得 22.4 L。系数比是 2∶1，不是 1∶1。

**变式**：同时收集 H₂ 与 Cl₂，标准状况下总体积是多少？（各 0.5 mol，共 22.4 L）

### 例题 2 · L2 常考

某粗盐样品含 Ca²⁺、Mg²⁺、SO₄²⁻ 及泥沙。现有 BaCl₂ 溶液、NaOH 溶液、Na₂CO₃ 溶液、稀盐酸。
(1) 写出一种合理的试剂加入顺序；
(2) 说明 Na₂CO₃ 溶液的两个作用；
(3) 能否把稀盐酸改到过滤前加入？

**解析**：
(1) BaCl₂ → NaOH → Na₂CO₃ → 过滤 → 加盐酸调至中性（答案不唯一，只要 Na₂CO₃ 在 BaCl₂ 后、过滤前）
(2) ① 沉淀 Ca²⁺：Ca²⁺ + CO₃²⁻ → CaCO₃↓；② 沉淀过量的 Ba²⁺：Ba²⁺ + CO₃²⁻ → BaCO₃↓
(3) **不能**。过滤前溶液呈碱性且含 CO₃²⁻，先加盐酸会让 CaCO₃、Mg(OH)₂ 重新溶解，杂质离子回到溶液中

**💥 陷阱**：只答出"除 Ca²⁺"一个作用。Na₂CO₃ 在这里是"一箭双雕"，漏掉除 Ba²⁺ 就说明没理解试剂顺序为什么被锁死。

**变式**：若把 BaCl₂ 改到过滤之后加，会引入什么后果？（滤液中新增 Ba²⁺，且已有 SO₄²⁻ 被除去，无法再除）

### 例题 3 · L3 综合

电解饱和食盐水，阴极收集到标准状况下 2.24 L 气体。
(1) 求电解过程中转移电子的物质的量；
(2) 求生成 NaOH 的物质的量与阳极气体的体积（标准状况）；
(3) 若把阳极气体全部通入石灰乳制漂白粉，理论上可得 Ca(ClO)₂ 多少克？

**解析**：
(1) n(H₂) = 2.24 L ÷ 22.4 L·mol⁻¹ = 0.1 mol。由 2H₂O + 2e⁻ → H₂↑ + 2OH⁻，每生成 1 mol H₂ 转移 2 mol e⁻，故转移 **0.2 mol e⁻**
(2) 由阴极反应：n(NaOH) = 2n(H₂) = **0.2 mol**；由总反应 2NaCl + 2H₂O →(电解) 2NaOH + H₂↑ + Cl₂↑，n(Cl₂) = n(H₂) = 0.1 mol，V(Cl₂) = **2.24 L**
(3) 2Cl₂ + 2Ca(OH)₂ → CaCl₂ + Ca(ClO)₂ + 2H₂O，Cl₂ 与 Ca(ClO)₂ 为 2∶1
n(Ca(ClO)₂) = 0.1 mol ÷ 2 = 0.05 mol，m = 0.05 mol × 143 g·mol⁻¹ = **7.15 g**

**💥 陷阱**：电子数与 H₂ 按 1∶1 算成 0.1 mol；或把 Cl₂ 与 Ca(ClO)₂ 当成 1∶1 得 14.3 g。

**变式**：若改用 MnO₂ 与浓盐酸制取同样多的 Cl₂（0.1 mol），至少需 HCl 多少摩尔？其中被氧化的占多少？（0.4 mol；被氧化 0.2 mol，另一半起酸的作用）

### ⏱️ 限时挑战（90 秒）

> **答案**：① 沉淀 Ca²⁺、沉淀过量的 Ba²⁺　② 黄绿色气体，能使湿润的淀粉碘化钾试纸变蓝　③ 11.2 L

## A-2.2 氯气的性质

*必修一 › 第2章 海洋中的卤素资源 ｜ Ⅱ · 考频高 ｜ 前置：A-2.1 ｜ 关联：A-2.3、A-2.7*

**⚡ 先猜**：铁在氯气中燃烧，产物是 FeCl₂ 还是 FeCl₃？如果换成盐酸，产物又是什么？

### 30 秒概述

氯气是黄绿色、有刺激性气味的有毒气体，密度比空气大，1 体积水约溶 2 体积 Cl₂。它的核心性质是**强氧化性**：与变价金属直接化合时一律生成**高价**氯化物，还能与 H₂、水、碱反应。

### 30 秒自评

1. 铁在氯气中燃烧生成 FeCl₂。
2. 干燥的氯气不能使干燥的有色布条褪色，但能使湿润的有色布条褪色。
3. 氢气在氯气中燃烧，火焰呈苍白色，瓶口出现白雾。

> **答案**：1. ✗（生成 FeCl₃，+3 价）　2. ✓（真正漂白的是 Cl₂ 与水生成的 HClO）　3. ✓

### 🔑 原理与方程式

**一、状态与颜色（常考识记）**

- 常温常压：黄绿色气体，密度 2.98 g·L⁻¹（比空气大），有毒
- 加压冷却到 −34.6 ℃ 变液氯，继续冷到 −101 ℃ 变固态氯
- 常温下 1 体积水溶解约 2 体积 Cl₂；干燥 Cl₂ 与铁在常温下不反应，故液氯可储于干燥钢瓶

**二、与金属反应（一律生成高价氯化物）**

- 2Fe + 3Cl₂ →(点燃) 2FeCl₃　（2-5）　产生棕黄色烟，加水后溶液呈棕黄色
- Cu + Cl₂ →(点燃) CuCl₂　产生棕黄色烟
- 2Na + Cl₂ →(点燃) 2NaCl　产生白色烟

**三、与非金属反应**

- H₂ + Cl₂ →(点燃) 2HCl　（2-6）　苍白色火焰，瓶口有白雾（HCl 遇水汽）
- H₂ 与 Cl₂ 的混合气受强光照射即爆炸化合，产物仍是 HCl

**四、与水、与碱反应**

- Cl₂ + H₂O ⇌ HCl + HClO　（2-7）
- Cl₂ + 2NaOH → NaCl + NaClO + H₂O　（2-9）

**五、现象描述的三件套**：颜色 + 烟/雾 + 加水后的溶液颜色。写"白烟"还是"白雾"取决于产物是固体小颗粒还是小液滴。

**适用条件**：与 Fe、Cu 反应需**点燃**；干燥、常温下 Cl₂ 与 Fe 不反应，这是钢瓶储氯的前提；尾气必须用 NaOH 溶液吸收，不能直接排空。

**易错边界**
1. Cl₂ 与 Fe 写成 FeCl₂——只有盐酸、稀硫酸这类非氧化性酸才给 +2 价
2. 干燥 Cl₂ 能漂白——漂白的是 HClO，干燥 Cl₂ 本身没有漂白性
3. 现象写成"淡蓝色火焰"——H₂ 在 Cl₂ 中是苍白色火焰，在空气中才是淡蓝色

### 例题 1 · L1 基础

写出 Fe、Na 分别在氯气中燃烧的化学方程式，指出氧化剂，并说明氯元素的化合价变化。

**解析**：
2Fe + 3Cl₂ →(点燃) 2FeCl₃；2Na + Cl₂ →(点燃) 2NaCl
氧化剂都是 **Cl₂**：Cl 由 0 价降到 −1 价，得电子、被还原，表现氧化性
Fe 由 0 价升到 +3 价、Na 由 0 价升到 +1 价，都被氧化，作还原剂

**💥 陷阱**：把 Fe 的产物写成 FeCl₂——氯气的氧化性比盐酸强得多，只要直接化合就是 +3 价。

**变式**：等物质的量的 Fe 分别与足量 Cl₂、足量盐酸反应，转移电子数之比是多少？（3∶2）

### 例题 2 · L2 常考

液氯储存在钢瓶中，钢瓶在装氯前必须彻底干燥。
(1) 用化学方程式解释"必须干燥"的原因；
(2) 若钢瓶内壁残留少量水，可能生成哪些物质？会带来什么后果？

**解析**：
(1) 干燥条件下，常温时 Fe 与 Cl₂ 不反应，钢瓶完好；一旦有水，Cl₂ 与水反应生成 HCl 和 HClO，钢瓶由"钝化不反应"变成"被酸腐蚀"
(2) 生成 HCl 与 HClO：Cl₂ + H₂O ⇌ HCl + HClO；HCl 直接腐蚀铁，HClO 见光分解出 O₂ 并进一步氧化，腐蚀加快，最终可能导致泄漏

**💥 陷阱**：答"铁与氯气不反应"。准确说法是"**干燥**、**常温**下不反应"，条件一破就剧烈反应。

**变式**：为什么工业上还可以用铁制容器储存浓硫酸、浓硝酸？（常温下钝化，表面生成致密氧化膜）

### 例题 3 · L3 综合

标准状况下 2.24 L Cl₂ 缓缓通入 100 mL 1.0 mol·L⁻¹ 的 FeBr₂ 溶液中。
(1) 写出 Cl₂ 与 Fe²⁺、Br⁻ 反应的离子方程式；
(2) 判断哪种离子先被氧化；
(3) 求被氧化的 Fe²⁺ 与 Br⁻ 的物质的量。

**解析**：
(1) 2Fe²⁺ + Cl₂ → 2Fe³⁺ + 2Cl⁻；Cl₂ + 2Br⁻ → 2Cl⁻ + Br₂
(2) 还原性 Fe²⁺ > Br⁻，**Fe²⁺ 先被氧化**
(3) n(Cl₂) = 0.1 mol，得电子 0.2 mol；n(Fe²⁺) = 0.1 mol，全部氧化耗 0.1 mol e⁻；余 0.1 mol e⁻ 氧化 Br⁻：n(Br⁻) = 0.1 mol
结论：被氧化 **Fe²⁺ 0.1 mol（全部）、Br⁻ 0.1 mol（原有 0.2 mol 的一半）**

**💥 陷阱**：一看到卤素就以为 Br⁻ 先被氧化。这里是"还原性强者优先"，Fe²⁺ 抢在前面；也不要把 0.2 mol e⁻ 全算给 Br⁻。

**变式**：若通入 3.36 L（标准状况）Cl₂，结果如何？（0.15 mol Cl₂ 得 0.3 mol e⁻，恰好把 0.1 mol Fe²⁺ 与 0.2 mol Br⁻ 全部氧化）

### ⏱️ 限时挑战（90 秒）

① 铁在氯气中燃烧的产物是什么颜色？② 干燥的氯气能否使干燥的红布条褪色？③ 实验室制氯气的尾气用什么吸收？

> **答案**：① 棕黄色烟（FeCl₃）　② 不能　③ NaOH 溶液

## A-2.3 氯水的成分与漂白性

*必修一 › 第2章 海洋中的卤素资源 ｜ Ⅱ · 考频高 ｜ 前置：A-2.2 ｜ 关联：A-2.4、A-2.6*

**⚡ 先猜**：新制氯水能使紫色石蕊试液先变红后褪色。把这瓶氯水放一个月，它还能让石蕊褪色吗？

### 30 秒概述

氯水是 Cl₂ 的水溶液，呈**三分子四离子**：Cl₂、H₂O、HClO 与 H⁺、Cl⁻、ClO⁻、OH⁻。显酸性的是 H⁺，能漂白的是 HClO，显黄绿色的是 Cl₂。HClO 见光分解，所以氯水必须现用现配，久置后只剩稀盐酸。

### 30 秒自评

1. 新制氯水中含 Cl₂、H₂O、HClO 三种分子和 H⁺、Cl⁻、ClO⁻、OH⁻ 四种离子。
2. 向新制氯水中滴入紫色石蕊试液，溶液先变红后褪色。
3. 氯水放置越久，漂白能力越强。

> **答案**：1. ✓（OH⁻ 来自水的电离，浓度极小）　2. ✓（H⁺ 变红，HClO 褪色）　3. ✗（HClO 分解，久置氯水就是稀盐酸）

### 🔑 原理与方程式

**一、氯水的成分**

- 溶解：常温下 1 体积水溶约 2 体积 Cl₂（氯水呈浅黄绿色，是 Cl₂ 的颜色）
- 反应：Cl₂ + H₂O ⇌ HCl + HClO　（2-7）——**可逆**，用 ⇌
- 三分子：Cl₂、H₂O、HClO；四离子：H⁺、Cl⁻、ClO⁻、OH⁻

**二、各微粒的检验（一条现象对一个微粒）**

| 微粒 | 检验方法 | 现象 |
|---|---|---|
| Cl₂ | 湿润的淀粉碘化钾试纸 | 变蓝 |
| H⁺ | 紫色石蕊试液、pH 试纸 | 变红 |
| Cl⁻ | 稀硝酸酸化的 AgNO₃ 溶液 | 白色沉淀 AgCl |
| HClO | 有色布条（干燥对比实验） | 褪色 |

**三、次氯酸的三条性质**

- **弱酸性**：酸性比 H₂CO₃ 还弱，只有部分电离，写离子方程式时不拆
- **强氧化性**：杀菌消毒、使染料和有机色质褪色（漂白）
- **不稳定性**：2HClO →(光照) 2HCl + O₂↑　（2-8），受热、见光分解更快

**四、干燥氯气不漂白的对比实验**

干氯气 + 干燥红布条 → 不褪色；干氯气 + 湿润红布条 → 褪色。说明起漂白作用的不是 Cl₂，而是 Cl₂ 与水反应生成的 HClO。

**适用条件**：HClO 只存在于稀溶液中，浓度稍大即分解；氯水的漂白性与酸性都随放置时间衰减；用石蕊检验时必须用**新制**氯水。

**易错边界**
1. 把漂白性归给 Cl₂——褪色的是 HClO，Cl₂ 只负责"溶进水并生成 HClO"
2. 检验 Cl⁻ 忘加稀硝酸——Ag₂CO₃ 等白色沉淀会造成假阳性
3. 认为氯水中的 HClO 大量电离出 H⁺——它是弱酸，主要以分子形式存在

### 例题 1 · L1 基础

新制氯水中含有哪些分子和离子？分别指出起漂白作用和显酸性的微粒。

**解析**：
分子：Cl₂、H₂O、HClO；离子：H⁺、Cl⁻、ClO⁻、OH⁻
漂白：**HClO**（强氧化性，破坏有色物质）；显酸性：**H⁺**（来自 HCl 与 HClO 的电离）
浅黄绿色：Cl₂

**💥 陷阱**：把 HClO 写成"大量 H⁺ + ClO⁻"。HClO 是弱酸，主要以身形式存在；也不要漏掉 H₂O 这个分子。

**变式**：向氯水中加入 NaHCO₃ 粉末产生气泡，说明什么？（说明溶液中 H⁺ 能与 HCO₃⁻ 反应，即 HCl 的酸性强于 H₂CO₃；HClO 酸性弱于 H₂CO₃，不与 NaHCO₃ 反应）

### 例题 2 · L2 常考

将氯气持续通入紫色石蕊试液中，溶液颜色依次为：紫色 → 红色 → 无色。
(1) 解释每一阶段颜色变化的原因；
(2) 若改用**干燥**的紫色石蕊试纸，现象有何不同？为什么？

**解析**：
(1) 变红：Cl₂ 与水反应生成 HCl 和 HClO，电离出的 H⁺ 使石蕊变红；褪色：HClO 的强氧化性把有色物质氧化破坏
(2) 干燥试纸上**不变红也不褪色**：试纸没有水，Cl₂ 既生成不了 HCl（无 H⁺ 可变红），也生成不了 HClO（无漂白微粒）；只有试纸先被润湿，才会出现"先变红后褪色"

**💥 陷阱**：答"氯气有漂白性使石蕊褪色"。氯气本身不漂白，漂白的是它溶于水后生成的 HClO。

**变式**：向褪色后的溶液中再滴加 NaOH 溶液，颜色会恢复吗？（不会，HClO 的漂白是氧化破坏，不可逆；SO₂ 的漂白才可逆）

### 例题 3 · L3 综合

实验室有一瓶放置很久的氯水。
(1) 与中新制氯水相比，久置氯水中明显减少的微粒有哪些？
(2) 用化学方程式解释其漂白性消失的原因；
(3) 取该溶液 50.0 mL，加入足量稀硝酸酸化的 AgNO₃ 溶液，得白色沉淀 0.287 g，求 c(Cl⁻)。

**解析**：
(1) 减少：Cl₂、HClO（Cl₂ 不断与水反应并被消耗，HClO 见光分解）
(2) Cl₂ + H₂O ⇌ HCl + HClO；2HClO →(光照) 2HCl + O₂↑，总效果是氯水逐渐变成稀盐酸
(3) n(AgCl) = 0.287 g ÷ 143.5 g·mol⁻¹ = 0.002 mol，故 n(Cl⁻) = 0.002 mol
c(Cl⁻) = 0.002 mol ÷ 0.0500 L = **0.040 mol·L⁻¹**

**💥 陷阱**：用 M(Ag) = 108 去除；或体积用 50 而不是 0.0500 L；也有人把沉淀当成 AgClO（AgClO 可溶，不生成沉淀）。

**变式**：若沉淀改为 0.574 g，c(Cl⁻) 是多少？（0.004 mol ÷ 0.0500 L = 0.080 mol·L⁻¹）

## A-2.4 次氯酸盐与漂白粉

*必修一 › 第2章 海洋中的卤素资源 ｜ Ⅰ · 考频中 ｜ 前置：A-2.3 ｜ 关联：A-2.2、A-2.6*

**⚡ 先猜**：漂白粉放在空气中久了会失效，是因为它"潮解"了吗？

### 30 秒概述

HClO 不稳定、难保存，于是让它与碱反应生成**稳定的次氯酸盐**：NaClO 是 84 消毒液的有效成分，Ca(ClO)₂ 是漂白粉的有效成分。漂白粉遇酸或空气中的 CO₂ + H₂O 又放出 HClO，所以既靠这个反应生效，也因这个反应失效。

### 30 秒自评

1. 漂白粉的有效成分是 Ca(ClO)₂。
2. 漂白粉露置在空气中会失效，是因为 Ca(ClO)₂ 与 CO₂、H₂O 反应生成 HClO，HClO 又分解。
3. 84 消毒液与洁厕灵（含盐酸）混合使用，消毒效果更好。

> **答案**：1. ✓（主要成分是 Ca(ClO)₂、CaCl₂、Ca(OH)₂ 的混合物，有效成分只有 Ca(ClO)₂）　2. ✓　3. ✗（酸性条件下 ClO⁻ 与 Cl⁻ 反应放出 Cl₂，会中毒）

### 🔑 原理与方程式

**一、制备**

- 与 NaOH：Cl₂ + 2NaOH → NaCl + NaClO + H₂O　（2-9）；离子方程式 Cl₂ + 2OH⁻ → Cl⁻ + ClO⁻ + H₂O　（2-10）
- 与消石灰：2Cl₂ + 2Ca(OH)₂ → CaCl₂ + Ca(ClO)₂ + 2H₂O　（2-11）
- 漂白粉 = Ca(ClO)₂ + CaCl₂ + Ca(OH)₂ 的混合物，**有效成分是 Ca(ClO)₂**

**二、生效与失效**

- 遇酸生效：Ca(ClO)₂ + 2HCl → CaCl₂ + 2HClO　（2-12）
- 遇空气失效：Ca(ClO)₂ + CO₂ + H₂O → CaCO₃↓ + 2HClO　（2-13），随后 2HClO →(光照) 2HCl + O₂↑
- 结论：漂白粉必须**密封、避光、干燥**保存

**三、有效氯**

- 定义：漂白粉与浓盐酸反应生成 Cl₂ 的质量与漂白粉质量之比
- 工业漂白粉有效氯约 35%，漂粉精（Cl₂ 与石灰乳反应制得）可高达 70%
- 定量关系：Ca(ClO)₂ + 4HCl → CaCl₂ + 2Cl₂↑ + 2H₂O，即 1 mol Ca(ClO)₂ 放出 2 mol Cl₂

**四、消毒原理的离子视角**

ClO⁻ 水解生成 HClO：ClO⁻ + H₂O ⇌ HClO + OH⁻。加少量白醋降低 pH，平衡右移、HClO 浓度升高，消毒能力增强——但酸性不能过强，否则会放出 Cl₂。

**适用条件**：漂白粉在干燥时稳定，只有遇酸或潮湿空气才释放 HClO；NaClO 溶液应避光密封、不宜与酸混用。

**易错边界**
1. 把"主要成分"与"有效成分"混为一谈——有效成分只有 Ca(ClO)₂
2. 84 消毒液与洁厕灵混用——ClO⁻ + Cl⁻ + 2H⁺ → Cl₂↑ + H₂O，**危险操作，绝不可混**
3. 认为失效只是"受潮结块"——实质是生成 HClO 并分解，氧化性物质被消耗

### 例题 1 · L1 基础

写出氯气与消石灰反应制漂白粉的化学方程式，指出氧化剂、还原剂，并求每生成 2 mol Ca(ClO)₂ 转移的电子数。

**解析**：
2Cl₂ + 2Ca(OH)₂ → CaCl₂ + Ca(ClO)₂ + 2H₂O
4 个 Cl 原子中，2 个由 0 价降到 −1 价（进 CaCl₂，被还原），2 个由 0 价升到 +1 价（进 Ca(ClO)₂，被氧化）
**Cl₂ 既是氧化剂又是还原剂**（歧化反应）
每 2 mol Cl₂ 转移 **2 mol e⁻**，故生成 2 mol Ca(ClO)₂ 时转移 2 mol e⁻

**💥 陷阱**：说"Cl₂ 只是氧化剂"；或把电子数算成 4 mol（把 4 个 Cl 的价差全加一遍，重复计数）。

**变式**：3Cl₂ + 6KOH →(Δ) 5KCl + KClO₃ + 3H₂O 中转移多少电子？（5 mol e⁻：5 个 Cl 降 1 价，1 个 Cl 升 5 价）

### 例题 2 · L2 常考

(1) 漂白粉为什么要密封保存？写出失效过程中两步反应的化学方程式。
(2) 使用漂白粉时加入少量稀盐酸，漂白效果为什么增强？

**解析**：
(1) 空气中的 CO₂ 与 H₂O 会与 Ca(ClO)₂ 反应：
Ca(ClO)₂ + CO₂ + H₂O → CaCO₃↓ + 2HClO；2HClO →(光照) 2HCl + O₂↑
HClO 不断被消耗，有效成分减少，故须密封、避光、干燥
(2) Ca(ClO)₂ + 2HCl → CaCl₂ + 2HClO，短时间内产生大量 HClO，漂白速率加快

**💥 陷阱**：认为加酸是"增强碱性"或写成生成 Cl₂。少量酸使 HClO 增多，是增强；**酸过量**才会发生 ClO⁻ + Cl⁻ + 2H⁺ → Cl₂↑ + H₂O。

**变式**：为什么漂白粉不能与洁厕灵混用？（酸性条件下 ClO⁻ 与 Cl⁻ 归中生成有毒 Cl₂）

### 例题 3 · L3 综合

某漂白粉样品 10.0 g，与足量浓盐酸充分反应，标准状况下放出 Cl₂ 1.12 L。
(1) 写出反应的化学方程式，并标出电子转移的方向与数目；
(2) 求样品中 Ca(ClO)₂ 的质量分数；
(3) 求该样品的有效氯（保留三位有效数字）。

**解析**：
(1) Ca(ClO)₂ + 4HCl → CaCl₂ + 2Cl₂↑ + 2H₂O
ClO⁻ 中 2 个 Cl（+1）得 2e⁻ 变为 Cl₂；2 个 Cl⁻（−1）失 2e⁻ 变为 Cl₂，转移 **2e⁻**；另 2 个 HCl 只起酸的作用
(2) n(Cl₂) = 1.12 L ÷ 22.4 L·mol⁻¹ = 0.05 mol
由 1 mol Ca(ClO)₂ ～ 2 mol Cl₂：n(Ca(ClO)₂) = 0.025 mol
m = 0.025 mol × 143 g·mol⁻¹ = 3.575 g，质量分数 = 3.575 ÷ 10.0 × 100% ≈ **35.8%**
(3) m(Cl₂) = 0.05 mol × 71 g·mol⁻¹ = 3.55 g
有效氯 = 3.55 ÷ 10.0 × 100% = **35.5%**

**💥 陷阱**：把 Ca(ClO)₂ 与 Cl₂ 按 1∶1 计算，质量分数会算成 71.5%；把有效氯当成 Ca(ClO)₂ 的质量分数（两者数值接近但定义不同，一个用 Cl₂ 质量，一个用 Ca(ClO)₂ 质量）。

**变式**：另取该漂白粉 20.0 g（有效氯 35.5%），与足量盐酸反应，标准状况下得 Cl₂ 多少升？（7.1 g ÷ 71 g·mol⁻¹ = 0.1 mol，2.24 L）

## A-2.5 氧化还原反应

*必修一 › 第2章 海洋中的卤素资源 ｜ Ⅱ · 考频高 ｜ 前置：A-2.2 ｜ 关联：A-2.6、A-2.7*

**⚡ 先猜**：没有氧元素参加的反应，一定不是氧化还原反应吗？

### 30 秒概述

判断氧化还原反应只看一件事：**有没有元素化合价升降**。升降的本质是电子转移（得失或偏移），且得失总数一定相等。抓住"升失氧、降得还"六个字，配平、计算、判断氧化剂全都由此展开。

### 30 秒自评

1. 有单质参加的反应一定是氧化还原反应。
2. 在 Cl₂ + 2NaOH → NaCl + NaClO + H₂O 中，Cl₂ 既是氧化剂又是还原剂。
3. 氧化剂在反应中被氧化，化合价升高。

> **答案**：1. ✗（如 3O₂ → 2O₃，化合价不变）　2. ✓（Cl 由 0 价分别变到 −1 与 +1，歧化）　3. ✗（被还原、化合价降低）

### 🔑 原理与方程式

**一、特征与本质**

- 特征（判断依据）：反应前后有元素**化合价升降**
- 本质：有**电子转移**（得失或偏移），且失电子总数 = 得电子总数
- 氧化反应：化合价升高、失电子、被氧化、该物质作**还原剂**
- 还原反应：化合价降低、得电子、被还原、该物质作**氧化剂**
- 口诀：**升失氧（还原剂），降得还（氧化剂）**

**二、电子转移的表示**

- 双线桥：由反应物指向生成物中的同种元素，标"得/失 n e⁻"
- 单线桥：只在反应物之间画一条箭头，由失电子元素指向得电子元素，只标数目
- 示例：2Na + Cl₂ →(点燃) 2NaCl，Na：0 → +1，失 1e⁻ ×2；Cl：0 → −1，得 1e⁻ ×2；转移 **2e⁻**
- 歧化示例：Cl₂ + 2NaOH → NaCl + NaClO + H₂O，转移 **1e⁻**（每个 Cl₂ 中 1 个 Cl 降 1 价、1 个 Cl 升 1 价）

**三、常见的氧化剂与还原剂**

| 类别 | 常见物质 |
|---|---|
| 氧化剂 | O₂、Cl₂、浓硫酸、硝酸、KMnO₄、H₂O₂、Ca(ClO)₂ |
| 还原剂 | C、H₂、CO、金属单质（Na、Ca、Al、Zn）、KI、SO₂ |

- 中间价态物质两面性：H₂O₂ 遇强还原剂作氧化剂（被还原为 H₂O），遇强氧化剂作还原剂（被氧化为 O₂）；Fe²⁺ 同理

**四、配平四步（电子守恒法）**

1. 标变价元素的化合价，算出"升/降总数"
2. 求最小公倍数，定氧化剂、还原剂的系数
3. 用观察法配平其余元素（先金属、再非金属、后氢氧）
4. 查三样：原子守恒、电荷守恒（离子方程式）、条件与状态

**适用条件**：判断"是不是"只看化合价，不看有没有氧气参与；"被氧化/被还原"说的是**元素**，不是整个物质；浓硫酸、硝酸的氧化性随浓度下降而减弱，稀硝酸产物是 NO 而非 NO₂。

**易错边界**
1. "氧化剂被氧化"——氧化剂得电子，被**还原**
2. 电子转移数漏乘系数：2KClO₃ 分解是 12e⁻，不是 6e⁻
3. 把没有化合价变化的反应当氧化还原：CaO + H₂O → Ca(OH)₂ 不是

### 例题 1 · L1 基础

判断下列反应是否属于氧化还原反应，并指出氧化剂：
① 2Na + Cl₂ →(点燃) 2NaCl　② CaO + H₂O → Ca(OH)₂　③ 2H₂O₂ →(MnO₂) 2H₂O + O₂↑

**解析**：
① 是。Na 0 → +1，Cl 0 → −1；**Cl₂ 是氧化剂**，Na 是还原剂
② 不是。Ca、O、H 化合价均未变化，属于化合反应
③ 是。O 由 −1 价变为 −2 价（H₂O）和 0 价（O₂）；**H₂O₂ 既是氧化剂又是还原剂**

**💥 陷阱**：③ 只看到"放出 O₂"就说 H₂O₂ 是还原剂。它同时把另一部分氧还原成 −2 价，两重身份都要写。

**变式**：③ 中 2 mol H₂O₂ 完全分解，转移电子多少？（2 mol e⁻）

### 例题 2 · L2 常考

用双线桥标出 2KClO₃ →(MnO₂, Δ) 2KCl + 3O₂↑ 的电子转移，指出氧化剂、还原剂，并求生成 0.3 mol O₂ 时转移的电子数。

**解析**：
Cl：+5 → −1，得 6e⁻，共 2 个 Cl，得 12e⁻
O：−2 → 0，失 2e⁻，共 6 个 O，失 12e⁻
转移 **12e⁻**；KClO₃ 既是氧化剂又是还原剂（自身歧化）
生成 3 mol O₂ 对应 12 mol e⁻，故 0.3 mol O₂ 转移 **1.2 mol e⁻**（每 1 mol O₂ 对应 4 mol e⁻）

**💥 陷阱**：只算 Cl 的 6e⁻，或只算一半氧的 6e⁻；两者必须相等，不等就是没配平或没数全。

**变式**：若反应中有 0.5 mol KClO₃ 分解，转移电子多少？（0.5 × 6 = 3 mol e⁻）

### 例题 3 · L3 综合

实验室用 KMnO₄ 与浓盐酸反应制氯气：KMnO₄ + HCl(浓) → KCl + MnCl₂ + Cl₂↑ + H₂O（未配平）。
(1) 配平方程式，指出氧化剂、还原剂；
(2) 求被氧化的 HCl 占参加反应 HCl 的物质的量之比；
(3) 若转移 0.5 mol 电子，标准状况下生成 Cl₂ 多少升？

**解析**：
(1) Mn：+7 → +2，得 5e⁻；Cl：−1 → 0，失 1e⁻。最小公倍数 10：KMnO₄ 系数 2，被氧化的 HCl 为 10
2KMnO₄ + 16HCl(浓) → 2KCl + 2MnCl₂ + 5Cl₂↑ + 8H₂O
氧化剂 **KMnO₄**，还原剂 **HCl**（只有一部分被氧化，其余起酸的作用）
(2) 16 mol HCl 中只有 10 mol 被氧化，比值 **10∶16 = 5∶8**
(3) 每生成 1 mol Cl₂ 转移 2 mol e⁻，故 n(Cl₂) = 0.5 ÷ 2 = 0.25 mol，V = 0.25 × 22.4 = **5.6 L**

**💥 陷阱**：认为 16 mol HCl 全被氧化（得 16∶16）；或把电子数与 Cl₂ 按 1∶1 算成 0.5 mol（11.2 L）。

**变式**：若用 0.2 mol KMnO₄，最多能氧化多少摩尔 HCl？（0.2 × 5 = 1.0 mol）

## A-2.6 离子反应与离子方程式

*必修一 › 第2章 海洋中的卤素资源 ｜ Ⅱ · 考频高 ｜ 前置：A-2.5 ｜ 关联：A-2.2、A-2.7*

**⚡ 先猜**：H⁺ + OH⁻ → H₂O 能代表"所有"强酸与强碱的中和反应吗？

### 30 秒概述

电解质在水溶液或熔融状态下电离出自由移动的离子，这是导电的原因。酸碱盐在溶液中的反应，实质是**部分离子**的结合；把真正参加反应的离子写出来，就是离子方程式。判断能不能反应，只看有没有沉淀、气体或弱电解质生成。

### 30 秒自评

1. 电解质一定是化合物；能导电的物质不一定是电解质。
2. BaSO₄ 难溶于水，所以它是非电解质。
3. H⁺ + OH⁻ → H₂O 可以表示 Ba(OH)₂ 与 H₂SO₄ 的反应。

> **答案**：1. ✓（铜能导电但不是化合物）　2. ✗（熔融 BaSO₄ 导电，是强电解质）　3. ✗（还有 Ba²⁺ + SO₄²⁻ → BaSO₄↓）

### 🔑 原理与方程式

**一、电解质与非电解质**

- 电解质：在水溶液中**或**熔融状态下能导电的**化合物**
- 非电解质：两种状态下都不导电的化合物（蔗糖、酒精）
- 导电条件：有自由移动的离子 + 外加电压。NaCl 固体、气态 HCl 不导电，因为离子不能自由移动
- 强电解质：水溶液中**全部**电离（强酸、强碱、大多数盐）；弱电解质：**部分**电离（CH₃COOH、NH₃·H₂O、H₂O）

**二、电离方程式**

- NaCl → Na⁺ + Cl⁻；HCl → H⁺ + Cl⁻；NaOH → Na⁺ + OH⁻；Na₂SO₄ → 2Na⁺ + SO₄²⁻
- 弱电解质用 ⇌：CH₃COOH ⇌ H⁺ + CH₃COO⁻；NH₃·H₂O ⇌ NH₄⁺ + OH⁻；H₂O ⇌ H⁺ + OH⁻

**三、离子反应发生的条件（三者有其一即可）**

- 生成**沉淀**：Ba²⁺ + SO₄²⁻ → BaSO₄↓；Ag⁺ + Cl⁻ → AgCl↓
- 生成**气体**：CO₃²⁻ + 2H⁺ → CO₂↑ + H₂O
- 生成**弱电解质**：H⁺ + OH⁻ → H₂O；Cl₂ + H₂O ⇌ H⁺ + Cl⁻ + HClO

**四、离子方程式书写四步（以 CaCO₃ 与盐酸为例）**

1. 写化学方程式：CaCO₃ + 2HCl → CaCl₂ + CO₂↑ + H₂O
2. **拆**：强酸、强碱、可溶性盐拆成离子；沉淀、气体、弱电解质、氧化物、单质一律写化学式
   CaCO₃ + 2H⁺ + 2Cl⁻ → Ca²⁺ + 2Cl⁻ + CO₂↑ + H₂O
3. **删**：两边相同的离子（2Cl⁻）
4. **查**：原子守恒 + 电荷守恒 → CaCO₃ + 2H⁺ → Ca²⁺ + CO₂↑ + H₂O

**五、氧化还原也可写离子方程式**

- Fe + Cu²⁺ → Fe²⁺ + Cu（对应 Fe + CuSO₄ → FeSO₄ + Cu）

**适用条件**：微溶物看状态——澄清石灰水拆成 Ca²⁺ + 2OH⁻，石灰乳写 Ca(OH)₂；浓硫酸以分子为主，不拆；弱电解质、难溶物、气体、单质、氧化物都不拆。

**易错边界**
1. 拆错：把 CaCO₃、HClO、NH₃·H₂O 写成离子形式
2. 只查原子、不查电荷——Fe³⁺ + Cu → Fe²⁺ + Cu²⁺ 电荷不平，正确为 2Fe³⁺ + Cu → 2Fe²⁺ + Cu²⁺
3. 把 H⁺ + OH⁻ → H₂O 套到所有中和反应——Ba(OH)₂ 与 H₂SO₄ 还必须写 BaSO₄ 沉淀

### 例题 1 · L1 基础

写出下列反应的离子方程式：
① 盐酸与 NaOH 溶液　② 碳酸钙与盐酸　③ 硫酸铜溶液与 NaOH 溶液

**解析**：
① H⁺ + OH⁻ → H₂O（强酸、强碱都拆）
② CaCO₃ + 2H⁺ → Ca²⁺ + CO₂↑ + H₂O（CaCO₃ 难溶，保留化学式）
③ Cu²⁺ + 2OH⁻ → Cu(OH)₂↓（SO₄²⁻、Na⁺ 未参加反应，删去）

**💥 陷阱**：② 把 CaCO₃ 拆成 Ca²⁺ + CO₃²⁻；③ 把化学方程式 Na₂SO₄ 之类不反应的离子留在式子里。

**变式**：② 中改用硫酸代替盐酸，离子方程式变吗？（不变，仍是 CaCO₃ + 2H⁺ → Ca²⁺ + CO₂↑ + H₂O）

### 例题 2 · L2 常考

判断下列离子方程式书写是否正确，错误的说明原因并改正：
A. 氯气通入 NaOH 溶液：Cl₂ + 2OH⁻ → Cl⁻ + ClO⁻ + H₂O
B. 溴与碘化钾溶液：Br₂ + I⁻ → Br⁻ + I₂
C. 溴化钠与硝酸银溶液：NaBr + AgNO₃ → AgBr↓ + NaNO₃
D. 盐酸与氢氧化镁：H⁺ + OH⁻ → H₂O

**解析**：
A **正确**：原子守恒（Cl 2、H 2、O 2），电荷守恒（左 −2、右 −2）
B **错误**：电荷不平（左 −1、右 −2），未配平。正确：Br₂ + 2I⁻ → 2Br⁻ + I₂
C **错误**：NaBr、AgNO₃ 是可溶强电解质，必须拆。正确：Ag⁺ + Br⁻ → AgBr↓
D **错误**：Mg(OH)₂ 难溶，不能拆。正确：Mg(OH)₂ + 2H⁺ → Mg²⁺ + 2H₂O

**💥 陷阱**：B 看上去"物质都对"就放过。离子方程式三查里最容易漏的是**电荷守恒**，而它恰恰是判错的最快入口。

**变式**：把 D 改成"盐酸与澄清石灰水"，离子方程式怎么写？（H⁺ + OH⁻ → H₂O，澄清石灰水中 Ca(OH)₂ 完全电离）

### 例题 3 · L3 综合

某无色溶液中可能含有 Na⁺、Mg²⁺、Cu²⁺、Cl⁻、SO₄²⁻、CO₃²⁻ 中的几种。取 100 mL 该溶液进行实验：
① 加足量 BaCl₂ 溶液，得白色沉淀 2.33 g，过滤；
② 向滤液中加 NaOH 溶液至过量，得白色沉淀 0.58 g；
③ 另取原溶液，加稀硝酸酸化的 AgNO₃ 溶液，得白色沉淀 2.87 g。
判断原溶液中一定存在、一定不存在、可能存在的离子。

**解析**：
① 2.33 g 为 BaSO₄（M = 233），n(SO₄²⁻) = 0.01 mol → **一定含 SO₄²⁻**
② 0.58 g 为 Mg(OH)₂（M = 58），n(Mg²⁺) = 0.01 mol → **一定含 Mg²⁺**
③ 2.87 g 为 AgCl（M = 143.5），n(Cl⁻) = 0.02 mol → **一定含 Cl⁻**
溶液**无色** → **一定不含 Cu²⁺**（Cu²⁺ 显蓝色）
CO₃²⁻ 与 Mg²⁺ 不能大量共存（生成 MgCO₃ 沉淀）→ **一定不含 CO₃²⁻**
电荷守恒检验：阳离子电荷 2 × 0.01 = 0.02 mol；阴离子电荷 2 × 0.01 + 0.02 = 0.04 mol
负电荷多出 0.02 mol，必须由 Na⁺ 补足 → **一定含 Na⁺ 0.02 mol**
结论：一定有 Na⁺、Mg²⁺、Cl⁻、SO₄²⁻；一定没有 Cu²⁺、CO₃²⁻

**💥 陷阱**：算完三种离子就收工，漏掉电荷守恒这一步——Na⁺ 是"算出来"的，不是"看出来"的。另外忽略"无色"，就会把 Cu²⁺ 放进可能存在的名单。

**变式**：若③中沉淀改为 1.435 g，其余不变，Cl⁻ 的浓度是多少？还需 Na⁺ 吗？（0.01 mol ÷ 0.1 L = 0.1 mol·L⁻¹；正电荷 0.02 mol、负电荷 0.02 + 0.01 = 0.03 mol，仍需 Na⁺ 0.01 mol）

## A-2.7 卤素性质递变与溴、碘的提取

*必修一 › 第2章 海洋中的卤素资源 ｜ Ⅱ · 考频高 ｜ 前置：A-2.2、A-2.6 ｜ 关联：A-2.5*

**⚡ 先猜**：把溴水滴入 NaCl 溶液，能把 Cl⁻ 氧化成 Cl₂ 吗？

### 30 秒概述

Cl₂、Br₂、I₂ 都是双原子分子，随相对分子质量增大，颜色由黄绿→深棕红→紫黑，密度增大、熔沸点升高、水中溶解度减小。化学上它们都易得 1 个电子变成 −1 价离子，但**氧化性 Cl₂ > Br₂ > I₂**，前面的单质能把后面的离子置换出来。提溴靠"浓缩—氧化—吹出"，提碘靠海带富集后氧化、萃取。

### 30 秒自评

1. 卤素单质的氧化性顺序为 Cl₂ > Br₂ > I₂。
2. 溴的四氯化碳溶液呈红棕色，碘的四氯化碳溶液呈紫色。
3. 用 CCl₄ 萃取碘水中的碘，静置分层后紫色在下层。

> **答案**：1. ✓　2. ✓　3. ✓（CCl₄ 密度 1.59 g·cm⁻³，比水大，下层为紫红色）

### 🔑 原理与方程式

**一、单质的状态与颜色**

| 单质 | 常温状态 | 颜色 | 水中溶解性 | 特性 |
|---|---|---|---|---|
| Cl₂ | 气体 | 黄绿色 | 1 体积水溶约 2 体积 | 有毒 |
| Br₂ | 液体 | 深棕红色 | 3.4 g/100 g 水 | 易挥发，须水封保存 |
| I₂ | 固体 | 紫黑色 | 0.029 g/100 g 水 | 易升华，遇淀粉变蓝 |

- 递变规律：颜色加深、密度增大、熔点沸点升高、水中溶解度减小
- 溴的保存：试剂瓶密封，并加少量水覆盖以减少挥发
- 碘的升华：受热直接变蒸气，蒸气遇冷又凝成固体，可用于提纯碘

**二、氧化性递变与置换**

- Cl₂ + 2Br⁻ → 2Cl⁻ + Br₂　（2-14）
- Cl₂ + 2I⁻ → 2Cl⁻ + I₂　（2-15）
- Br₂ + 2I⁻ → 2Br⁻ + I₂　（2-16）
- 结论：氧化性 **Cl₂ > Br₂ > I₂**；对应离子还原性 **I⁻ > Br⁻ > Cl⁻**
- 碘的检验：遇淀粉溶液变蓝（I⁻ 不行，必须先是 I₂）

**三、萃取与分液**

- 原理：同一种溶质在两种互不相溶的溶剂中溶解度不同，用溶解度大的溶剂把溶质"拉"过来
- 萃取剂三条件：与原溶剂不互溶、不与被萃取物反应、溶质在其中溶解度远大于原溶剂
- 常用 CCl₄（密度大于水，下层有色）、苯（密度小于水，上层有色）；**酒精不能萃取碘**（与水互溶，不分层）
- 操作顺序：加萃取剂 → 振荡 → 静置分层 → 分液（下层从下口放出，上层从上口倒出）

**四、从海水中提溴（浓缩 → 氧化 → 提取）**

- 原料：苦卤（海水晒盐后的母液），Br⁻ 已富集
- 氧化：通入 Cl₂，Cl₂ + 2Br⁻ → 2Cl⁻ + Br₂（2-14）
- 吹出：向溶液中鼓入热空气或水蒸气，Br₂ 随水蒸气挥发，冷凝得粗溴（利用 Br₂ 沸点比水低、易挥发）
- 富集（工业流程常见）：用 SO₂ 水溶液吸收 Br₂，SO₂ + Br₂ + 2H₂O → H₂SO₄ + 2HBr（2-20），再用 Cl₂ 氧化，得到高纯度溴

**五、从海带中提碘**

- 海带灼烧成灰 → 浸泡使 I⁻ 进入水中 → 通 Cl₂ 氧化：Cl₂ + 2I⁻ → 2Cl⁻ + I₂（2-15）→ 萃取或升华得碘
- 海水不能直接提碘：碘浓度太低；海藻类有富集碘的能力

**六、卤素离子的检验**

- 试剂：稀硝酸酸化的 AgNO₃ 溶液
- Ag⁺ + Cl⁻ → AgCl↓（白色）　（2-17）
- Ag⁺ + Br⁻ → AgBr↓（浅黄色）　（2-18）
- Ag⁺ + I⁻ → AgI↓（黄色）　（2-19）
- 三种沉淀均不溶于稀硝酸；加稀硝酸的目的是排除 CO₃²⁻ 的干扰

**适用条件**：萃取剂必须与原溶剂互不相溶；溴、碘的萃取是分离过程（没有生成新物质），而 Cl₂ 置换 Br⁻ 是化学变化，两者不能混为一谈；卤素离子检验必须先酸化。

**易错边界**
1. 用酒精萃取碘——酒精与水互溶，根本不分层
2. 把"萃取"当成"置换"——萃取只改变溶质所在溶剂，不改变物质本身
3. 检验 Cl⁻ 只加 AgNO₃ 不加稀硝酸——Ag₂CO₃ 也是白色沉淀，会造成误判

### 例题 1 · L1 基础

写出 Cl₂ 分别与 NaBr 溶液、KI 溶液反应的离子方程式，并据此排出 Cl₂、Br₂、I₂ 的氧化性顺序。

**解析**：
Cl₂ + 2Br⁻ → 2Cl⁻ + Br₂；Cl₂ + 2I⁻ → 2Cl⁻ + I₂
Cl₂ 能把 Br⁻、I⁻ 氧化，说明 Cl₂ 的氧化性强于 Br₂、I₂
氧化性顺序：**Cl₂ > Br₂ > I₂**

**💥 陷阱**：写成化学方程式不拆（NaBr + Cl₂ → NaCl + Br₂），或忘配平 2Br⁻ 导致电荷不平。

**变式**：Br₂ 与 KI 溶液反应吗？写出离子方程式。（反应，Br₂ + 2I⁻ → 2Br⁻ + I₂，说明 Br₂ > I₂）

### 例题 2 · L2 常考

取 10 mL 碘水于试管中，加入 5 mL CCl₄，振荡后静置。
(1) 描述现象；(2) 分液时先放出哪一层，上层从哪里取出；(3) 能否用酒精代替 CCl₄，为什么？

**解析**：
(1) 溶液分层：**下层为紫红色**（碘的 CCl₄ 溶液），上层颜色明显变浅（碘被萃取走）
(2) CCl₄ 密度比水大，先放出**下层**；上层液体从分液漏斗**上口**倒出，避免污染
(3) **不能**。酒精与水任意比互溶，加入后不分层，无法分液，也起不到萃取分离的作用

### 例题 3 · L3 综合

某化工厂以苦卤为原料提溴，主要步骤为：通入 Cl₂ 氧化 → 鼓入热空气吹出 → 用 SO₂ 水溶液吸收 → 再通 Cl₂ 氧化 → 蒸馏得液溴。
(1) 写出步骤①的离子方程式；
(2) 步骤②为什么能用热空气把溴吹出？
(3) 步骤③中 SO₂ 起什么作用？写出化学方程式；
(4) 处理 1.0 m³ 苦卤（c(Br⁻) = 0.050 mol·L⁻¹），理论上至少需 Cl₂ 多少摩尔？可得 Br₂ 多少千克？（Br 取 80）

**解析**：
(1) Cl₂ + 2Br⁻ → 2Cl⁻ + Br₂
(2) Br₂ 沸点（58.8 ℃）比水低、易挥发，鼓入热空气或水蒸气时 Br₂ 随气流逸出，冷凝即得粗溴
