# 体例与符号规范（化学卷 · v1）

> 沿用物理、数学卷的骨架：**一张卡片 = 一个教材章**，章内按考点拆，先自评、再决定读多少。
> 化学的差别在"公式"换成了**方程式与守恒关系**：配平、条件、状态、单位，一处错整题错，所以规范要比物理更死。

---

## 一、编号规则

| 对象 | 格式 | 示例 | 说明 |
|---|---|---|---|
| 模块 | A–E | C | A 必修一、B 必修二、C 反应原理、D 物质结构、E 有机基础 |

| 考点 | `字母-章号.序号` | `C-3.2` | 章内从 1 开始，按教材节序 |

| 例题 | `例题 n · L级` | `例题 2 · L2` | L1 基础 / L2 常考 / L3 综合 |
| 方程式 | 卡内编号 | `(3-2)` | 单元内连续编号，速查表引用同一编号 |

## 四、化学式与方程式写法（本卷最重要的约定）

**统一纯文本 + Unicode 上下标，不写 LaTeX，不用图片公式。** 这样 PDF、Word、HTML、Excel 四处同源。

| 项 | 约定 | 正例 | 反例 |
|---|---|---|---|
| 下标 | Unicode 下标数字 | H₂SO₄、Ca(OH)₂、C₆H₁₂O₆ | H2SO4、H_2SO_4 |
| 电荷 | Unicode 上标 | SO₄²⁻、Fe³⁺、NH₄⁺、OH⁻ | SO4^2- |
| 反应箭头 | `→` | `2H₂ + O₂ → 2H₂O` | `-->`、`=` |
| 可逆反应 | `⇌` | `N₂ + 3H₂ ⇌ 2NH₃` | `<->` |
| 气体/沉淀 | `↑` / `↓`，只在该标时才标 | `Zn + 2HCl → ZnCl₂ + H₂↑` | 所有气体都标 |
| 反应条件 | 箭头右侧圆括号 | `2KClO₃ →(MnO₂, Δ) 2KCl + 3O₂↑` | 把条件写在等号上 |
| 状态（热化学） | `(g)` `(l)` `(s)` `(aq)` | `H₂(g) + ½O₂(g) → H₂O(l) ΔH = −285.8 kJ·mol⁻¹` | 省略状态 |
| 离子方程式 | 强酸强碱可溶盐拆成离子，其余写化学式 | `Ag⁺ + Cl⁻ → AgCl↓` | 把 AgCl 拆开 |
| 电子式/结构式 | 用 `·` `×` 表示最外层电子；结构式用 `—` 连键 | `H—O—H`、`Na⁺[:Cl:]⁻` | 画图 |

**配平与检查**：写方程式必须过"三查"——查元素守恒、查电荷守恒（离子方程式）、查条件与状态。缺一项按错处理。

## 五、数值与单位约定

| 项 | 取值 |
|---|---|
| 阿伏加德罗常数 N_A | 6.02 × 10²³ mol⁻¹ |
| 气体摩尔体积 V_m | 22.4 L·mol⁻¹（**标准状况** 0 ℃、101 kPa） |
| 摩尔质量 | 以 g·mol⁻¹ 计，取教材相对原子质量（H 1、C 12、N 14、O 16、Na 23、Mg 24、Al 27、S 32、Cl 35.5、K 39、Ca 40、Fe 56、Cu 64、Zn 65、Ag 108、Ba 137） |
| 水的离子积 K_w | 1.0 × 10⁻¹⁴（25 ℃），温度升高增大 |
| 燃烧热/中和热 | 统一注温度与压强，ΔH 带符号与单位 kJ·mol⁻¹ |
| 有效数字 | 题干几位结果几位；pH 保留两位小数 |
| 单位书写 | 用 `·` 连接复合单位（mol·L⁻¹、kJ·mol⁻¹），不用 `/` 叠加两次 |

**约定**：计算题先写"解：设……"，再列式子，最后带单位作答；比例式必须写清"物质的量之比 = 化学计量数之比"。

## 六、考点卡片固定结构（10 段）

```
### C-3.2 弱电解质的电离平衡
*反应原理 › 选必一 第3章 水溶液中的离子反应与平衡 ｜ Ⅱ · 考频高 ｜ 前置 C-3.1 ｜ 关联 C-3.3*

**⚡ 先猜**：一句反直觉的判断（不给答案）
**30 秒概述**        2–3 句：解决什么问题、核心结论
**30 秒自评**        3 题（判断/选择/小计算），答案紧跟
**🔑 原理与方程式**   定义、规律、方程式（编号引用速查表）
**适用条件**         什么时候不成立（浓度、温度、状态）
**易错边界**         3 条以内，具体到错在哪一步
**例题 1 · L1 基础** 单点、单步
**例题 2 · L2 常考** 上海卷常见形态
**例题 3 · L3 综合** 多步、跨考点，必配变式
**⏱️ 限时挑战**      60–90 秒 2–3 小问
**✅ 接下来做什么**   按自评结果给走法 + 过关线
```

每个单元另附两张表：
- `## 📐 方程式速查`：编号 / 方程式 / 名称 / 条件（parse.py 会解析为"公式"）
- `## 🕸️ 考点关系`：从 / 到 / 类型（前置、派生、易混、综合、实验）

## 八、实验与配图

- 实验考点必须写清：**仪器 → 操作 → 现象 → 结论 → 注意事项**，五要素缺一不可。
- 装置图暂用文字描述 + 简表；如需图，用 SVG，画布 480×280、线宽 2、字号 13，颜色语义固定：**蓝 = 液体/水**，**灰 = 玻璃仪器**，**橙 = 加热/火焰**，**绿 = 气体**。
- 危险操作（浓硫酸稀释、可燃性气体验纯、尾气处理）必须在"易错边界"里单列。

## 九、图谱关系

| 类型 | 含义 | 例子 |
|---|---|---|
| 前置 | 学它之前必须先掌握 | 物质的量 → 摩尔浓度 |
| 派生 | 由它直接推出 | 勒夏特列原理 → 合成氨条件选择 |
| 易混 | 概念相近易错 | 电解质 ↔ 非电解质 |
| 综合 | 常在综合题中联用 | 氧化还原 ↔ 电化学 |
| 实验 | 对应的必做实验 | 中和滴定 ↔ 酸碱指示剂选择 |

### 考点级：30 秒自评 3 题

| 正确数 | 行动 |
|---|---|
| 3 | 直接做例 3 + 变式，全对才过 |
| 2 | 读"易错边界"，做例 2、例 3 变式 |

### 过关标准

> **例题 3 做对 + 变式做对 = 过关。**
> 方程式的题，配平错、条件漏、状态缺，按错处理。

## 十一、错题回炉（错因码）

| 码 | 名称 | 典型表现 |
|---|---|---|
| C1 | 概念混淆 | 电解质/非电解质、同素异形体/同位素 |
| C2 | 漏条件 | 标准状况、温度、浓度、过量/少量 |
| C3 | 方程式错 | 未配平、电荷不平、条件漏写、拆写错 |
| C4 | 单位换算 | mL 当 L、g 与 mol 混用 |
| C5 | 运算失误 | 10⁻¹⁴ 算错、指数加减错 |
| C6 | 读题漏信息 | "恰好完全反应"看成"过量" |
| C7 | 模型选错 | 该用守恒却硬算、该用平衡常数却用转化率 |
| C8 | 表述不全 | 缺现象、缺结论、缺单位 |

**回炉日程**：D0 记错题 + 错因码 → D+1 遮解析重做 → D+3 换数据做同结构题 → D+7 仍错回读易错边界。

## 十二、构建与产物

```bash
bash build/make.sh      # 解析 → Excel → Word → HTML → PDF（Chrome 打印）
```

| 产物 | 文件 |
|---|---|
| PDF 手册 | `输出/上海高中化学知识图谱手册.pdf` |
