# 怎么用这本书

## 一张卡片长什么样

一个教材章一张卡，卡里按考点拆，每个考点固定 10 段，从上往下读：

| 部分 | 是什么 | 要不要全看 |
|---|---|---|
| **标题 + 灰色斜体行** | 如 `C-3.2 弱电解质的电离平衡`，后面是教材位置、层级、考频、前后关联 | 可跳过 |
| **⚡ 先猜** | 一道反直觉的判断，**故意不给答案** | 建议做，30 秒 |
| **30 秒概述** | 两三句话讲清"这个考点解决什么问题" | 必看 |
| **30 秒自评** | 3 道判断/选择/小计算，答案紧跟其后 | 必做，2 分钟 |
| **🔑 原理与方程式** | 定义、规律、方程式都在这里 | 按自评结果决定 |
| **适用条件 / 易错边界** | 什么时候不成立、最容易错在哪一步 | 自评不理想时必看 |
| **例题 1 / 2 / 3** | 基础 → 常考 → 综合，每题带陷阱和变式 | 看年级 |
| **⏱️ 限时挑战 + ✅ 接下来做什么** | 90 秒小测，再按"对了几道"告诉你下一步 | 必看 |

每个单元末尾还有两张表：**📐 方程式速查**（编号、方程式、名称、条件）和 **🕸️ 考点关系**（前置/派生/易混/综合/实验）。

## 三个年级怎么用

| 年级 | 建议做法 | 每个考点花多久 |
|---|---|---|
| **高一** | 跟着教材进度：概述 + 自评 + 原理与方程式，做例题 1 | 10–15 分钟 |
| **高二** | 全看，重点啃"适用条件"和"易错边界"，做例题 1、2 | 20–25 分钟 |
| **高三** | 跳过概述，直接自评；全对就只做例题 3 + 变式 | 8–12 分钟 |

## 一个考点的完整闭环

1. **先猜**（30 秒）：带着悬念读，猜错了更好。
2. **自评**（3 题）：数一数对了几道，别急着看答案。
3. **按结果做题**：
   - 3 道全对 → 直接做例题 3 + 变式，全对才进下一个考点；
   - 对 2 道 → 读"易错边界"，做例题 2、3 的变式；
   - 对 0–1 道 → 从"原理与方程式"顺序学到例题 3。
4. **限时挑战**（90 秒）：只练已学内容，超时也做完、不记分。
5. **错了就回炉**：D0 记错题与错因码，D+1 遮解析重做，D+3 换数据做同结构题，D+7 仍错就回读易错边界。

## 化学要特别盯的三件事

1. **方程式必须"三查"**：查元素守恒、查电荷守恒（离子方程式）、查条件与状态。缺一项按错处理。
2. **条件与状态是得分点**：标准状况（0 ℃、101 kPa）才用 22.4 L/mol；热化学方程式必须标 (g)/(l)/(s)/(aq) 和 ΔH 的符号、单位。
3. **单位一路带到底**：mL 先换 L、g 先换 mol；带单位的答案才算完整。

## 错因码（记错题时标一个主因）

| 码 | 名称 | 典型表现 |
|---|---|---|
| C1 | 概念混淆 | 电解质/非电解质、同素异形体/同位素 |
| C2 | 漏条件 | 标准状况、温度、浓度、过量/少量 |
| C3 | 方程式错 | 未配平、电荷不平、条件漏写、拆写错 |
| C4 | 单位换算 | mL 当 L、g 与 mol 混用 |
| C5 | 运算失误 | 10⁻¹⁴ 算错、指数加减错 |
| C6 | 读题漏信息 | "恰好完全反应"看成"过量" |
| C7 | 模型选错 | 该用守恒却硬算、该用平衡常数却用转化率 |
| C8 | 表述不全 | 缺现象、缺结论、缺单位 |

## 一周怎么安排（参考）

| 时间 | 做什么 | 多久 |
|---|---|---|
| 周一 | 新单元入口自评 10 题，决定这个单元学多少 | 12 分钟 |
| 周二–周三 | 按自评结果学 ★ 考点，做例题 1、2 | 每天 20 分钟 |
| 周四 | 例题 3 + 变式；背本单元方程式速查 | 20 分钟 |
| 周五 | 限时挑战 + 错题回炉（D+1、D+3） | 15 分钟 |
| 周末 | 方程式默写：遮住"方程式"列，只看名称写方程式 | 20 分钟 |

## 三条使用建议

1. **不要从第一页读到最后一页。** 先自评，再决定读多少；全对就只做例题 3 + 变式。
2. **方程式不要"看会"**，要"写对"。遮住答案默写，配平、条件、状态一个都不能少。
3. **错题比新题值钱。** 同一个考点错三次，该回去读"适用条件与易错边界"，而不是再刷十道新题。

## 版本说明

- 教材依据：沪科版（上海科学技术出版社）《化学》必修第一、二册（2021 版），选择性必修第一册《化学反应原理》、第二册《物质结构与性质》、第三册《有机化学基础》（2023 版）
- 覆盖：5 册、19 章、60 节，拆为 19 个单元
- 考试依据：上海高考化学（等级考）
- 记号约定：化学式用 Unicode 下标（H₂SO₄），离子电荷用上标（SO₄²⁻），反应 `→`、可逆 `⇌`、气体 `↑`、沉淀 `↓`、条件写在箭头右侧括号内
- 数值约定：N_A = 6.02 × 10²³ mol⁻¹；V_m = 22.4 L·mol⁻¹（标准状况）；K_w = 1.0 × 10⁻¹⁴（25 ℃）
