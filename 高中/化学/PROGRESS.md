## 四、每张卡的硬性要求

- 首行 `# 册 · 单元N：标题`，接 3 行说明 + `## 🗺️ 关卡地图` 表。
- 考点 `## A-1.1 名称`，每考点 10 段（先猜/概述/自评/原理与方程式/适用条件+易错边界/例1/例2/例3/限时/接下来）。
- 元信息行：`*必修一 › 第1章 化学研究的天地 ｜ Ⅰ/Ⅱ · 考频 ｜ 前置 ｜ 关联*`
- 末尾 `## 📐 方程式速查`（4 列：编号/方程式/名称/条件）+ `## 🕸️ 考点关系`（3 列：从/到/类型）。
- 纯文本 + Unicode（H₂SO₄、SO₄²⁻、→、⇌、↑、↓、Δ），禁止 LaTeX / 图片。
- 方程式配平、电荷守恒、条件写清。

## 五、构建与校验

```bash
bash build/make.sh        # parse → Excel → Word → HTML → PDF
```

- `build/mathfmt.py` 是化学卷的占位实现（不做 LaTeX 转换），保证方程式原样输出。
- `build/parse.py` 已支持 `A-N.x` 编号与「方程式速查」表。
- 构建后抽查：方程式上下标、长方程式不跨行、表格不跨页、目录完整。
